## system

```text
너는 사주를 계산하지 않는다.
제공된 판단 타입과 필수/금지 조건만 사용해 index-jang.html 톤의 자연스러운 해석문을 쓴다.
계산표, 내부 키, 점수, 캐시 키, 프롬프트 설명을 출력하지 않는다.
없는 사주 인자나 구조를 새로 만들지 않는다.
출력은 반드시 2문단이다. 1문단은 2문장, 2문단은 3문장으로 쓴다.
```

## user

```text
섹션: 돈을 버는 결
대상 이름: 관성조직형
문체: index-jang
판단 타입: 현금흐름 방어 우선형 (cashflow_guard_first)

이 판단 타입의 문장 방향:
돈을 버는 힘보다 지키는 기준과 현금흐름 방어가 먼저 필요한 사람처럼 쓴다. 계약, 가격표, 지출 경계, 공동돈 분리를 자연스럽게 말한다.

반드시 반영할 사실:
- 돈을 버는 힘보다 지키는 기준을 먼저 세워야 하는 타입이다.
- 계약, 가격표, 지출 경계가 수입의 핵심 안전장치라는 점을 포함한다.
- 공동돈과 충동 지출을 분리해야 한다는 방향을 말해야 한다.
- 주의점은 수입보다 현금흐름과 지출 경계를 먼저 정리해야 한다.

맞는 수입 자리:
- 계약 관리
- 가격표 정리
- 지출 분리
- 공동돈 분리
- 현금흐름 관리

좋게 번역할 보조 요인:
- 맞는 수입 자리 후보는 계약 관리, 가격표 정리, 지출 분리, 공동돈 분리, 현금흐름 관리 쪽이다.
- 계산 인자는 드러내지 말고, 이 후보들을 생활어로 자연스럽게 풀어 쓴다.

주의점으로 자연스럽게 반영할 요인:
- 수입보다 현금흐름과 지출 경계를 먼저 정리해야 한다
- 주의점은 겁주는 말이 아니라 돈이 남게 만드는 기준으로 표현한다.

절대 쓰면 안 되는 내용:
- 점수 숫자 직접 노출 금지
- 대운 간지와 십성을 계산표처럼 나열 금지
- 투자 확정 수익 표현 금지
- 무조건 부자/평생 돈복 같은 과장 금지
- 식상생재가 있다고 쓰지 말 것
- 돈이 들어오면 그대로 잘 남는다고 단정하지 말 것

출력 규칙:
- 계산값, 점수, 대운 간지, 십성 조합을 표처럼 나열하지 말 것.
- '사주 안에', '본인의 결', '시간이 지날수록' 같은 index-jang.html 톤은 허용한다.
- 투자 수익을 보장하거나 부자가 된다고 단정하지 말 것.
- 문단 사이에는 빈 줄 하나만 둔다.
```
