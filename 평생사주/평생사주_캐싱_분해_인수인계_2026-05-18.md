# 평생사주 캐싱 분해 인수인계

작성일: 2026-05-18

## 결론

평생사주는 아이기질+부모양육처럼 부모/아이 조합이 폭발하지 않는다. 생년월일, 출생시간, 성별 기준의 1인 단독 캐시가 가능하다.

단, 완성 HTML 전체를 저장하지 않는다. 기존 렌더/레이아웃/차트/표는 유지하고, 실제 엔진 계산값과 LLM 문장 블록만 분리해 저장한다.

## 실제 엔진

```text
옵시디언 문서: 룰북/평생사주1/1_엔진레이어.md
진입점: lib/saju-core.ts#computeFullSajuCore
보조 파일:
- lib/saju-calculator.ts
- lib/saju-traditional.ts
- lib/jpjjeon.ts
- lib/sibiunseong.ts
- lib/tonggeun.ts
- lib/samhap.ts
- lib/seun.ts
- lib/personal-traits-block-v2.ts
```


## 샘플 상태

샘플 4개의 calculated.json은 실제 `computeFullSajuCore` 호출로 생성했다. standalone/options 문장은 calculated.json의 일간, 오행, 십성, 신강신약, 용신, 대운 필드를 읽어 만든 블록 구조 확인용 초안이다.

다음 단계는 영역별 점수 산출기와 대운별 bright/care period 산출기를 붙여서 재물/직업/사업/결혼/건강의 시기 블록을 결정론 값으로 채우는 것이다.
