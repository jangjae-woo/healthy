# 평생사주 LLM 사전생성 캐시 계약

작성일: 2026-05-18

## 결론

평생사주는 실시간 LLM 풀이로 가지 않는다.

구조는 다음으로 고정한다.

```text
엔진 = 판단
LLM = 문장화
캐시 = 서비스 출력
검수 = 모순 제거
```

LLM은 사주 판단을 하지 않는다. 엔진이 만든 판단 타입, 강약 구간, 금지 조건, 필수 조건을 받아서 `index-jang.html` 톤의 자연스러운 해석문으로 바꾸는 역할만 한다.

## 숫자 구간 기준

오행:

```text
0       = 없음
0.1~0.9 = 결핍
1.0~1.9 = 약
2.0~2.9 = 보통
3.0~3.9 = 중상
4.0~5.9 = 강
6.0+    = 과다
```

십성:

```text
0       = 없음
0.1~0.9 = 미약
1.0~1.9 = 약
2.0~2.9 = 보통
3.0~3.9 = 강
4.0+    = 과다
```

원점수는 계산에만 사용한다. 캐시 키에는 구간 라벨을 넣는다.

## LLM 입력 원칙

LLM에게 생년월일시를 던지고 풀이를 맡기지 않는다.

반드시 아래처럼 판단 완료된 상태를 넘긴다.

```text
pageAlias=wealth
sectionRole=earning
personName=장민호
tone=index-jang
judgementType=created_value_to_asset
wealthFlow=siksang_to_jaeseong
siksangBand=강
jaeseongBand=중상
shinkang=신강
strongElement=수
weakElement=금
fitIncomeSeats=본인 이름 콘텐츠, 노하우 기반 서비스, 1인 사업, 전문 컨설팅
riskPattern=contract_price_boundary
forbidden=점수 노출 금지, 없는 인자 생성 금지, 계산표 말투 금지
```

## 원하는 출력 톤

나쁜 방향:

```text
35~44세 병오 대운에는 정재/정재 점수 95가 들어옵니다.
수 기운이 강하고 금 기운이 약합니다.
```

좋은 방향:

```text
장민호 님은 본인이 만든 결과물이 곧 자산이 되는 결이에요.
사주 안에 식상생재 흐름이 또렷하게 살아 있어, 본인의 표현·재능·기획이 돈으로 이어지는 자연 통로가 있습니다.

구체적으로는 본인 이름을 건 콘텐츠, 노하우 기반 서비스, 1인 사업, 전문 컨설팅 같은 자리가 잘 맞아요.
회사 월급도 안정적인 바탕이 될 수 있지만, 본인은 "내가 만든 가치가 직접 돈으로 흐르는 자리"에서 결이 가장 살아납니다.
시간이 지날수록 결과물의 가치가 쌓이는 구조라, 오래 축적한 노하우가 평생 수입의 자리가 될 수 있습니다.
```

## 평생사주 우선 구현

1. `돈을 버는 결`부터 판단 타입을 만든다.
2. 판단 타입은 인자 하나가 아니라 조합 판단 결과여야 한다.
3. 예: 식상 상태 + 재성 상태 + 식상생재 여부 + 비겁 소모 + 신강신약 + 대운 점수.
4. LLM은 이 판단 타입을 받아 자연어 문단 후보를 만든다.
5. 후보는 캐시에 저장하고 자동 검수한다.
6. `index-jang.html`의 폼, 문단 수, 리스트 수는 절대 바꾸지 않는다.

## 다른 채널 전달: 인연궁합

아래 내용을 인연궁합 담당 Codex에게 그대로 전달한다.

```text
너는 인연궁합 파트를 맡아줘.

공통 구조는 "엔진 판단 + LLM 사전생성 + 캐싱 + 검수"다.
LLM은 궁합 판단을 하지 않는다. 엔진이 두 사람의 관계 판단 타입을 만든 뒤, LLM은 그 결과를 자연스러운 문장으로 바꾼다.

인연궁합에서 먼저 만들어야 할 판단 타입:
- comfortable_growth_match: 편안하게 성장하는 궁합
- strong_attraction_high_friction: 끌림은 강하지만 마찰이 큰 궁합
- stable_life_partner: 생활 안정형 배우자 궁합
- teacher_student_dynamic: 한쪽이 이끌고 한쪽이 배우는 궁합
- emotional_care_match: 감정 돌봄이 잘 맞는 궁합
- money_reality_conflict: 돈과 현실 기준에서 부딪히는 궁합
- communication_repair_needed: 말의 방식 조율이 필요한 궁합
- long_term_routine_match: 오래 반복되는 생활 리듬이 맞는 궁합

필수 판단 인자:
- 두 사람의 일간 관계
- 두 사람의 일지 관계
- 일지 합/충/형/파/해
- 배우자성 상태
- 오행 보완 관계
- 오행 과다 충돌
- 십성 상호작용
- 대운 시기 겹침
- 관계 리스크 태그

금지:
- 한 사람 사주만 보고 궁합을 단정하지 말 것
- 없는 합/충을 만들지 말 것
- 끌림과 안정성을 같은 뜻으로 쓰지 말 것
- 공포 문장 금지
- 계산표 말투 금지
- 원본 폼의 문단 수와 구조를 깨지 말 것
```

## 다른 채널 전달: 연애사주

아래 내용을 연애사주 담당 Codex에게 그대로 전달한다.

```text
너는 연애사주 파트를 맡아줘.

공통 구조는 "엔진 판단 + LLM 사전생성 + 캐싱 + 검수"다.
LLM은 연애운을 판단하지 않는다. 엔진이 연애 판단 타입을 만든 뒤, LLM은 그 결과를 자연스러운 문장으로 바꾼다.

연애사주에서 먼저 만들어야 할 판단 타입:
- slow_trust_love: 천천히 신뢰가 쌓이는 연애
- fast_attraction_love: 빠르게 끌리는 연애
- expression_first_love: 표현과 대화가 먼저 살아나는 연애
- caregiving_love: 챙김과 돌봄으로 이어지는 연애
- independent_distance_love: 독립성과 거리감이 중요한 연애
- idealization_risk_love: 이상화와 착각을 조심해야 하는 연애
- reality_check_love: 현실 조건 확인이 중요한 연애
- late_blooming_stable_love: 늦게 안정되는 연애

필수 판단 인자:
- 일간
- 일지
- 배우자성
- 식상/관성/재성 상태
- 도화/홍염 등 연애 보조 태그
- 오행 감정 흐름
- 신강신약
- 연애 bright/care 대운

금지:
- 배우자성이 약한데 강하다고 쓰지 말 것
- 식상이 약한데 표현이 넘친다고 단정하지 말 것
- 대운 시기를 임의로 바꾸지 말 것
- 운명론/공포 문장 금지
- 계산표 말투 금지
- 원본 폼의 문단 수와 구조를 깨지 말 것
```
