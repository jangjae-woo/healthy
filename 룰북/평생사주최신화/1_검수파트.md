## Step 2 작업 — route.ts 흐름 변경

현재 (L4279~): 청크별 stream push
```
gemini stream → 청크마다 enqueue({ t: 'x', v: text })
```

신규: 청크 누적 → 가드 → 단일 push
```
gemini stream → accumulatedText 누적
→ guardGeneratedText({ service: "saju", ... })
→ enqueue({ t: 'x', v: finalText })
→ enqueue({ t: 'tk', m: tokensObj }) (cross-chapter)
→ enqueue({ t: 'd' }) → [DONE]
```

UX 변화: 글자 떠오르는 효과 사라짐. 섹션마다 "잠시 기다림 → 한 번에 본문 박힘". 다른 서비스(hongsil/inyeon/parent-child)와 동등.

## Step 3 작업 — Cross-chapter usedTokens
