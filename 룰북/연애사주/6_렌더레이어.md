# 6. 렌더 레이어 — 결과 화면 표시

## 역할
계산값과 LLM 본문을 카드·챕터·슬라이드로 표시. 초반 교육 UI 포함.

## 주요 파일
- `app/hongsil/result/page.tsx` — 메인 결과 페이지 + 8단 초반 교육 UI
- `components/hongsil/ChapterShell.tsx` — 챕터 셸 (다음/이전 버튼)
- `components/hongsil/YongsinCards.tsx` — 용신·희신·기신 카드
- `components/hongsil/SipseongRow.tsx` — 십성 행
- `components/hongsil/OhaengChart.tsx` — 오행 차트
- `components/hongsil/SajuTable.tsx` — 사주 4기둥 표
- `components/hongsil/SinKangBar.tsx` — 신강신약 바

## 초반 교육 UI (page.tsx 내부)
1. 어서 오세요
2. 들어가며: 사주란 무엇인가요?
3. 사주팔자의 구조
4. 천간
5. 지지
6. 오행
7. 연애의 열쇠, 일주
8. 관계의 방향표: 용신·희신·기신

→ LLM 생성 본문이 아닌 렌더 고정 UI. 디자인 수정 시 page.tsx에서만.

## 본문 렌더 흐름 (page.tsx L928~954)
1. SSE 스트림에서 `{ t: "x", ch, v }` 이벤트 누적 → `aiText[ch]`
2. `aiBodies`: 누적 텍스트를 `### sub` 헤더 단위로 분리
3. `bodyOf(ch, title, fb)`: `aiText[ch][title]` 또는 fallback 반환
4. `ChSub` 컴포넌트: `SubSection title={title} body={bodyOf(...)}`

## 본문 도착 안 할 시
- `aiText[ch]` 비어있으면 fallback 표시 (예: "편지를 정리하고 있어요…")
- 무한 로딩 ≈ LLM 응답이 빈 채로 와서 `enqueue('t:x')` 안 됨

## 시각 카드 사실 강제 (build-context.ts에서 prompt 주입)
- ch2 DaeunTimeline — 60세 이하 대운만 본문 인용 강제 (노년 대운 차단)
- ch3 DestinyHero — 운명 짝꿍 캐릭터 결정론
- ch4 PatternTags — 결정론 태그
- ch5 DesireBar — Q2 자가답
- ch6 LetterQuote — 두 캐릭터 결정론

→ 시각자료에 표시되는 데이터와 본문이 어긋나지 않게 prompt 단계에서 강제.

## 시각자료 데이터 출처
- `lib/hongsil/pattern-tags.ts` `derivePatternTags(saju, duration)`
- `_desireLabels` (build-context.ts에 정의) — Q2 선택지 → 라벨
- `meMatch.innerImage`, `destinyMatch.innerImage` — 캐릭터 내적 이미지

## 결제 후 흐름 (saved=1 / unlocked=1)
- saved=1: 저장된 풀이 재방문 → OpeningVideo 스킵 / 가드 재실행 X
- unlocked=1: 결제 직후 → `AI_START` 자동 점프

## 알려진 결함 / 운영 메모
- 본문 fallback 무한 로딩 시 → vercel logs에서 `[hongsil chN] EMPTY RESPONSE` 확인
- 캐릭터 카드(시각자료) 데이터와 본문 캐릭터 이름이 불일치하면 안 됨 → ch3 짝꿍 캐릭터 보존이 중요
