# 1. 엔진 레이어 — 사주 계산

## 역할
생년월일시를 사주 원국·오행 분포·십성·신살·대운·신강신약·용신/희신/기신·통근·합국·세운·십이운성·격국까지 모두 결정론 계산. LLM 입력 전 단계.

## 주요 파일
- `lib/saju-core.ts` — 핵심 계산 진입점
- `lib/saju-calculator.ts` — 천간·지지·오행·십성 분배
- `lib/saju-traditional.ts` — 전통 명리 보조
- `lib/jpjjeon.ts` — 자평진전 격국 8 정격 + 외격 + 공망
- `lib/sibiunseong.ts` — 십이운성 12단계 (일간×지지)
- `lib/tonggeun.ts` — 지장간 본기/중기/여기 통근 (총점·등급)
- `lib/samhap.ts` — 삼합·방합·반합
- `lib/seun.ts` — 세운(歲運) 정밀 분석 + 점수

## 호출 위치
- `app/api/hongsil-compute/route.ts` — 렌더용 데이터
- `app/api/hongsil-generate/route.ts` — LLM 생성용 데이터
- 둘 다 `computeFullSajuCore`를 같은 입력으로 호출 → 같은 결과 보장

## 출력 데이터 (SajuAnalysis)
- `pillars` — 년월일시 4기둥 (천간+지지)
- `ilgan` — 일간 (예: 갑목)
- `sipseong` — 천간/지지 십성
- `elements` — 목·화·토·금·수 카운트
- `yongsin` — 용신
- `sinsal` — 신살 목록
- `daeun.cycles` — 대운 흐름 (10년 주기)
- `shinkang` — 극약/태약/신약/중화/신강/태강/극왕
- `ohaengTop` / `ohaengWeak` — 가장 강한/약한 오행

## 주의
- 계산 로직 변경 시 hongsil + 인연궁합 + 평생사주 + 자도인 V2 + 부모자녀 모두 영향
- LLM에 직접 전달하지 않고 다음 단계인 **해석 기획 레이어**가 인자 분배 결정
