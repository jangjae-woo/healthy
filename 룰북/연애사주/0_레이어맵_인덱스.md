# 연애사주 — 6 레이어 인덱스

```
입력 (Q1·Q2·Q3 + 사주 데이터)
   ↓
1. 엔진 레이어              → 사주 원국·오행·십성·신살·대운·격국 계산
   ↓
2. 해석 기획 레이어         → 챕터별 인자 분배·중복 방지·톤·생활어 슬롯
   ↓
3. 캐릭터 매핑 레이어        → 본인·짝꿍 캐릭터 + 페어 라벨
   ↓
5. LLM 생성 레이어 (Gemini) → 챕터별 prompt → 본문 스트리밍
   ↓
4. LLM 검수팀               → 결정론 가드 → judge → rewrite → 결정론 가드 (이중)
   ↓
6. 렌더 레이어              → SSE 누적 → ### sub 헤더 분리 → ChSub 표시
   ↓
결과 (6 챕터 풀이지)
```

## 작업 시 수정 범위 가이드
| 수정하고 싶은 것 | 손대야 할 레이어 |
|---|---|
| 사주 계산법 변경 | 1 (다른 서비스 영향 검토) |
| 챕터별 톤 / 중복 정책 | 2 |
| 캐릭터 매핑 룰 | 3 |
| 본문 생성 prompt | 5 (v5-report.ts) |
| 본문 검수 / 자동 보정 | 4 (llm-output-guard.ts) |
| 결과 화면 디자인 / 시각자료 | 6 |
| 사주 처방 같은 새 데이터 추가 | 2 (helper) + 5 (prompt 주입) |
| 환각·결핍·반복 같은 출력 결함 | 4 (가드) — 5의 prompt 룰로는 한계 |

## 핵심 의사결정 (2026-05-13 기준)
- 한자 톤 정책: ch1 집중 (양반사주 톤) / ch2~ch6 점진 축소 — 룰북 의도
- Cross-chapter 한자 2회 허용 (3회째부터 풀 대명사 치환)
- 5장 한자 strip 강제
- 단독 풀이 환각 가드 (상대 사주 단정 금지)
- LLM judge + rewrite 활성 (챕터당 +3~5초 비용 받아들임)
- ch6는 한자 정의/cross-chapter 안내 prepend 제외 (모순 회피)

## 잔존 결함 (88~92% 천장)
