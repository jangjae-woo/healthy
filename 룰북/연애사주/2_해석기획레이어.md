# 2. 해석 기획 레이어 — 인자 분배·중복 방지·톤 결정

## 역할
엔진 결과를 LLM에 바로 던지지 않고, **전체 톤·반복 금지 인자·파트별 렌즈·한문 노출 정책**을 먼저 정한다. 같은 사주 인자가 여러 챕터에서 같은 말로 반복되지 않게.

## 주요 파일
- `lib/hongsil/interpretation-plan.ts` — 전체 해석 기획 + 챕터 정책
- `lib/hongsil/sub-distribution.ts` — sub별 PRIMARY 인자/생활어 슬롯 분배 + 인자 영역 회전 룰
- `lib/hongsil/traits-block.ts` — 결정론 매핑 풀 (cell framework)
- `lib/hongsil/build-context.ts` — 모든 블록을 챕터 prompt에 prepend (오케스트레이터)

## 핵심 함수
- `deriveHongsilInterpretationPlan(saju, name)` — 전체 해석 기획 생성
- `hongsilInterpretationPlanBlock(plan, scope)` — 챕터별 해석 기획 블록 생성
- `hongsilSubDistribution(scope)` — sub별 분배표 + 생활어 슬롯 룰
- `deriveHongsilTraits(saju)` — 자도인 V2 cell 재사용
- `hongsilTraitsToPromptBlock(traits, name, scope)` — 챕터별 traits 블록 (ch1만 풀 데이터, ch2~ch6은 간소화)

## 챕터별 정책 (CHAPTER_POLICY)
- **ch1 근거 신뢰 페이지**: "내 매력은?" 한문 병기 3~6개, 나머지 sub 1~3개 허용. 단 모두 자리 설명 + 쉬운 해석 동반.
- **ch2 사랑 타이밍**: 한문 1~2개. 반드시 시기·속도·준비감으로 번역. 대운·세운 직접 출력 X.
- **ch3 짝꿍·관계 방향**: 한문 1~3개 제한. 태도·만남 장면으로 즉시 해석.
- **ch4 반복 패턴**: 한문 0~2개. 결핍 낙인 금지.
- **ch5 끌림·본능**: 한문 0~2개 (실제로는 가드가 strip). 온도·거리·반응으로.
- **ch6 종합 편지**: 한문 직접 노출 금지. 캐릭터 결로 종합.

## 인자 영역 회전 룰 (sub-distribution.ts FACTOR_ROTATION_RULE)
- 같은 사주 인자를 다른 sub에서 메인 어휘로 반복 금지
- 인자가 같아도 다른 질문 영역으로만 사용 (매력 ≠ 호감 신호 ≠ 시기)
- 중복 판정 = 인자명이 아니라 "독자가 읽는 결론이 같은가"

## 절대 룰 (build-context.ts에서 모든 챕터에 prepend)
1. **SIPSEONG_STANDARD_DEFINITIONS** — 5종 십성 표준 정의 1문장씩
   - 비겁 = 자기 리듬·자기 기준·또래 감각·독립성
   - 식상 = 표현·발산·창의·전달
   - 재성 = 현실감·관계 운영·결단·실행
   - 관성 = 약속·기준·책임·규율
   - 인성 = 받아들임·사색·배움·내적 지지
   → 한 풀이 안에서 같은 십성을 다른 정의로 묘사 금지
2. **SOLO_MODE_GUARD** — 단독 풀이 환각 방지. "상대의 ○○ 기운" 단정 금지

## ch6 특이 사항
- `_common`(SIPSEONG_STANDARD_DEFINITIONS) 제외 — ch6 prompt 본문의 "한자 금지" 룰과 모순 → 빈 응답 사건 (2026-05-13 발생, fix됨)
- `crossChapterBlock` 제외 — 같은 이유
- SOLO_MODE_GUARD만 유지

## 금지 패턴 (interpretation-plan.ts L190)
- "신약한 사주" / "비겁이 없어" / "식상이 약해" / "부족해서 보완" / "혼자 짊어짐" / "감정을 삭임" / "벽처럼 느껴짐"
- 변형 표현(예: "신약한 구조", "관계의 모든 부담을 짊어")도 SOFT_REPLACEMENTS에서 캡처

## 금지 연결어 (반복 시)
- "앞에서 본", "이 흐름", "이 결", "이 리듬", "이 구조"

## 자연 비유 정책
- 1장 첫 sub("내 매력은?")만 허용
- 1장 sub2~sub6 + ch2~ch6: 자연 비유 (마치 X 처럼/같이/하듯, 나무·물·불·꽃·강·바다 등) 최소화
- 가드가 detect 후 judge로 issue 리포트, rewrite로 행동·말투·속도 어휘 교체
