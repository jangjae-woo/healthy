# 부모자녀궁합 — 6 레이어 인덱스

```
입력 (childName + 생년월일시 + momName/dadName 옵션)
   ↓
1. 엔진 레이어              → 자녀·부모 사주 원국·오행·십성·신살·대운·격국 + 부모-자녀 궁합 계산
   ↓
2. 해석 기획 레이어         → 챕터별 인자 분배·중복 방지·자도인 톤·생활어 슬롯·연령별 톤·미래형 강제
   ↓
3. 캐릭터 매핑 레이어        → 자도인(慈道人) 1 narrator + 자녀 일주 60갑자
   ↓
5. LLM 생성 레이어 (Gemini) → V2 phase별 prompt → 본문 스트리밍 (compute → ch1~ch6 → outro)
   ↓
4. LLM 검수팀               → 결정론 가드 → judge → rewrite → 결정론 가드 (이중)
   ↓
6. 렌더 레이어              → 클라이언트 phase 마커 → SLIDES 38개 매핑 → ChSub·OutroCard 표시
   ↓
결과 (38슬라이드 풀이지)
```

## V2 phase 구조 (서버 → 클라이언트)
- `compute` — 사주 계산 JSON 응답 (LLM 호출 X)
- `ch1` — intro (자도인 도입 + 7가지 설계도)
- `ch2` — 우리 아이는 어떻게 공부할까 (5 sub)
- `ch3` — 우리 아이 칭찬하고 혼내는 법 (5 sub)
- `ch4` — 친구 사이 우리 아이 (4 sub)
- `ch5` — 우리 아이는 무엇으로 빛날까 (5 sub)
- `ch6` — 엄마아빠와 우리 셋의 결 (3 sub, hasMom/hasDad 동적)
- `outro` — 자도인의 마지막 당부 (2~3 문장 강제)

→ 클라이언트가 fetch 루프 돌면서 phase 마커 `<<<PARENT_CHILD_PHASE:chN>>>` 박음. 본문 매핑은 마커로 phase 분기 + ### sub만 매칭.
