## 클라이언트 매핑 (Step 2 phase 마커)
- fetch 루프에서 `<<<PARENT_CHILD_PHASE:chN>>>` 마커 박음
- `buildSlideTextMap`: 마커로 phase 분기 → ### sub만 매칭, ## 헤더 무시
- `buildSlideTextMapLegacy` 보존 (회귀 안전망)
- **G13 SUB_HEADER_ALIASES**: 연령별 sub 헤더 양방향 매핑 — SLIDES canonical과 LLM 출력 양 헤더 둘 다 매칭

## 본문 렌더 흐름
1. compute fetch → `setMeta(computeJson)` (사주 데이터)
2. ch1~ch6+outro 순차 fetch
3. 매 phase 마커 박은 후 SSE stream 누적 → `setStreamText(full)`
4. `buildSlideTextMap(streamText)` → `result[slideIdx][sub]` 매핑
5. ChSub 컴포넌트가 `getSubText(map, slideIdx, sub.subtitle)`로 본문 받음
6. SUB_HEADER_ALIASES로 alias 매칭 (G13)
