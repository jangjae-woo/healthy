# 2. 해석 기획 레이어 — 인자 분배·중복 방지·자도인 톤·연령 분기

## 역할
엔진 결과를 LLM에 바로 던지지 않고, **전체 톤·반복 금지 인자·챕터별 sub 분배·자도인 페르소나·연령별 톤·미래형 강제**를 먼저 정한다. 같은 사주 인자가 여러 챕터에서 같은 말로 반복되지 않게.

## 주요 파일
- `lib/parent-child/build-context.ts` — 모든 블록 prepend (오케스트레이터, `buildParentChildContext`)
- `lib/parent-child/interpretation-plan.ts` — 5-lens plan + AgeStage 분류 + AGE_TONE_RULES + G6 미래형 강제 + G13 sub 헤더 분기
- `lib/parent-child/sub-distribution.ts` — sub별 PRIMARY 인자/생활어 슬롯 분배 + 인자 영역 회전 + CADENCE_OVERRIDE
- `lib/parent-child/yongsin-prescription.ts` — Step A 부모자녀 톤 처방
- `lib/parent-child-traits-block-v2.ts` — cell framework (250 cell + 60갑자 60 cell)
- `lib/personal-traits-block-v2.ts` — 자녀 단일 traits block
- `lib/heart-context.ts` — 십성 deep·신살·합충·용신 context
- `lib/child-seed.ts` — 자녀 핵심 키워드 seed
- `lib/age-stage.ts` — 연령별 톤 가이드·일일 디지털 한도
- `lib/opener-seed.ts` — 자도인 첫마디 priming
- `lib/element-prescription.ts` — 오행 처방 (보충·완화)
- `lib/inline-emphasis.tsx` — 본문 inline 강조 sanitize

## 핵심 함수
- `buildParentChildContext(req, sajuChild, sajuMom, sajuDad)` — 모든 챕터 prompt 컨텍스트 조립
- `getAgeAdaptedHeaders(ageStage)` — G13 ch2·ch3 sub 헤더 연령별 분기
- `classifyAgeStageFromYear(birthYear)` — AgeStage 분류
- `parentChildAgeToneBlock(ageStage)` — 연령 톤 강제 룰 prompt 블록
- `parentChildModeGuard` — 가족 입력 환각 차단 (한 부모만 입력시 다른 부모 단정 금지)

## 챕터별 sub 분배 (V2)
- ch1: intro (자도인 도입 + 7가지 설계도 — IntroSummaryV2 본문 1장)
- ch2: 우리 아이는 어떻게 공부할까 (5 sub: alone / method / express / clock / deskMind)
- ch3: 우리 아이 칭찬하고 혼내는 법 (5 sub: tantrum / calmEnv / praise / lie / breakdown)
- ch4: 친구 사이 우리 아이 (4 sub: heartDoor / friendStyle / lifeFriend / fatigue)
- ch5: 우리 아이는 무엇으로 빛날까 (5 sub: jobField / weapon / shineKey / shineAge / leaderExpert)
- ch6: 엄마아빠와 우리 셋의 결 (3 sub: ilganBond / trioMoment / flowFill)
- outro: 자도인의 마지막 당부 (2~3 문장 강제, F2)

## 연령 분기 (G13, 2026-05-14)
| AgeStage | 나이 | 허용 어휘 | 미래형 강제 |
|---|---|---|---|
| infant | 0~2 | 옹알이·놀이매트·자장가·그림책 | ★ |
| toddler | 3~4 | 걷기·블록·소꿉놀이 | ★ |
| preschool | 5~6 | 유치원·역할 놀이 | ★ |
| elementary | 7~12 | 학교·운동장·도서관 | 직업명만 미래형 |
| middle | 13~15 | 동아리·진로 탐색 | 성인 직업 미래형 |
| high | 16~18 | 진학·정체성 | 결혼·취업 미래형 |

### G6 미래형 강제 절대 룰 (infant/toddler/preschool)
- 패턴: "자라면서 ~한 결로 발전할 가능성", "커가면서 ~를 좋아하게 될 결", "초등 무렵엔 ~할 결"
- 금지: 현재형 학령기 묘사 ("이금희양은 책상 앞에 앉아 펜을 잡기 전", "연구자처럼 깊이 탐구")
- 정답: 미래형 prefix + 어른 어휘는 강제 변환

### G13 sub 헤더 연령 분기 (영유아 → 학령기)
- "혼자 vs 같이" ↔ "혼자 놀까 함께 놀까"
- "우리 아이만의 공부법" ↔ "이 아이는 어떻게 배워갈까"
- "글로 정리할까, 말로 표현할까" ↔ "입으로 보여줄까 손으로 보여줄까"
- "책상 앞 머릿속" ↔ "혼자 놀이할 때 머릿속" / "놀이매트 위 머릿속" (infant)
- "거짓말 했을 때" ↔ "고집부릴 때" (infant/toddler) / "거짓말이나 고집이 시작될 때" (preschool)

### 클라이언트 양방향 매핑
- `SUB_HEADER_ALIASES` 사전 + `getSubText` 함수 — SLIDES 정의 안 건드리고 alias로 매핑

## 톤 정책
- 자녀 호칭: `${childName}${honorific}` (남→군, 여→양)
- 부모 호칭: hasMom && hasDad ? "어머님, 아버님" : hasMom ? "어머님" : "아버님"
- 자도인 1인칭 narrator
- 결핍 낙인 어휘 금지 → "옅게 자리한 X의 결" 양반사주 톤
- F3 학령기 어휘 strip — 영유아엔 연구자/콘텐츠 제작자/책상/펜/문제집 등 차단

## 절대 룰 (build-context.ts에서 모든 챕터에 prepend)
1. **PARENT_CHILD_SIPSEONG_STANDARD_DEFINITIONS** — 5종 십성 표준 정의 (한 풀이 안에서 같은 십성을 다른 정의로 묘사 금지)
2. **parentChildModeGuard** — 가족 입력 환각 차단 (한 부모만 입력 시 다른 부모 단정 금지)
3. **G6 미래형 강제 룰** — 영유아 케이스에 자동 prepend (`parentChildAgeToneBlock`)

## CHAPTER_POLICY (sub-distribution.ts)
- ch1: intro 본문 1장으로 통합, 7가지 sub
- ch2: 학습 — 4단 구조 (단정 → 메커니즘 → 일상 → 권고), sub별 시그너처 (공식형/두 갈래/단정+일화/시간 흐름/관찰자)
- ch3: 칭찬·훈육 — 5 sub 시그너처 다양 (관찰자/단정 → 처방/금지어 직접 인용)
- ch4: 친구 — 4 sub (시간/4사분면/시기 짚기/패턴 진단)
- ch5: 빛나는 자리 — 미래형 5 sub
- ch6: 가족 — 부모 톤 (어머님께서는 / 아버님께서는)
- outro: 2~3문장 강제 (F2), 한 문장 50자 이내

## 인자 영역 회전 룰 (FACTOR_ROTATION_RULE)
- 같은 사주 인자를 다른 sub에서 메인 어휘로 반복 금지
- 인자가 같아도 다른 질문 영역으로만 사용 (학습 결 ≠ 친구 결 ≠ 칭찬 결)
- 중복 판정: 인자명이 아니라 "독자가 읽는 결론이 같은가"

## 금지 패턴
- "신약한 자녀", "비겁이 없어서", "감정을 삭임" — 결핍 낙인
- "5명 이내 팀 리더십", "콘텐츠 제작자" — 영유아 부적합 (F3 strip)
- "차가운 비판으로 자존감 무너짐" — 영아 부적합 (어휘 화이트리스트 확장 보류)
