4. 21 소제목 풀이 방향
================================================================

[1번 내 매력은?] 후킹형
- 1차 인자: 일간·귀인·재성·비겁
- 풀이: 여자 캐스케이드 1~6 매칭 → "OO상의 결" 단언 → 평상시 매력 결
- 영역 회전: 도화살 1차 노출 (이후 페이지엔 다른 영역)

[2번 첫인상에서 생기는 오해] 반전형
- 1차 인자: 일주 60갑자·일주 외형·일간 음양
- 풀이: 첫 1초 외형 → 오해 받는 결 → 진짜 결 (양면 대비 = 겉결 vs 속결)

[3번 호감이 생기면 내가 보내는 신호] 표준형
- 1차 인자: 식상·도화살
- 풀이: 무의식적 신호 (말이 늘어남·시선 머무름·먼저 다가감)

[4번 사랑하면 달라지는 태도] 반전형
- 1차 인자: 시간축·재성/관성
- 풀이: 평소 → 사랑할 때 두 결 대비 (E 시간 변화 + D 양면)

[5번 내가 다가가는 방식] 표준형
- 1차 인자: 식상·재성·신강 + 비겁
- 풀이: 직진·신중·돌다리 — 본인 행동 스타일 단언

[6번 끌리는 사람과 잘 맞는 사람] 대비형
- 1차 인자: 편관/편재(끌림) vs 정관/정재(적합)
- 풀이: 두 결 차이 단언 + 매트릭스 본인 행 백그라운드

[7번 사랑이 들어오는 시기] 시기형
- 1차 인자: 대운·세운·역마살·관성 진입
- 풀이: 가까운 시점 단언 (E 시간 변화 메인)

[8번 솔로 탈출 가이드] 시기형+행동
- 1차 인자: 대운·세운+역마+관성 + 행동 가이드
- 풀이: 만남 자리 + 본인이 해야 할 행동 3단계

[9번 올해 연애에서 조심할 흐름] 경고형+시기형
- 1차 인자: 2026 세운 + 기신
- 풀이: 상반기/하반기 결 + 핵심 분기 + 조심 가이드

[10번 내게 맞는 만남 방식] 대비형(3분류)
- 1차 인자: 화개살·도화살·홍염살·인성
- 풀이: 자연스러운 만남/주선된 만남/약속된 자리 — 본인에게 맞는 방식
- 어휘 금지: 자만추·인만추·결정사 단어 X (양반사주 어휘)
- 대체: "자연스러운 만남"·"주선된 만남"·"약속된 자리"

[11번 내 짝꿍 미리 보기] 후킹형
- 1차 인자: 부족 오행·약한 십성·일지
- 풀이: 남자 캐스케이드 1~6 매칭 → "OO상의 결" 단언

[12번 좋은 사람을 알아보는 신호] 표준형
- 1차 인자: 천을귀인·신살·역마살
- 풀이: 만남 임박 신호들 (일상 신호 3가지)

[13번 그 사람과 가까워지는 한 수] 표준형+행동
- 1차 인자: 식상·재성·일간 표현
- 풀이: 본인이 해야 할 결정적 행동 (매트릭스 본인 칸 백그라운드)

[14번 결혼까지 이어지는 관계의 조건] 시기형
- 1차 인자: 관성/재성 대운·일주 합·일지 합
- 풀이: 짝꿍 결합 후 결혼 자리 (매트릭스 본인 칸 톤 백그라운드)

[15번 자꾸 끌리는 위험한 유형] 경고형
- 1차 인자: 정관·편관 + 기신
- 풀이: 끌리지만 내 결 깎는 사람 + 시점 1~2문장 흡수
- 영역: 사람 유형 (시점은 보조)

[16번 반복되는 연애 패턴] 경고형
- 1차 인자: 약한 십성·일지·기신 작용
- 풀이: 본인 빈자리 + 반복 결말

[17번 그 패턴에서 벗어나는 방법] 경고형+해법
- 1차 인자: 용신·인성·희신 보강
- 풀이: 회복 행동 3단계

[18번 나도 모르게 풍기는 매력] 비유 강조형
- 1차 인자: 도화살·홍염살 위치
- 풀이: 외모형/관능형/매력형 분류 — 감춰진 매력 정체

[19번 내가 원하는 사랑의 온도] 표준형
- 1차 인자: 욕신살·일지 합·일간 음양
- 풀이: 본능 4 유형 (주도/수용/균형/표현)

[20번 둘 사이가 깊어지는 순간] 비유 강조형
- 1차 인자: 일지·용신·일간 음양
- 풀이: 시간·공간 (매트릭스 본인 칸 친밀 톤 백그라운드)

[21번 마지막 편지] 편지형+후킹 종합
- 1차 인자: 일간·용신 자연 비유
- 풀이: 두 캐릭터 종합 + 시적 축복

5. 6슬롯 짜임 룰 (paljawon 표준)
================================================================

[① Lead] - 페이지 전체 결론 두괄식 박음
- 톤: 단언 1~2문장
- 길이: 30~60자
- 담을 것: 결론 1줄 + 부연 1줄
- 담지 말 것: 한자 인자 X, 비유 X

[② 근거] - Lead 결론을 사주 인자로 뒷받침
- 톤: 정리체, 자연 흐름
- 길이: 100~140자
- 담을 것: 핵심 인자 2~3개를 한 단락에 자연 인용
- 담지 말 것: 인자별 단락 분리 X, 비유 X

[③ 비유] - 결론을 자연·사물 비유로 강화
- 톤: "마치 ~처럼" 비유체
- 길이: 70~100자
- 담을 것: 자연·사물 1개 비유
- 담지 말 것: 사람 비유 X, 일상 장면 X

[④ 실생활] - 사주 결론이 실제 일상에서 어떻게 보이는지
- 톤: 묘사·서사체
- 길이: 130~180자
- 담을 것: 일상 자리 2~3장면 (대명사 사용 — 룰 24)
- 담지 말 것: 사주 한자 재인용 X, 비유 X

[⑤ 이면] - 표면 결과 다른 한 면 (양면 대비 슬롯)
- 톤: 짧은 반전 ("다만 ~")
- 길이: 60~80자
- 담을 것: 다층화 1단락 (V1 솔로 양면 8축 중 1개 — 룰 26)
- 담지 말 것: 결론 뒤집기 X

[⑥ Close] - 결론 재단언 + 다음 페이지 미끼
- 톤: 시적 단언 + 미끼
- 길이: 50~70자
- 담을 것: Lead 변주 + 호기심 화살표
- 담지 말 것: Lead와 같은 표현 X, 새 정보 X

총 약 440~630자 / 6단락

6. 변형 패턴 8종 + 패턴별 슬롯 순서

[1. 후킹형] - 캐릭터 매칭 직접 노출
① Lead(캐릭터 매칭 단언) → ② 근거 → ③ 비유 → ④ 실생활 → ⑤ 이면 → ⑥ Close

[7. 경고형] - 위험·해법 슬롯 추가
① → ② 위험 → ② 근거 → ④ → ⑤ 어떻게 벗어나나 → ⑥
적용: 9·15·16·17번

9. 인자 영역 회전 매트릭스 (룰 23 핵심)
================================================================

핵심 원리: 같은 인자가 매번 다른 영역에서 다른 결의 풀이로 작동
청월당 갑목 15회 노출 안 지루한 이유 = 영역 회전
※ 페이지 번호는 모두 21 소제목 시스템 기준

[주요 인자별 회전 매트릭스]

[도화살(桃花煞)] - 4페이지 회전
- 1번 내 매력은? → 평상시 매력 영역 → "은은하게 빛나는 결"
- 3번 호감이 생기면 보내는 신호 → 신호 발산 영역 → "도화가 켜지는 그 한 순간"
- 7번 사랑이 들어오는 시기 → 시기 자극 영역 → "도화 대운에 결이 다가오는 자리"
- 18번 풍기는 매력 → 감춰진 매력 영역 → "안쪽에서만 비치는 결"

[홍염살(紅艶煞)] - 2페이지 회전
- 1번 내 매력은? → 매력 영역 → "결의 흐름"
- 18번 풍기는 매력 → 관능 영역 → "결의 끌림"

[식상(食傷)] - 3페이지 회전
- 3번 호감 신호 → 신호 표현 영역 → "솔직히 말이 늘어나는 결"
- 5번 다가가는 방식 → 다가감 동작 영역 → "먼저 말 거는 결"
- 13번 가까워지는 한 수 → 행동 가이드 영역 → "표현으로 잡는 결"

[비겁(比劫)] - 3페이지 회전
- 5번 다가가는 방식 → 본인 페이스 영역 → "본인 결로 밀어가는"
- 17번 패턴에서 벗어나는 방법 → 본인 정체 회복 영역 → "본인 결을 다시 잡는"
- 19번 사랑 온도 → 본인 능동성 영역 → "온도를 본인이 만드는"

[정관·편관(官星)] - 3페이지 회전
- 6번 끌리는 vs 잘 맞는 → 적합·끌림 두 결 영역 → "정관 적합·편관 끌림"
- 12번 좋은 사람 신호 → 신뢰 신호 영역 → "관성 진입 신호"
- 15번 위험 유형 → 위험 통제 영역 → "통제하려는 결"

[정재·편재(財星)] - 3페이지 회전
- 4번 사랑하면 달라지는 태도 → 시간축 변화 영역 → "현실 감각의 변화"
- 6번 끌리는 vs 잘 맞는 → 적합 영역 → "정재 적합"
- 14번 결혼 조건 → 결혼 대운 영역 → "관성/재성 강한 시기"

[천을귀인(天乙貴人)] - 2페이지 회전
- 8번 솔로 탈출 가이드 → 만남 자리 영역 → "천을 방위 자리"
- 12번 좋은 사람 신호 → 만남 신호 영역 → "귀인 진입 일상 신호"

[역마살(驛馬煞)] - 3페이지 회전
- 7번 사랑이 들어오는 시기 → 시기 활동 영역 → "역마 진입 시기"
- 8번 솔로 탈출 가이드 → 만남 환경 영역 → "역마 활동 자리"
- 9번 올해 조심할 흐름 → 활동 변동 영역 → "역마 + 2026 흐름"

[일지(日支) 합] - 2페이지 회전
- 14번 결혼 조건 → 일주·일지 합 시기 영역 → "결혼 자리"
- 20번 깊어지는 순간 → 친밀 결합 영역 → "결의 결합 온도"

[욕신살(浴神煞)] - 1페이지 노출
- 19번 사랑 온도 → 본능 깨어남 영역

[부족 오행] - 1페이지 노출
- 11번 짝꿍 미리 보기 → 짝꿍이 채울 결 영역

[약한 십성] - 2페이지 회전
- 16번 반복되는 연애 패턴 → 빈자리 영역 → "반복 원인"
- 17번 패턴 벗어나는 방법 → 회복 영역 → "빈자리 채움"

[용신(用神)·희신(喜神)] - 3페이지 회전
- 12번 좋은 사람 신호 → 만남 방위 영역
- 13번 가까워지는 한 수 → 행동 보강 영역
- 17번 패턴 벗어나는 방법 → 회복 행동 영역

[기신(忌神)] - 2페이지 회전
- 9번 올해 조심할 흐름 → 올해 위험 시기 영역
- 15번 위험 유형 → 깎는 결의 사람 영역 + 시점 1~2문장 흡수

[일주 외형·일주 겉/속] - 1페이지 노출
- 2번 첫인상에서 생기는 오해 → 외형·첫 1초·겉속 양면 영역

[일간 음양] - 다수 페이지
- 18·19·20번에서 능동/수동 본능 영역

[격국] - 사용 금지 (코드 v2-principles 위반)
- 격국명·격국 분류 본문 노출 절대 X
- 풀이 로직에서는 사용 가능

[원칙]
- 같은 인자 등장 시 → 영역(매력·신호·시기·짝꿍·반복·해법 등) 확인
- 같은 영역 반복 X. 영역 회전이면 OK
- 인자명 한자 노출은 매 페이지 1~2회 (룰 7)

12. V1 솔로 양면 대비 8축 (룰 26)
================================================================

V1 솔로라도 양면 대비 가능. 본인 안 두 결.

[축 1. 평소 vs 사랑할 때] (시간 축)
적용: 4번 사랑하면 달라지는 태도
예: "평소엔 신중한 결 → 사랑할 때 직진의 결"

[축 2. 겉결 vs 속결] (공간 축)
적용: 2번 첫인상에서 생기는 오해
예: "남들이 보는 차분한 결 vs 가까이 가야 보이는 활기"

[축 3. 끌리는 결 vs 잘 맞는 결] (편관/편재 vs 정관/정재)
적용: 6번 끌리는 사람 vs 잘 맞는 사람
예: "마음이 흔들리는 결 vs 결혼해도 안정된 결"

[축 4. 강한 결 vs 빈자리] (강·약)
적용: 11번 내 짝꿍 미리 보기 (짝꿍이 채울 결)
예: "본인이 단단한 영역 vs 짝꿍이 채울 영역"

[축 5. 사랑 들어오는 시기 vs 흔들리는 시기] (시기 양면)
적용: 9번 올해 조심할 흐름
예: "다가오는 시기 vs 조심할 시기"

[축 6. 진짜 인연 vs 가짜 인연] (좋은 vs 위험)
적용: 12·15번
예: "결을 채우는 사람 vs 결을 깎는 사람"

[축 7. 드러나는 매력 vs 감춰진 매력] (외향·내향)
적용: 1·18번
예: "평상시 빛나는 결 vs 친밀의 자리에서만 켜지는 결"

[축 8. 본인이 보내는 신호 vs 짝꿍이 보내는 신호] (주고받음)
적용: 3·12번
예: "내가 자연스럽게 보내는 결 vs 그 사람이 보내는 결"

[원칙]
- 페이지마다 양면 1축 선택 (이면 슬롯에 강제 적용)
- 두 결을 대비하되 한쪽이 나쁘다 X

13. 단락 간 연결어미 (룰 6 상세) + 어색 연결 금지 예시
================================================================

[위치별 권장 연결어미]

위치 ① → ② (인과형):
- "그 결의 바탕에는 ~"
- "그 결의 근거는 ~"
- "이러한 결을 지니신 이유는 ~"

위치 ① → ② (1차 인자 회수 시):
- "앞서 말씀드린 OO 결을 떠올려 보세요"
- "앞서 짚어드린 결을 이번엔 ○○ 자리에서 보면 ~"

위치 ② 안 인자 사이 (첨가형):
- "여기에 ~까지 함께 자리해"
- "그리고 ~이 더해져"
- "이와 함께 ~이 놓여 있어"

위치 ② → ③ (비유 도입형):
- "이 결을 자연에 빗대보면 ~"
- "비유하자면 ~"
- "마치 ~처럼"

위치 ③ → ④ (장면 전환형):
- "이 결이 가장 잘 보이는 자리는 ~"
- "그 모습은 일상에서 이렇게 켜져요"
- "예를 들어 ~ 자리에서는"

위치 ④ → ⑤ (전환·반전형):
- "다만 ~"
- "그렇다고 ~만은 아니에요"
- "한편으로는 ~"
- "안쪽 결을 들여다보면 ~"

위치 ⑤ → ⑥ (요약·재단언형):
- "그래서 이OO님은,"
- "결국 ~"
- "한 마디로 말씀드리면 ~"
- "이렇게 정리하면 ~"

위치 ⑥ 안 미끼 (호기심 유발형):
- "다만 ~ 순간에는 또 다른 결이 켜져요 →"
- "이 결은 다음 자리에서 보여드릴게요 →"

[★ 어색 연결 금지 예시 (사용자 검출)]

금지 1. "다만"이 ④→⑤가 아닌 ⑤→⑥에 잘못 들어감
- 어색 예시: "...깊어지는 사랑을 경험할 수 있습니다. 다만, 끌리는 감정만을 좇다 보면..."
- 원인: "다만"은 ④→⑤(전환·반전) 위치 전용
- 해결: ⑤→⑥엔 "그래서·결국" 사용

금지 2. "그러나·하지만" 너무 강한 부정 전환
- 어색 예시: 긍정 단언 직후 강한 부정 전환
- 해결: "한편으로는·다만"으로 톤 부드럽게

금지 3. 단락 흐름과 안 맞는 연결어미
- 어색 예시: ②→③에서 "다만"이 들어가면 비유 도입 흐름 깨짐
- 해결: 위치별 권장 어미 표 준수

금지 4. 카페·동호회·여행지 등 구체 장소 반복 (룰 24 위반)
- 어색 예시: "카페에서 처음 만났을 때..." 여러 페이지 반복
- 해결: 룰 24 대명사 풀로 대체 ("처음 마주한 자리·낯선 자리")

금지 5. "마치 카페에서..." 행동 비유 반복
- 어색 예시: 청월당 60p 분석에서 "마치 카페·등불·돌다리" 비유 풀 협소
- 해결: 룰 24 + 룰 25 결합 (대명사 + 감각 디테일)

[검수 단계 점검]
- LLM judge가 위 5가지 어색 연결 자동 검출
- 자동 재작성 트리거: "다만"이 ⑤→⑥에 있으면 "그래서·결국"으로 치환

```
일간(日干)이 한낮의 햇살처럼 자리해 있고, 월덕귀인(月德貴人)이
```

```
이OO님의 사랑이 들어오는 자리는, 가까운 ○○세 무렵으로

```

[고정 해설 문구]

용신: 내 결을 살리는 핵심 기운

- 희신 카드: 제목 "희신" / 해설 "용신이 잘 자라도록 받쳐주는 기운" / 역할 "용신이 힘을 내도록 도와주는 보조 방향"

[전체 원칙]
1. 용신, 희신, 기신은 새 챕터로 만들지 않는다
2. 용신이 나오는 흐름에서는 희신과 기신도 필요할 때 함께 다룬다
3. 희신은 용신을 받쳐주는 방향으로 쓴다
4. 기신은 과해지면 흐름을 흔드는 방향으로 쓴다
5. 매번 길게 반복하지 않는다
6. 문장 수는 고정하지 않는다
7. 연애 장면에 억지로 연결하지 않는다
8. 오행명만 던지지 말고 그 파트에서 왜 필요한지 알 수 있게 쓴다
9. "피해야 한다", "나쁘다", "망친다" 같은 불안 조장 표현 X
10. 기본 축은 "살린다 / 받쳐준다 / 흔든다"로 통일

[본문 삽입 위치 (21 소제목 기준)]
- 6번 끌리는 vs 잘 맞는: 용신 + 희신 + 기신 (적합/끌림/위험)
- 9번 올해 조심할 흐름: 기신 (위험 시기)
- 12번 좋은 사람 신호: 용신·희신 (만남 방위)
- 13번 가까워지는 한 수: 용신 + 희신 (행동 보강)
- 15번 자꾸 끌리는 위험한 유형: 기신 (깎는 결의 사람)
- 16번 반복되는 연애 패턴: 기신 작용
- 17번 패턴 벗어나는 방법: 용신 + 희신 (회복) — 가장 균형
- 21번 마지막 편지: 종합 한 줄
