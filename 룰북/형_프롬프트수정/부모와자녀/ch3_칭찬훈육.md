## 3장 — 우리 아이 칭찬하고 혼내는 법

### 화났을 때 입을 닫을까, 폭발할까
[메인: 식상 / 서브: 비겁·신강신약·일주·신살(양인·괴강·고란)]
[시그너처: 두갈래 대비형] — "안으로 쌓임 vs 바로 흘러나옴"을 대비하되, 결론은 감정 반응 방식에만 둔다. 환경·칭찬·금지어 처방까지 여기서 반복하지 말 것.
구성: ① 단정 — "${cnh}은 화가 났을 때 [밖으로 표현하기보다 안으로 쌓이는 / 그때그때 표정과 말로 흘러나오는] 아이예요." → ② 식상 + 신강신약 + 비겁 + 일주·신살(양인 = 급한 분출 / 고란 = 닫힘) 결합. 식상 0이면 "감정을 먼저 안에서 정리하는 결" 양면 풀이. → ③ 누적형이면 "아무렇지 않아 보이다가 늦게 터지는 장면", 즉시형이면 "작은 자극에도 바로 얼굴·목소리에 드러나는 장면" 1개. → ④ 끝문장은 반응 판별법으로 마무리: "그래서 ${cnh}의 화는 말보다 먼저 [침묵/표정/몸짓/목소리]에서 읽어야 합니다." 안정·지지 권고로 끝내지 말 것.

### 아이 감정이 가라앉는 환경
[메인: 오행 / 서브: 일주·신강신약·기신 오행·12운성]
[시그너처: 처방전형 — 환경 권장이 산문 안에 자연 녹음. 박스·5축 리스트·이모지 절대 X.]
구성: ① 단정 — "${cnh}은 [빛·공간·소리·온도 중 자녀 결에 맞는 1~2축]이 맞을 때 감정의 속도가 먼저 느려지는 아이예요." → ② 강한 오행·약한 오행·기신·12운성 결합으로 어떤 자극을 줄이고 어떤 감각을 남겨야 하는지 설명. "정돈/고요/따뜻함" 같은 추상어만 쓰지 말고, 조명 밝기·소리 크기·자리 이동·손으로 하는 활동 중 2개를 구체화. → ③ 야단 직후 설득 금지. 먼저 자리·소리·몸의 속도를 바꾼 뒤 대화로 넘어가는 순서를 묘사. → ④ 끝문장은 회복 순서로 마무리: "이 아이에게는 말보다 먼저 [공간 → 몸 → 대화]의 순서가 필요합니다." 칭찬·비교 금지 내용 반복 X.

### 마음 열리는 칭찬
[메인: 인성 / 서브: 식상·일주·용신·천을귀인]
[시그너처: 칭찬 문장 처방형] — "무엇을 칭찬해야 하는가"에만 집중. 감정 안정·금지어·훈육 대화법 반복 X.
구성: ① 단정 — "${cnh}은 [결과보다 과정 / 능력보다 노력 / 행동보다 마음 / 고유한 시도]를 알아봐줄 때 반응하는 아이예요." → ② 인성(정인·편인) + 식상 + 일주 + 용신·천을귀인 결합. 인성 0이면 "설명보다 직접 확인받는 결"로 양면 풀이. → ③ 자녀 결에 맞는 칭찬 멘트 1~2개를 실제 문장으로 제시하고, 하나만 [[ ]] 강조. 예시는 짧고 부모가 그대로 말할 수 있어야 함. → ④ 끝문장은 칭찬의 초점으로 마무리: "${cnh}에게 칭찬은 '잘했다'보다 '[노력/마음/시도/끝맺음]을 봤다'는 신호일 때 오래 남습니다."

### ${ah.ch3_lie}
[메인: 일주 / 서브: 관성·인성·신살·합·충]
[시그너처: 동기 추적형] — 표면(${ah.ch3_lieContext} 한 행동)이 아니라 "왜 그 행동이 나왔는가"와 "어떤 순서로 물어야 하는가"만 다룬다. 가상 대화 박스 절대 X.
구성: ① 단정 — "${cnh}은 ${ah.ch3_lieContext} 자체가 목적이 아니라, [실망시키고 싶지 않은 마음 / 혼나는 게 두려운 마음 / 자유를 지키려는 마음 / 부담을 잠시 내려놓고 싶은 마음]에서 ${ah.ch3_lieContext}을 하는 아이예요." (영유아면 거짓말 어휘 X) → ② 일주 + 관성 강/약 + 인성 + 신살 + 합·충 결합으로 동기 결정. → ③ 부모 질문 순서를 산문으로 제시: 사실 확인보다 몸 상태·상황·마음 순서. 직접 인용은 1문장만 허용. → ④ 끝문장은 질문법으로 마무리: "따져 묻기보다, 먼저 [무슨 일이 있었는지]를 말할 자리를 열 때 ${ah.ch3_lieContext}의 필요가 줄어듭니다." 안정·단단 결말 반복 X.

### 이 아이가 무너지는 자극
[메인: 기신 / 서브: 약한 오행·신강신약·신살·12운성]
[시그너처: 금지어 판별형] — 기신(忌神) 한자 1회 명시 + 금지어 직접 인용 + "행동만 짚되 인격은 보호". 신호등 박스·이모지 절대 X.
구성: ① 단정 — "${cnh}은 [차가운 비교 / 일방적인 재촉 / 자기 페이스 무시 / 공개적인 지적] 같은 자극에서 가장 빨리 움츠러드는 아이예요." → ② 기신·약한 오행·신강신약·신살·12운성 결합으로 왜 그 자극이 크게 들어오는지 설명. → ③ 금지어 직접 인용 1~2개. "왜 너는 못해?", "다른 애들은 다 하는데", "빨리빨리 좀 해", "너는 왜 이런 애가 됐어" 중 자녀 결에 맞는 것만 선택하고, 그 말이 행동이 아니라 존재 평가로 들리는 지점을 짚는다. → ④ 끝문장은 훈육 기준으로 마무리: "혼낼 때는 [행동 한 가지]만 짚고, 성격·비교·미래 단정은 문장 밖에 남겨야 합니다."
