# 형에게 — 부모자녀궁합 프롬프트 수정 패키지

부모자녀궁합(자도인) 프롬프트를 챕터별 메모로 쪼개놨어. **형이 본문 스펙만 고쳐서 돌려주면, 재우가 route.ts에 그대로 교체(복붙)함.** 그래서 아래 4가지만 안 건드리면 돼.

---

## ⛔ 절대 건드리지 말 것 4가지

### 1. `${...}` 변수 — 그대로 보존
챕터 본문은 `app/api/generate/route.ts` 안의 **JS 템플릿 리터럴**이야. 안에 변수가 박혀 있음:
- `${cnh}` — 자녀 호칭 (예: 이금희양, 김도현군)
- `${ah.ch2_alone}` 등 `${ah.xxx}` — 연령별로 자동 바뀌는 소제목 헤더 (영유아/학령기 분기)
- `${_ch2TraitsBlock}`, `${ch2ChartFacts}` 등 — 사주 데이터 자동 주입 지점
- `${cf_sinsalNames}` — 자녀 보유 신살 이름
- `${ch6Title}`, `${ch6FirstSubtitle}`, `${ch6TrioMoment}`, `${parentsLabel}` — ch6 부모 입력 동적값
- `${hasMom && hasDad ? "..." : "..."}` — ch6 부모 조합 분기

→ 이걸 평범한 텍스트로 보고 풀어쓰거나 지우면 코드가 깨짐. **변수는 위치·철자 그대로**.

### 2. 헤더 줄 — 한 글자도 변경 금지
- `## N장 — ...` (챕터 헤더)
- `### 소제목` (소제목 헤더)

이 줄들은 클라이언트가 본문을 슬라이드에 매핑하는 **매칭 키**야. 한 자라도 바뀌면 그 소제목 본문이 화면에 "(본문이 아직 없어요)"로 떠. **헤더 줄은 고정, 그 아래 스펙만 수정.**
(`### ${ah.ch2_alone}` 처럼 변수 헤더도 마찬가지 — 변수 그대로 둬.)

### 3. 백틱 이스케이프
템플릿 리터럴 안이라 본문에 백틱(`` ` ``)을 literal로 쓰려면 `` \` ``로 이스케이프해야 함. 현재 `` \`[[ ]]\` ``, `` \`## 1장 …\` `` 식으로 이미 박혀 있음. **새로 백틱 쓰지 말고, 있는 이스케이프 건드리지 마.** `${`도 변수 아닌데 literal로 쓰면 안 됨.

### 4. 공용 출력 룰 vs 소제목 스펙 — 충돌 금지
- ch3·ch4·ch5는 챕터 맨 위에 **[★ 공용 출력 룰]** 블록이 있고, 그게 그 챕터 **모든 소제목에 강제 적용**됨.
- 소제목 하나만 톤 바꿈 → 그 `### ` 블록만 수정.
- 챕터 전체 톤·분량·금지패턴 바꿈 → 공용 출력 룰 수정.
- 둘이 안 맞으면 안 됨. (예: 공용 룰 "450~600자"인데 소제목에 "380~450자" 적으면 LLM 혼란)

## 📐 모든 챕터가 따르는 [V2 절대 원칙 A~L] — 참고용 (수정 대상 아님)

이건 시스템 프롬프트에 박힌 공통 룰이라 챕터 메모엔 안 들어있지만, 형이 본문 스펙 고칠 때 이 톤 안에서 움직여야 함:

```text
A. 사주 용어 노출 룰 — 메인 인자 한자병기 1회만 허용("비겁(比劫)은…"), 이후 부모 언어로. 격국은 V2에서 완전 삭제. 신살명 한자병기 1회 허용.

B. ★ 시그너처 톤 다양성 (가장 중요) — 5단락 동일 템플릿 절대 금지. 각 소제목은 자기 시그너처(공식형/두 갈래 비교/단정+일화/시간 흐름/관찰자 시점/처방전/신호등 진단/케이스 분기 등)를 가짐. 한 챕터 안 5 sub 시그너처가 모두 달라야 함.

C. ★ "대충" 느낌 금지 — 깊이 사수. 짧은 시그너처도 350~450자, 긴 건 500~700자. 단정·결론만 쓰고 끝 금지 — 사주 인자 결합 메커니즘 본문 등장. 5인자 결합 강제(메인+서브 모두). 일반론 금지.

D. 메인 인자 강도 분기 — 강:두드러지는 결 / 중:양면 풀이 / 약:옅은 결+다른 결이 채움 / 0:양면 풀이 강제 (비겁0=협력형, 식상0=신중한 결, 재성0=의미 집중, 관성0=자유로운 길, 인성0=직관 실전형). "○○이 약해서 보완" 패턴 금지.

E. 아이 묘사 어조 보호 — "무너지는/폭발하는/약한 아이" 금지. 양면 모두 긍정적으로.

F. 자녀 호칭 — ${d.childName} 단독 금지. 매번 ${cnh}. sub당 1~2회.

G. 부모 호명 — "어머님·아버님" sub당 1~2회.

H. 단정·정량·균형 표현 금지 — "균형/안정/조화"는 실제 분포가 균형일 때만.

I. 사춘기·자아 형성 → "결이 변하는 시기/스스로 자라는 시기"로.

J. 마크다운 헤더 정확 출력 — 헤더 텍스트 한 자도 변경 금지 (시스템 매칭 키).

K. 6장 어머님·아버님 어휘 분리 — 어머님:식탁·정돈·실내·따뜻한 손길 / 아버님:야외·운동·만들기·단단한 어깨. 둘 다 긍정적.

L. ★ 가독성 강조 1종만 — 별표/물결/백틱 등 다른 마크다운 강조 금지. 쓸 수 있는 단 하나: [[텍스트]] (골드 강조). 소제목 본문 전체에서 1~2회만, 10자 이내 키워드에만. 한 단락에 1개.

(그 외 G14 풀 대명사 단독 도입 금지, G18 호칭 룰, G19 도미넌트 불명확 시 양면 풀이 — 디테일 룰 다수. 필요하면 재우한테 요청.)
```

## 📦 챕터 메모 목록

| 메모 | 챕터 | 소제목 수 | route.ts 라인 |
|---|---|---|---|
| `ch1_outro.md` | 1장 도입(헤더만) + outro 마지막 당부 | — | L3123 / L3306 |
| `ch2_학습.md` | 2장 우리 아이는 어떻게 공부할까 | 5 | L3128~3159 |
| `ch3_칭찬훈육.md` | 3장 우리 아이 칭찬하고 혼내는 법 | 5 (+공용룰) | L3161~3201 |
| `ch4_친구.md` | 4장 친구 사이 우리 아이 | 4 (+공용룰) | L3203~3239 |
| `ch5_빛나는자리.md` | 5장 우리 아이는 무엇으로 빛날까 | 5 (+공용룰) | L3241~3280 |
| `ch6_가족.md` | 6장 엄마아빠와 우리 셋의 결 | 3 | L3282~3304 |

각 메모에: ① 그 챕터에 나오는 변수 표 ② 고정 헤더 표 ③ **현재 프롬프트 전문**(코드블록) ④ 교체 위치.
형은 코드블록 안의 본문 스펙만 고쳐서 돌려주면 됨.

## 🔄 작업 흐름

1. 재우가 형한테 이 폴더(또는 특정 챕터 메모)를 줌
2. 형이 코드블록 안 본문 스펙 수정 (변수·헤더·백틱 보존)
3. 형이 수정본 돌려줌
4. 재우가 route.ts 해당 라인에 그대로 교체
5. `npx vercel --prod --yes` 배포 → `node saju_test.js parent-child preset1` 로 회귀 확인
