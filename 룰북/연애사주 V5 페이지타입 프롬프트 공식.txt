연애사주 V5 페이지타입 프롬프트 공식
작성일: 2026-05-12

목적
- 001~069 레퍼런스를 "결과물 역설계" 관점으로 분석해, 홍실 전용 페이지 타입과 프롬프트 공식을 정의한다.
- V5 구현 시 이 문서를 기준으로 프롬프트를 쪼개고, 각 페이지가 맡는 역할을 고정한다.

공통 출력 원칙
1. 사주 근거가 있는 풀이처럼 느껴져야 한다.
2. 초반에는 한자와 사주 인자를 보여주되, 바로 쉬운 말로 풀어준다.
3. 중반 이후에는 전문용어를 반복하지 않고, 이미 본 근거를 생활 장면으로 적용한다.
4. 같은 인자가 다시 쓰이면 같은 결론을 반복하지 말고 깊이를 바꾼다.
5. 모든 본문은 결론이 먼저 나오고, 근거와 장면이 따라온다.

페이지 타입 01. 안내자 진입형
- 목적: 사용자를 상담 흐름으로 초대한다.
- 사용 위치: 첫 페이지
- 사주 근거: 없음
- 한자/전문용어: 금지
- 구조:
  1) 이름 호명
  2) 지금 찾아온 이유를 받아줌
  3) 사주 속 힌트를 함께 보겠다고 안내
  4) 앞으로 표와 해석을 차례로 볼 것이라고 예고
- 프롬프트 공식:
  "${name}님이 이 풀이를 읽는 이유를 다정하게 받아주고, 앞으로 사주표를 먼저 보고 그다음 연애 해석으로 들어간다고 안내하라."

페이지 타입 02. 사주 원국 교육형
- 목적: 사주표를 보는 법을 알려준다.
- 사용 위치: 초반 안내부
- 사주 근거: 시주, 일주, 월주, 년주, 천간, 지지
- 한자/전문용어: 허용. 단, 바로 쉬운 풀이 필수
- 구조:
  1) 사주팔자가 무엇인지 설명
  2) 네 기둥과 여덟 글자 설명
  3) 윗글자=천간, 아랫글자=지지 설명
  4) 일주/일간이 왜 중요한지 설명
  5) 이후 풀이의 기준표라고 연결
- 프롬프트 공식:
  "사주표를 처음 보는 사람에게, 이 표가 해석의 근거 지도라는 점을 설명하라. 각 용어는 한 번만 쓰고 바로 쉬운 말로 풀어라."

페이지 타입 03. 내 사주표 근거 연결형
- 목적: 개인 사주표와 앞으로 나올 풀이를 연결한다.
- 사용 위치: 원국표 바로 아래 또는 다음 페이지
- 사주 근거: 일간, 일지, 월지, 강한 오행, 약한 오행
- 구조:
  1) "이 표에서 가장 먼저 볼 자리는..."으로 시작
  2) 일간/일지/월지 등 핵심 자리 2~4개 선택
  3) 각 자리가 연애에서 무엇을 보는지 설명
  4) "이제 이 근거를 연애 장면으로 풀어본다"고 연결
- 프롬프트 공식:
  "개인 사주표에서 이번 연애사주에 쓸 핵심 근거 2~4개를 고르고, 각 근거가 연애에서 무엇을 판단하는 자리인지 초보자용으로 설명하라."

페이지 타입 04. 십성 역할 번역형
- 목적: 비견/겁재/식신/상관 등 어려운 단어를 초보자에게 풀어준다.
- 사용 위치: 초반 안내부
- 사주 근거: 십성 전체 또는 개인에게 두드러지는 십성
- 구조:
  1) 십성은 관계에서 작동하는 역할이라고 설명
  2) 비겁/식상/재성/관성/인성을 쉬운 말로 번역
  3) 개인에게 강한/약한 역할 1~2개를 짚음
  4) 본문에서는 이 용어를 반복하지 않겠다고 자연스럽게 연결
- 프롬프트 공식:
  "십성을 어려운 명리 용어가 아니라 관계 안에서 나타나는 역할 언어로 번역하라. 용어 노출보다 쉬운 역할 설명을 우선하라."

페이지 타입 05. 오행 균형 시각형
- 목적: 오행이 많고 적은 것을 눈으로 이해시킨다.
- 사용 위치: 초반 안내부
- 사주 근거: 목/화/토/금/수 비율
- 구조:
  1) 가장 강한 오행과 약한 오행을 말함
  2) 과다/적정/부족은 낙인이 아니라 성향의 방향이라고 설명
  3) 연애에서는 표현, 안정, 속도, 기준, 감정 흐름으로 나타난다고 풀어줌
- 프롬프트 공식:
  "오행 비율을 숫자 나열로 쓰지 말고, 강한 기운과 약한 기운이 연애에서 어떤 생활 장면으로 나타나는지 설명하라."

페이지 타입 06. 용신/희신/기신 보조 설명형
- 목적: 용신만 말하지 않고 희신/기신을 함께 이해시킨다.
- 사용 위치: 초반 안내부 또는 보완 전략 파트
- 사주 근거: 용신, 희신, 기신
- 고정 풀이:
  - 용신: 내 결을 살리는 핵심 기운
  - 희신: 용신이 잘 자라도록 받쳐주는 기운
  - 기신: 과해지면 흐름을 흔드는 기운
- 구조:
  1) 세 기운을 짧게 구분
  2) 연애에서 각각 어떻게 드러나는지 설명
  3) 억지로 길게 반복하지 않음
- 프롬프트 공식:
  "용신, 희신, 기신을 한 번에 구분하되, 점수나 절대 운명처럼 말하지 말고 관계에서 도움이 되는 방향과 조심할 흐름으로 설명하라."

페이지 타입 07. 근거 제시형 본문
- 목적: AI가 지어낸 말이 아니라 사주표에서 나온 해석처럼 느끼게 한다.
- 사용 위치: 본문 초입, 특히 "내 매력은?"
- 사주 근거: 해당 풀이에 필요한 핵심 근거 2~4개
- 구조:
  1) 결론: 독자가 바로 이해할 수 있는 매력/성향 한 줄
  2) 근거: 일간, 일지, 월지, 오행, 십성 등 실제 근거 2~4개
  3) 쉬운 번역: 각 근거가 생활어로 무엇을 뜻하는지
  4) 연애 장면: 처음 만남, 대화, 호감 신호, 관계 속 모습
  5) 이면: 장점이 과해질 때의 주의점
- 프롬프트 공식:
  "먼저 결론을 말하고, 그 결론이 어떤 사주 자리에서 나온 것인지 근거를 붙여라. 근거는 2~4개만 쓰고, 바로 쉬운 말로 번역한 뒤 실제 연애 장면으로 연결하라."

페이지 타입 08. 근거 재사용 생활화형
- 목적: 같은 인자를 반복하지 않고 깊이를 바꿔 말한다.
- 사용 위치: 본문 중반 이후
- 사주 근거: 앞에서 공개한 근거를 내부 참조
- 한자/전문용어: 금지
- 구조:
  1) 앞 근거를 다시 말하지 않고 바로 장면으로 시작
  2) 이번 페이지의 질문 영역만 다룸
  3) 첫인상/호감/사랑태도/갈등/회복 중 하나만 선택
  4) 다른 페이지와 결론이 겹치면 더 깊은 행동/감정으로 이동
- 프롬프트 공식:
  "앞에서 공개한 사주 근거를 다시 설명하지 말고, 이번 페이지 질문에 맞는 생활 장면으로만 적용하라. 같은 결론을 반복하지 말고 더 깊은 행동이나 감정으로 내려가라."

페이지 타입 09. 비교표형
- 목적: 긴 본문을 쉬게 하고 실전 판단을 돕는다.
- 사용 위치: 중간 요약 페이지
- 예시:
  - 내가 끌리는 사람 vs 나에게 끌리는 사람
  - 끌리는 사람 vs 잘 맞는 사람
  - 진짜 인연 vs 피곤한 인연
  - 관계 강점 vs 조심할 점
- 구조:
  1) 비교 주제 한 줄 설명
  2) 3~5개 항목 표
  3) 표 아래에서 ${name}님에게 중요한 핵심 1개 설명
- 프롬프트 공식:
  "두 대상을 3~5개 항목으로 비교하라. 각 칸은 짧고 구체적인 생활어로 쓰고, 표 아래에서 ${name}님에게 가장 중요한 기준 하나를 설명하라."

페이지 타입 10. 위험 신호 판단형
- 목적: 피해야 할 관계 유형을 알려준다.
- 사용 위치: 반복 패턴/흑역사 파트
- 구조:
  1) 끌리지만 피곤해지는 유형 단언
  2) 말투, 연락, 약속, 감정기복 등 신호 제시
  3) 왜 ${name}님이 흔들릴 수 있는지 생활어로 설명
  4) 빠져나오는 기준 1~2개
- 프롬프트 공식:
  "위험한 사람을 악인처럼 단정하지 말고, ${name}님이 피곤해질 수 있는 관계 신호로 설명하라. 불안 조장보다 판단 기준을 제공하라."

페이지 타입 11. 타이밍/운 흐름형
- 목적: 사랑이 들어오는 시기를 현실적으로 말한다.
- 사용 위치: 타이밍 파트
- 사주 근거: 대운, 세운, 흐름
- 출력: 한자/전문용어 금지
- 구조:
  1) 현재 사랑 흐름 한 줄
  2) 가까운 시기/나이대/연도 무렵
  3) 그 시기에 생기는 만남의 특징
  4) 준비해야 할 행동
  5) 무리하면 흔들리는 지점
- 프롬프트 공식:
  "대운/세운이라는 말은 쓰지 말고, 시기와 준비감으로 번역하라. 사건을 확정하지 말고, 사랑을 받아들이기 쉬운 흐름과 행동을 말하라."

페이지 타입 12. 액션 플랜형
- 목적: 사용자가 바로 행동할 수 있게 한다.
- 사용 위치: 마지막 전 또는 타이밍 파트 끝
- 구조:
  1) 지금 가장 먼저 할 일
  2) 한 달 안에 확인할 신호
  3) 관계에서 피할 선택
  4) 좋은 사람을 알아보는 기준
- 프롬프트 공식:
  "위로보다 행동을 우선하라. 추상적 조언 대신 메시지, 약속, 대화, 확인 기준처럼 실행 가능한 문장으로 써라."

페이지 타입 13. 마지막 편지형
- 목적: 전체 해석을 정서적으로 닫는다.
- 구조:
  1) 이름 호명
  2) 앞에서 본 매력과 사랑 흐름 회상
  3) 맞는 사람과 반복 패턴 회상
  4) 지금 가져갈 한 문장
  5) 서명
- 프롬프트 공식:
  "사주 근거를 다시 나열하지 말고, 앞에서 본 생활어 결론을 편지처럼 회상하라. 마지막에는 ${name}님이 가져갈 짧은 문장을 남겨라."

4. 오행과 십성으로 보는 관계 역할
5. 용신·희신·기신, 사랑에서의 보완점
6. 내 매력은?
7. 첫인상에서 생기는 오해
8. 호감이 생기면 보내는 신호
9. 사랑하면 달라지는 태도
10. 끌리는 사람과 잘 맞는 사람
11. 사랑이 들어오는 시기

13. 내게 맞는 만남 방식

22. 액션 플랜

구현 메모
- 기존 V4는 유지한다.
- V5는 페이지 타입을 더 잘게 쪼개는 것이 목표다.
- 6개 챕터 안에 그대로 우겨 넣을 수도 있지만, 경쟁사 수준의 흐름을 내려면 내부적으로 20개 이상 페이지 타입을 가진 구조가 더 적합하다.
- 렌더는 기존 ChapterShell을 유지하되, 초반 교육 카드와 중간 비교표를 추가하는 방식이 현실적이다.
