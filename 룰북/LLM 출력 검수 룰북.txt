LLM 출력 검수 룰북
작성일: 2026-05-11

목적
- 연애사주/인연궁합 생성 결과에서 LLM이 근거 없는 부정 풀이를 확장하지 못하게 한다.
- 프롬프트만 믿지 않고, 생성 후 검수와 필요 시 재작성을 거친다.

적용 파일
- lib/llm-output-guard.ts
- app/api/hongsil-generate/route.ts
- app/api/inyeon-generate/route.ts
- app/api/generate/route.ts

적용 범위
- 하나의 홍실(연애사주)
- 인연궁합
- 부모와 자녀 궁합 V2

검수 흐름
1. Gemini가 챕터 본문을 생성한다.
2. 서버가 챕터 본문 전체를 먼저 모은다.
3. 1차 코드 검사로 금지 표현과 위험 조건을 찾는다.
4. 반복 사주근거 카운트를 만든다.
5. LLM judge가 사주 근거와 룰을 기준으로 PASS/FAIL을 판정한다.
6. FAIL 또는 위험 이슈가 있으면 재작성 LLM이 문제 문장만 수정한다.
7. 이름 오타 방지 가드를 적용한 뒤 프론트로 전송한다.

부모와 자녀 궁합 V2 예외
- 부모자녀는 기존 클라이언트 후처리(enforceParentVoice, stripAgeInappropriate, stripParentTakeaway)를 유지한다.
- 서버 검수는 그 앞단에서 근거 없는 추론, 비유 과다, 원점수 노출, 같은 근거 반복을 줄인다.
- 나이 부적합 표현과 부모 호칭은 기존 부모자녀 전용 후처리가 한 번 더 정리한다.

1차 금지 표현
- 혼자 모든 것을 짊어
- 혼자 짊어
- 벽처럼 느껴
- 감정을 삭이
- 감정을 솔직하게 표현하지 못
- 사랑을 못 하
- 관계가 무너
- 부족해서 보완
- 약해서 채워
- 반드시 헤어/무너/불행/실패
- 비겁/식상/재성/관성/인성 원점수 1.1, 2.2 같은 기준 없는 숫자 노출
- 한 챕터 안에서 "마치" 비유가 3회 이상 반복되는 흐름
- 태약/신약 + 비겁 + 식상/재성 약함 같은 동일 근거가 반복되는 흐름
- 신약, 비겁, 식상, 재성, 관성, 인성, 일주, 일간, 용신/희신/기신 같은 근거명이 2회 이상 반복되는 흐름

핵심 해석 금지
- 신약 + 비겁 0만으로 "혼자 모든 것을 짊어짐" 단정 금지.
- 신약 + 비겁 0만으로 "감정을 삭임" 단정 금지.
- 신약 + 비겁 0만으로 "상대에게 벽처럼 느껴짐" 단정 금지.
- 식상 0만으로 "감정 표현을 못함" 단정 금지.
- 특정 십성 부족을 "상대가 채워줘야 한다"로 단정 금지.
- 관계 파국, 불행, 이별, 실패를 미래 사건처럼 단정 금지.
- 비유가 풀이보다 길어지는 구성 금지.
- 같은 사주 근거를 같은 챕터에서 반복 설명 금지.
- 1.1, 2.2 같은 기준 없는 원점수 본문 노출 금지.

반복 사주근거 처리
- 원 프롬프트는 수정하지 않는다.
- 생성 후 검수 단계에서 근거명을 카운트한다.
- 같은 근거명은 첫 1회만 직접 노출한다.
- 2회째부터는 "이 흐름", "이 결", "이 리듬", "앞에서 본 구조"로 치환한다.
- 같은 근거에서 파생된 설명은 삭제하지 않고 한 문단으로 병합한다.
- 새로운 사주 해석을 추가하지 않는다.
- 내용량은 유지하고, 반복되는 근거명과 의미 중복만 줄인다.

의미 중복 문장표 방식
- 원 프롬프트가 아니라 검수/재작성 단계에서만 사용한다.
- LLM은 내부적으로 중복 문장표를 만든다고 가정한다.
- 출력에는 중복 문장표를 노출하지 않고 최종 본문만 반환한다.
- 같은 클러스터 문장이 2개 이상이면 하나의 문단으로 병합한다.
- 사주근거명이 달라도 결론 의미가 같으면 중복으로 본다.
- "이 흐름", "이 결", "이 리듬", "자기 리듬을 천천히 세우는 결" 같은 대체어도 반복 금지한다.

의미 클러스터 기준
- 속도/신중함: 천천히 세움, 바로 말하지 않음, 정리 후 전함, 상대 반응을 살핌, 안정되면 드러남.
- 수용/조율: 상대 흐름을 받아들임, 맞춰줌, 협력형, 자기 주장보다 상대 의견 존중.
- 표현 방식: 감정 표현, 말투, 솔직함, 안으로 정리함, 대화 타이밍.
- 현실/결과: 현실감, 목표 지향, 결과를 만듦, 실용성, 꾸준함.
- 책임/안정: 책임감, 안정적 관계, 신뢰, 약속, 오래 가는 구조.
- 내면/일주 이미지: 겉모습과 속마음, 포부, 의지, 일주 비유, 내면 힘.
- 외부 받침/환경: 외부의 지지, 받쳐주는 관계, 편안한 분위기, 안정적인 환경.
- 매력/끌림: 상대가 느끼는 매력, 호기심, 끌림, 인상.
- 미래/관계 단계: 결혼, 장기 관계, 다음 단계, 시기.
- 양육/아이 환경: 부모 반응, 아이의 안정, 학습/감정/생활 환경.

시뮬레이션 확인
- Gemini API로 짧은 중복 샘플을 UTF-8 전송해 확인했다.
- 신약/비겁/자기 리듬 반복 문장 4개가 1문단으로 압축됨.
- 사주근거명은 첫 문장에만 남고, 반복 설명은 병합되는 방향으로 동작했다.

허용 표현 예시
- 비겁 0: 상대 흐름을 먼저 살피는 결.
- 비겁 0: 자기 리듬을 천천히 세우는 결.
- 식상 0: 감정을 바로 꺼내기보다 한 번 정리한 뒤 전하는 편.
- 관성/재성 강함: 책임감과 현실 감각이 크게 작동할 수 있음.
- 인성 강함: 생각을 깊게 정리하고 받아들이는 힘.
- 원점수 대신: 얇음 / 보통 / 강함 / 크게 작동함.
- 반복 근거 대신: "앞에서 본 그 흐름은 실제 관계에서는..."처럼 장면으로 전환.

시각화 추천 위치
- 초반 사주표 다음: 비겁/식상/재성/관성/인성 5가지 힘 요약 막대.
- 신강신약/태약 첫 언급 지점: 나를 밀어주는 힘 vs 밖에서 들어오는 힘 게이지.
- 연애사주 중반: 사랑에서 먼저 쓰는 힘 TOP 3 카드.
- 인연궁합 중반: 두 사람의 십성 작동 순서 비교 막대.
- 부모자녀 초반: 아이의 5가지 힘 요약, 부모와 아이의 흐름 비교 카드.
- 긴 표가 이어지는 지점: "잘하는 것 / 헷갈리는 것 / 필요한 환경" 3칸 요약 카드.

실시간 로딩 영향
- 기존 스트리밍 즉시 전송 구조에서 챕터 단위 검수 후 전송 구조로 변경.
- 챕터별로 LLM judge 1회가 추가된다.
- FAIL 시 재작성 LLM 1회가 추가된다.
- 30초 오프닝 영상과 챕터별 읽기 흐름을 전제로 실사용 대기 노출은 낮게 설계.

주의
- 이 검수는 명리학 정답 엔진이 아니라, 근거 없는 과장/부정 단정/룰 위반을 줄이는 안전장치다.
- 기존 글맛과 구체성은 유지하고, 문제 문장만 고치는 방향으로 작동한다.
