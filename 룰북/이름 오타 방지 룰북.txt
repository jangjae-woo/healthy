이름 오타 방지 룰북
작성일: 2026-05-11

문제
- LLM이 이름을 생성하면서 글자를 중복하거나 변형할 수 있다.
- 예: 장재우 -> 장재재우
- 입력 이름을 프롬프트에 넣는 것만으로는 완전 방지되지 않는다.

운영 원칙
1. 프롬프트에는 이름 고정 룰을 넣는다.
2. 생성 결과는 스트리밍 직전에 이름 보호 후처리를 거친다.
3. 후처리는 원래 이름을 기준으로 흔한 중복 음절 변형만 되돌린다.
4. 사용자가 입력한 이름 자체는 바꾸지 않는다.

적용 코드
- lib/name-guard.ts
- app/api/inyeon-generate/route.ts
- app/api/hongsil-generate/route.ts

보호 방식
- 입력 이름: 장재우
- 보호 대상 예시:
  - 장장재우
  - 장재재우
  - 장재우우
- 출력 전 치환:
  - 장재재우님 -> 장재우님

주의
- 이름이 한 글자면 자동 변형 후보를 만들지 않는다.
- 이름에 공백이 있으면 공백 제거형도 원래 표기로 복구한다.
- 모든 가능한 오타를 막는 것이 아니라, LLM에서 자주 생기는 중복 글자 변형을 막는 장치다.

향후 확장
- 저장 전 최종 본문 전체에 protectNames를 한 번 더 돌리면 더 안전하다.
- 별칭 허용 기능이 생기면 name guard 예외 목록이 필요하다.
