## Phase 2 — 구체화 prompt (요청 시 추가)

### 방향
hongsil 패턴 (`refinement/`) — 메인 LLM 본문 받은 후 특정 sub만 별도 LLM 호출로 강화.

### 후보 챕터 (강화 필요시)
| ch | 강화 후보 | 내용 |
|---|---|---|
| ch5 깊은 결 | 본능·끌림 강화 prompt | 두 사람 사이 본능적 끌림 6단 구조 |
| ch7 결혼·미래 | 미래 구체 처방 + 결혼 시기 | 사주 처방 매핑 활용 |
| ch8 마지막 편지 | 두 캐릭터 결 종합 강화 | hongsil ch6 패턴 |

### 작업 패턴 (hongsil refinement/ 참조)
1. `lib/inyeon/prompts/refinement/${name}.ts` 신규
2. 메인 본문 받은 후 splitBySubHeader → 그 sub만 재호출
3. fallback: 실패 시 메인 본문 유지
