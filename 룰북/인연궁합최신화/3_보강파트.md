## Phase 3 — inyeon-prescription 신규 (조건부)

### 목적
hongsil의 `yongsin-prescription.ts` 패턴을 인연궁합 특화로.

### 데이터 구조 (예상)

```ts
interface InyeonPrescription {
  twoElement: {
    matched: ['목', '화'];   // 두 사람 강한 오행 결합
    boost: string[];          // 두 사람 함께 좋은 행동
    avoid: string[];          // 함께 피할 환경·행동
  };
  sinsalActivation: {
    me: string[];   // 본인 신살 활용
    partner: string[];  // 짝꿍 신살 활용
    pair: string[];  // 두 사람 신살 결합
  };
  seunFlow: {
    goodFlow: string[];    // 함께 좋은 시기
    riskFlow: string[];   // 함께 피할 시기 (충 등)
    chungBranches: string[];
    hapBranches: string[];
  };
  goingTogether: {
    places: string[];     // 함께 갈 장소 (수족관·바닷가·서점 등)
    activities: string[]; // 함께할 활동
    seasons: string[];   // 좋은 계절
    avoid: string[];     // 함께 피할 자리
  };
}
```

### 적용 위치
**ch7 결혼·미래궁합 구체화 prompt**에 주입. helper 결과를 LLM에 넘기고 LLM은 그 데이터에서만 처방 추출.

### 진행 시점
**Phase 2 ch7 강화와 결합**. 단독 Phase 아님.
