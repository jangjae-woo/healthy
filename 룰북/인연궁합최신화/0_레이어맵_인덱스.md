# 인연궁합최신화 — 전체 레이어맵

## 4 파트 분류 (사용자 합의)

```
1. 검수 파트   = LLM 검수 가드 (lib/llm-output-guard.ts inyeon 분기)
2. 프롬프트 파트 = 메인 prompt (8 챕터) + 구체화 prompt (refinement/)
3. 보강 파트   = helper / 매핑 / 사주 처방 데이터
4. 참조 파트   = 연애사주에서 가져온 자산 매핑 (재활용 출처 추적)
```

## 작업 단계 (사용자 합의)

```
Phase 0 → Phase 1 → 본문 1차 받기 → Phase 2/3 (필요 sub만)
```

- **Phase 0**: 메인 prompt 슬림화 (보수적 — 명백한 안내 어휘만)
- **Phase 1**: 검수 가드 정합 (회귀 위험 0, 즉시 효과)
- **본문 1차 받기**: 풀이 검수 → 약한 sub 식별
- **Phase 2**: 약한 sub만 구체화 prompt 신규 (요청 시 추가)
- **Phase 3**: 처방 필요시 helper 신규 (Phase 2와 결합)

## 폴더 안 파일

- **0_레이어맵_인덱스.md** — 이 파일. 전체 그림.
- **1_검수파트.md** — Phase 1 가드 정합. inyeon 분기에 추가한 가드들.
- **2_프롬프트파트.md** — Phase 0 슬림화 + Phase 2 구체화 prompt.
- **3_보강파트.md** — Phase 3 helper / 매핑 / 사주 처방 데이터.
- **4_참조파트.md** — 연애사주 자산 매핑 (어떤 hongsil 패턴을 inyeon에 가져왔는지).
- **5_진행로그.md** — 작업 시점·결과·배포 URL 기록.

## 연애사주(hongsil) 비교 — 가져올 자산

연애사주에서 적용 완료한 자산 중 인연궁합에 가져올 것:
- 검수 가드 셋 (suppressRepeatedHongsilEvidence / stripSipseongScoreLeakage / SOFT_REPLACEMENTS 확장 / REPETITION_TONE_GUIDE 등)
- 메인 prompt 슬림화 패턴 (예시 어휘 제거)
- 구체화 prompt 패턴 (refinement/ 폴더 구조)
- 사주 처방 helper 패턴 (yongsin-prescription → inyeon-prescription)

## 의사결정 (확정)

- 구체화 prompt: **요청 시 추가** (한 번에 8 챕터 다 만들지 않음 — 작업 양·시간 비용)
- 사주 처방 위치: **ch7 결혼·미래궁합** 우선 후보 (Phase 2와 결합)
- 슬림화 방향: **보수적** — 정보 데이터는 보존, 명백한 안내 어휘만 제거
