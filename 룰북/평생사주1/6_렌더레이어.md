# 6. 렌더 레이어 — 결과 화면 + 시각 컴포넌트

## 역할
계산값과 LLM 본문을 목차별 1~2페이지 통합 result 페이지로 표시. 14 섹션 + opener + 사주 기초 차트 + 오프닝 영상. 어제(2026-05-12) 대규모 페이지 통합 작업으로 슬라이드 수 크게 압축.

## 주요 파일
- `app/saju/result/page.tsx` — Suspense + SajuSlideResult
- `app/saju/page.tsx` — 랜딩 (짙은 녹색·금 톤)
- `app/saju/form/page.tsx` — 입력 폼 (단일 페이지 폼, 2026-05-11 묵도인 채팅에서 전환)
- `components/SajuSlideResult.tsx` — 메인 슬라이드 컴포넌트 (2234줄)
- `components/SajuVisuals.tsx` — 신규 시각 컴포넌트 (2026-05-13, parent-child 시각 포팅)
- `components/SajuForm.tsx` — 폼 컴포넌트
- `components/OpeningVideo.tsx` — 오프닝 영상 (`/평생사주.mp4`, theme="saju" prop)
- `components/PaymentModal.tsx` — 결제 모달

## 페이지 구조 (어제 통합 작업 결과)
- 무료 영역 7페이지 → 2페이지 (커버 / 사주팔자·오행·십성·안내 머지)
- 유료 영역 목차별 통합:
  - 당신은 누구 (personality1+2) → 2페이지
  - 관계·재물·직업·학문 (money1+2) → 2페이지
  - 인연의 자리 (love1+2+3) → 1페이지
  - 몸과 마음 (health) → 1페이지
  - 특수 기운 (hidden) → 1페이지
  - 시기별 흐름 (timeline1+2) → 1페이지
  - 종합 해석 (compass+closing) → 1페이지
- AI_START = 13 (결제 후 자동 점프 위치)
