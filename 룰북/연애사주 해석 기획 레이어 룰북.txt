연애사주 해석 기획 레이어 룰북
작성일: 2026-05-12
적용 범위: 하나의 홍실 / 연애사주 생성 프롬프트

1. 적용 위치
- 코드 위치: lib/hongsil/interpretation-plan.ts
- 주입 위치: lib/hongsil/build-context.ts
- 주입 순서: 해석 기획 레이어 -> sub 분배 룰 -> traits block -> 시각 카드 사실 -> 챕터별 프롬프트
- 생성 API: app/api/hongsil-generate/route.ts

2. 왜 넣었는가
- 기존 연애사주는 식상, 재성, 관성, 비겁, 인성, 신약, 용신 같은 사주 인자가 여러 챕터에서 반복 노출될 수 있었다.
- 독자 입장에서는 같은 근거가 계속 반복되어 AI스럽고 지루하게 느껴질 수 있었다.
- 경쟁사 1페이지/2페이지 분석처럼 첫 페이지는 근거를 보여주고, 이후 페이지는 한글 생활 장면으로 번역하는 흐름이 필요했다.

3. 챕터별 정책
- 1장: 근거 신뢰 페이지. `내 매력은?`은 한문 병기와 전문 용어 3~6개까지 허용하고, 나머지 소제목도 소제목당 1~3개 정도 허용한다. 단, 반드시 바로 쉬운 말로 풀이한다.
- 2장: 사랑의 타이밍. 대운, 세운은 과다 반복하지 않되 소제목당 1~2개까지 근거로 보여줄 수 있다. 반드시 시기, 속도, 준비감으로 번역한다.
- 3장: 끌리는 사람과 관계 방향. 배우자궁, 일지, 용신 등은 소제목당 1~3개까지 제한적으로 보여줄 수 있다. 바로 태도와 만남 장면으로 말한다.
- 4장: 반복 패턴. 한문 근거는 소제목당 0~2개만 허용한다. 약한 축, 기신, 충돌 근거는 반복되는 관계 장면으로 번역하고 결핍 낙인을 만들지 않는다.
- 5장: 끌림과 본능. 도화, 홍염, 식상 등은 소제목당 0~2개만 허용한다. 온도, 거리, 반응, 표현 습관으로 바로 풀어쓴다.
- 6장: 종합 편지. 사주 근거를 길게 나열하지 않되, 필요하면 핵심 근거 1~2개만 짧게 회상하고 독자가 가져갈 문장으로 정리한다.

4. 금지 패턴
- 한자/전문용어 자체를 금지하지 않는다. 금지하는 것은 설명 없이 던지는 한문, 과다 반복, 낙인형 표현이다.
- 각 소제목에는 한문/사주근거 1~3개를 허용한다. `내 매력은?`은 3~6개까지 허용한다.
- 한문 병기나 전문용어를 썼다면 반드시 같은 문단에서 자리 설명과 쉬운 해석을 붙인다.
- 같은 근거를 다시 말할 때는 길게 반복하지 말고 1~2개만 짧게 회상한 뒤 바로 생활 장면으로 들어간다.
- 금지 문장 패턴: "신약한 사주", "비겁이 없어", "식상이 약해", "부족해서 보완", "혼자 짊어짐", "감정을 삭임", "벽처럼 느껴짐"
- 자연 비유를 길게 늘어놓지 않는다. 실제 연애에서 겪는 말투, 속도, 반응, 선택 장면으로 쓴다.

5. 기존 프롬프트와의 충돌 정리
- 기존 공통 검수문에는 "본문에 사주 인자 명사 최소 3개 노출" 기준이 있었다.
- 새 정책과 충돌하므로 lib/hongsil/prompts/v2-principles.ts의 출력 직전 체크를 바꿨다.
- 새 검수 기준은 "ch1 외에는 한자 병기와 사주 전문용어 반복을 줄이고 생활 장면으로 번역했는가"를 확인한다.

6. 기대 효과

- 두 번째 장부터는 어려운 용어 반복을 줄이고 독자가 자기 연애 장면처럼 읽게 만든다.
- 같은 근거가 반복되어도 근거명 대신 장면과 문맥으로 연결되어 중복 피로도가 줄어든다.

10. 2026-05-12 연애사주 프롬프트 전체 정리
- 기존에는 1장 첫 소제목 "내 매력은?"에서만 한자/전문용어를 허용했으나, V5에서 기준을 바꿨다.
- 현재 기준: 각 소제목에 한문/사주근거 1~3개 허용, `내 매력은?`은 3~6개 허용. 단, 반드시 자리 설명과 쉬운 해석을 붙인다.
- 기존 하위 챕터 프롬프트에 남아 있던 "본문 직접 노출", 괄호 한자, 식상/재성/관성/비겁/인성 반복 지시를 제거하거나 내부 근거 표기로 바꿨다.
- `lib/hongsil/sub-distribution.ts`도 PRIMARY 인자 노출표에서 INTERNAL 기획표로 바꿨다.
- `lib/hongsil/traits-block.ts`는 ch2~ch6에서 상세 사주 키워드 풀을 주입하지 않고, 내부 계산 완료 + 생활어 출력 지시만 주도록 줄였다.
- `lib/llm-output-guard.ts`의 연애사주 빠른 치환은 비문/어색한 표현만 고치도록 조정했다. 일간, 일지, 용신, 식상 같은 근거명과 괄호 한자는 더 이상 무조건 생활어로 바꾸지 않는다.
- 목적: 한문을 없애는 것이 아니라, 070 이미지처럼 한문과 해석이 섞인 근거 있는 글을 만들되 과다 반복만 막는다.

11. 2026-05-12 생활어 슬롯 중복 방지 2차 구조
- 2차 기준: `내 매력은?`은 사주 근거 공개 + 생활어 번역표 페이지로 운영한다.
- 여기에서 일간/일주, 오행, 십성 흐름, 신강신약, 신살, 용신/희신/기신 등 핵심 근거를 한 번 공개한다.
- 같은 페이지 안에서 위 근거를 말투, 반응, 속도, 기준감, 끌림, 안정, 회복 같은 생활어 키워드 5~7개로 번역한다.
- 이후 모든 소제목은 사주 근거명을 반복하지 않고, 배정된 생활어 슬롯만 메인 어휘로 사용한다.
- 생활어도 반복되면 AI스럽게 느껴지므로 한 소제목 안에서 같은 핵심 단어 2회 이상 반복 금지.
- 금지 연결어: "앞에서 본", "이 흐름", "이 결", "이 리듬", "이 구조" 반복 금지. 필요하면 바로 장면으로 들어간다.
- `lib/hongsil/sub-distribution.ts`에 sub별 생활어 슬롯을 배정했다.
- `lib/hongsil/prompts/v2-principles.ts`에 생활어 슬롯 중복 금지 룰을 추가했다.
- `lib/hongsil/interpretation-plan.ts`에 생활어 슬롯 운영 원칙을 추가했다.

12. 2026-05-12 연애사주 목차/소제목 중복 회피 재설계
- 페이지 수를 억지로 맞추지 않고, 질문 의도가 겹치는 소제목을 줄이거나 바꿨다.
- 핵심 원칙: `내 매력은?`에서 사주 근거와 생활어 번역표를 공개하고, 이후 소제목은 그 근거를 다시 설명하지 않고 서로 다른 연애 장면을 맡는다.
- 1장 변경: `첫인상에서 생기는 오해`, `호감이 생기면 내가 보내는 신호`, `사랑하면 달라지는 태도`, `내가 다가가는 방식`, `끌리는 사람과 잘 맞는 사람`.
- 2장 변경: `사랑이 들어오는 시기`, `솔로 탈출 가이드`, `올해 연애에서 조심할 흐름`.
- 3장 변경: `짝꿍의 첫인상과 분위기`와 `운명을 알아보는 단서`가 겹쳐 보여, `좋은 사람을 알아보는 신호`로 통합했다. 3장은 6개가 아니라 5개 소제목으로 운영한다.
- 4장 변경: `자꾸 끌리는 위험한 유형`, `반복되는 연애 패턴` 또는 `첫 연애에서 조심할 신호`, `그 패턴에서 벗어나는 방법`.
- 5장 변경: `솔직한 19금 사주`를 `끌림과 사랑의 온도`로 바꾸고, `나도 모르게 풍기는 매력`, `내가 원하는 사랑의 온도`, `둘 사이가 깊어지는 순간`으로 완화했다.
- 수정 파일: `lib/hongsil/prompts/ch1-charm.ts`, `ch2-timing.ts`, `ch3-destiny.ts`, `ch4-pattern.ts`, `ch5-instinct.ts`, `lib/hongsil/sub-distribution.ts`, `lib/llm-output-guard.ts`, `app/hongsil/result/page.tsx`.

13. 2026-05-12 목차 재설계 재사용 패턴
- 이번 연애사주 목차 재설계는 결과가 좋았으므로 평생사주, 연애궁합, 부모자녀궁합에도 재사용 가능하다.
- 핵심은 "소제목을 많이 만드는 것"이 아니라 "각 소제목이 서로 다른 질문에 답하게 만드는 것"이다.
- 1페이지/첫 파트는 사주 근거 공개와 생활어 번역표 역할을 맡긴다.
- 2페이지 이후는 한자/전문용어/사주 인자명을 반복하지 않고, 생활 장면과 행동 언어로 해석한다.
- 질문 의도가 겹치는 파트는 통합하거나 제목을 바꾼다. 페이지 수는 맞추지 않아도 된다.
- 수정 범위는 항상 네 가지를 같이 본다: 프롬프트 소제목, 생활어 슬롯표, 결과 렌더 순서, 화면 목차 label.
- 이번에 프롬프트만 바뀌고 렌더 순서가 남아 있어 2페이지가 예전 `내 짝꿍`으로 보였던 문제가 있었다. 이후 `내 매력 → 사랑 타이밍 → 내 짝꿍 → 반복 패턴 → 사랑 온도 → 마지막 편지` 순서로 맞춰 해결했다.
- 앞으로 다른 서비스도 목차를 바꾸면 `chapter === n` 렌더 조건과 `ChSub title`까지 반드시 확인한다.

14. 2026-05-12 사용자 표현 선호 반영
- 제목은 더 쉬운 표현으로 바꾸되, 내부 해석 슬롯은 유지했다.
- `끌리는 사람과 오래 맞는 사람` → `끌리는 사람과 잘 맞는 사람`. 내부 룰은 순간 끌림 vs 오래 편해지는 조건 비교를 유지한다.
- `지금 솔로에서 벗어나는 행동` → `솔로 탈출 가이드`. 내부 룰은 행동 타이밍과 만남 방식 처방을 유지한다.
- `나도 모르게 풍기는 끌림` → `나도 모르게 풍기는 매력`. 내부 룰은 상대가 느끼는 시선·분위기·온도 중심을 유지한다.

15. 2026-05-12 부적절/어색 표현 방지 룰
- 같은 결과물 안에서 카페 예시를 반복하지 않는다. 장소 소재는 카페, 산책길, 퇴근길, 지인 모임, 소개 자리, 메시지 창, 전화 통화, 약속 전후, 차 안, 집 앞 골목, 전시·서점·운동 공간 등으로 분산한다.
- `회복기를 거치는 결이에요`, `부담감을 자기 리듬을 천천히 세우려 하는`, `흐름한 결`, `상대 반응을 살피는 흐름한 결` 같은 비문 금지.
- `다만`은 습관적으로 쓰지 않는다. 전환이 필요하면 `주의할 점은`, `반대로`, `이럴 때는`, `그래서`를 문맥에 맞게 쓴다.
- `자기 리듬을 천천히 세우는 결`도 반복 금지. 필요하면 `속도를 맞추는 편`, `마음이 정리된 뒤 움직이는 편`, `확신이 생기면 움직이는 편`으로 바꾼다.
- 빠른 출력 보정에도 위 비문 치환을 추가했다.

- 가져온 것:
  - 인자 영역 회전: 같은 사주 인자를 내부 근거로 다시 쓰더라도 매력, 신호, 시기, 만남 방식, 짝꿍 조건, 위험 신호, 회복 행동, 친밀 장면처럼 서로 다른 질문 영역으로만 사용한다.
  - 대명사형 장소: 구체 지명이나 경쟁사식 고유 장면을 쓰지 않고, `처음 마주한 자리`, `지인들이 모인 자리`, `메시지 창`, `약속 전후`, `조용한 길`, `익숙한 공간`처럼 독자가 자기 상황을 넣을 수 있는 표현을 쓴다.
  - 의미 중복 판정: 인자명이 달라도 독자가 읽는 결론이 같으면 중복으로 본다.
  - 어색 연결어미와 비문 방지: 기존 15번 룰을 유지하고 더 강하게 적용한다.
- 가져오지 않은 것:
  - 감각 디테일 의무화. `시선`, `말소리`, `거리감`, `온도`, `침묵` 등은 필요한 곳에만 짧게 쓴다.
  - 자연 비유 강화. 2장 이후에는 비유보다 실제 연애 장면, 말투, 반응, 선택으로 쓴다.
  - 캐릭터명 과노출. 캐릭터 직접 노출은 기존처럼 `내 매력은?`, `내 짝꿍 미리 보기`, `마지막 편지` 3곳만 허용한다.
  - 경쟁사 문장·고유 장소·고유 비유 차용. 구조만 참고하고 문장 표현은 재사용하지 않는다.
