# 1. 엔진 레이어 — 두 사람 사주 + 궁합 계산

## 역할
a·b 두 사람의 사주 원국을 각각 계산하고, 두 사주 간 궁합 점수·체질·시기·본능 결합·재물·미래까지 결정론 계산. LLM 입력 전 단계.

## 주요 파일
### 단일 사주 (4 서비스 공통)
- `lib/saju-core.ts` — 핵심 계산 진입점 (`computeFullSajuCore`)
- `lib/saju-calculator.ts` — 천간·지지·오행·십성 분배 + `getYongsin` + `getDayMasterStrength` + `calcCompatibility(a, b)` (CompatibilityResult)
- `lib/saju-traditional.ts` — 격국·공망·기신 (`calcGyeokguk` 등)
- `lib/jpjjeon.ts` — 자평진전 격국 8 정격 + 외격
- `lib/sibiunseong.ts` — 십이운성
- `lib/tonggeun.ts` — 지장간 통근

### 궁합 (인연 전용)
- `lib/inyeon/scoring.ts` — `computeInyeonScores` · `estimateAssetCurve` · `estimateTogetherCurve`
- `lib/inyeon-traits.ts` — `deriveInyeonTraits` · `traitsToPromptBlock` (cell framework)

## 진입점
- `app/api/inyeon-generate/route.ts` L88~ — POST 시작 → `computeFullSajuCore(body.a)`·`(body.b)` + `calcCompatibility(a, b)`
- `app/inyeon/result/page.tsx` — 결과 화면이 같은 데이터 fetch

## 출력 데이터 (두 SajuAnalysis + 궁합)
- 각 사람: `pillars` / `ilgan` / `sipseong` / `elements` / `yongsin` / `sinsal` / `daeun.cycles` / `shinkang`
- 궁합:
  - `compat.basic` — 기본 호환 점수
  - `compat.elementBalance` — 두 사람 오행 보충
  - `compat.iljiRelation` — 일지(日支) 관계 (합·충·형·해·파)
  - `compat.dayMasterRelation` — 일간(日干) 관계
  - `compat.timing` — 만남·전환 시기
  - 자산 곡선: `curves.a` / `curves.b` / `curves.together` (6장 SWAP 후 일부 미사용)

## 6 관계 컨텍스트 (입력 layer)
- `relationship: "crush" | "talking" | "dating_short" | "dating_long" | "married" | "exboyfriend"`
- `duration: "lt_1m" | "1to3m" | "3to6m" | "6mto1y" | "1to3y" | "gt_3y"`
- `lib/inyeon/prompts/shared-context.ts`의 `relationshipTone(rel)` / `stageGuide(duration)` 함수가 컨텍스트 string 반환
