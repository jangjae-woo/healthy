# 6. 렌더 레이어 — 결과 화면 + 시각 컴포넌트

## 역할
계산값과 LLM 본문을 8 챕터 결과 페이지로 표시. 챕터별 시각 카드·EntryModal·OpeningVideo. 클라이언트는 SSE 챕터 인덱스 이벤트로 매핑.

## 주요 파일
- `app/inyeon/page.tsx` — 랜딩 (두루마리 LEGEND 디자인, 월하노인)
- `app/inyeon/form/page.tsx` — 입력 폼 (라이트 핑크 톤)
- `app/inyeon/result/page.tsx` — 메인 결과 페이지 + 챕터별 IIFE 매핑 + 동적 ChSub 렌더링
- `components/inyeon/ChapterShell.tsx` — 챕터 셸 (헤더·목차·다음/이전 버튼)
- `components/inyeon/EntryModal.tsx` — 2단계 입력 (관계 6 + 기간 6)
- `components/inyeon/SajuTable.tsx` — 사주 4기둥 표
- `components/inyeon/OhaengChart.tsx` — 오행 차트
- `components/inyeon/SipseongRow.tsx` — 십성 행
- `components/inyeon/SinKangBar.tsx` — 신강신약 바
- `components/inyeon/YongsinCards.tsx` — 용신·희신·기신 카드
- `components/inyeon/ScoreGauge.tsx` — 연꽃잎 점수 카드
- `components/inyeon/AssetCurve.tsx` — 자산 곡선
- `components/inyeon/SeasonGrid.tsx` — 시즌 그리드
- `components/OpeningVideo.tsx` — 오프닝 영상 (`/opening.mp4` 3.1 MB, CRF 28 압축)

## EntryModal — 2단계 입력
- 1단계: 6 관계 (`crush` / `talking` / `dating_short` / `dating_long` / `married` / `exboyfriend`)
- 2단계: 6 만남 기간 (`lt_1m` / `1to3m` / `3to6m` / `6mto1y` / `1to3y` / `gt_3y`)
- → result page url query로 전달 → API body로 매핑

## 챕터별 시각 카드
- ch1·ch2: 각 사주 펼치기 (사주팔자·오행 차트·십성·신살·신강바)
- ch3: 인연 시작 — 첫인상·끌림·DestinyHero (운명 짝꿍 캐릭터 결정론)
- ch4: 성격궁합 — 일지(日支) 관계 (합·충·형)
- ch5: 감정궁합 — 마음 닿는 방식 (DesireBar, Q2 자가답)
- ch6: 깊은궁합 — 체질·시기·본능 (관계별 18 풀이)
- ch7: 관계조언 — 관계별 처방 (재물 SWAP, 자산 곡선)
- ch8: 마지막 편지 — LetterQuote (두 캐릭터 결정론)

## 본문 렌더 흐름
1. SSE 스트림에서 `{ t: "cs", ch }`로 챕터 시작
2. `{ t: "x", ch, v }` 이벤트 누적 → `aiText[ch]`
3. `aiText[ch]`를 `### sub` 헤더 단위로 분리 → `aiBodies[ch][sub]`
4. ChSub 컴포넌트: 챕터 SLIDES 정의의 sub 순서대로 본문 매칭
5. `{ t: "cd", ch }` 챕터 완료 시 가드 결과 표시

## 클라이언트 매핑 정책
- ## 챕터 헤더 매칭 강제 X (cs/cd 이벤트로 챕터 경계 관리)
- ### sub 헤더만 매칭 — `^###\s+(.+)$` 정규식
- prompt 안내 라인 (`[인자:` 등) skip
- 본문 누락 시 fallback ("편지를 정리하고 있어요…" 등)
