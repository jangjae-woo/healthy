만세계산 테스트셋
작성일: 2026-05-11

목적
- 계산 코어 변경 후 같은 입력이 서비스별로 갈라지지 않는지 검토하기 위한 최소 테스트셋이다.
- 이 문서는 정답집이 아니라 회귀 테스트용 체크리스트다.

테스트 A: 양력 기본
- 입력: 1990-05-17, 양력, 오시, 남
- 기대: 홍실/연인궁합/부모자녀 generate가 모두 computeFullSajuCore를 통과한다.
- 확인: 연주, 월주, 일주, 시주, 오행, 신강신약이 서비스별로 달라지지 않아야 한다.

테스트 B: 음력 변환
- 입력: 1990-04-23, 음력, 오시, 남
- 기대: lunarToSolar 변환 후 양력 날짜 기준으로 연주, 월주, 대운이 계산된다.
- 확인: calculateFourPillars만 음력으로 계산하고 calcYearPillar/calcMonthPillar/calcDaeun은 원래 음력 날짜를 쓰는 혼합 상태가 없어야 한다.

테스트 C: 시간 모름
- 입력: 1995-08-12, 양력, 시간 모름, 여
- 기대: 일주까지 계산되고 시주는 null이다.
- 확인: 시주 십성도 null이며, 오행 계산에 시주가 들어가지 않는다.

테스트 D: 야자시
- 입력: 1995-08-12, 양력, 야자시 (23:30~23:59), 여
- 기대: hour 23, minute 30으로 계산한다.
- 확인: 시주가 null이 아니며, 기존 "시간 모름" 처리와 섞이지 않는다.

테스트 E: 자시
- 입력: 1995-08-13, 양력, 자시 (00:00~01:29), 여
- 기대: hour 0, minute 30으로 계산한다.
- 확인: 야자시와 구분되는 입력값으로 전달된다.

테스트 F: 기존 URL 호환
- 입력: 1995-08-12, 양력, 자시 (23:30~01:29), 여
- 기대: 기존 URL/저장값도 실패하지 않는다.
- 확인: 코어에서 기존 문자열을 계속 인식한다.

테스트 G: 가족 공통 오행
- 입력: 엄마/아빠/자녀 3인 사주
- 기대: sharedElement는 raw score 25 이상이 아니라 각자 오행 비율 25% 이상으로 판단한다.
- 확인: 총합 대비 비율로만 판정한다.

남은 수동 확인
- 절기 당일 입력은 날짜 공식 한계가 있으므로 실제 절입 시각 검증 전까지 "정확 확정"으로 말하지 않는다.
- 윤달 출생자는 UI 입력값이 없으므로 현재는 일반 음력으로 처리된다.
