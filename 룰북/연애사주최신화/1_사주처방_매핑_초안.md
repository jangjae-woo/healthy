# 사주 처방 매핑 — 초안 (사용자 검토 필요)

## 출처
- 풍수 통설 + 명리 신살 정통 해석 기반
- 책마다 약간 차이 있음. 명리 책 한 권 보고 검증 권장
- 사용자가 이 매핑을 OK해야 코드에 박음

---

## 1. 부족 오행 5종 보강 처방

### 1-1. 수(水) 부족 (또는 용신이 수)
연애 의미: 감정 깊이·인내·기다림의 결이 옅음 → 관계 안정감 보강 필요

| 영역 | 처방 |
|---|---|
| **행동** | 물·차·음료 자주 마시기 / 반신욕 / 수영·아쿠아 운동 / 명상·일기 |
| **장소** | 바닷가·강가·호수 산책 / 수족관·아쿠아리움 방문 / 비 오는 날 카페 |
| **사물** | 어항·물고기 기르기 (소형 1~2마리 OK) / 푸른 잎 수경식물 / 작은 분수·물그릇 |
| **색상** | 검은색·남색·짙은 파랑 (옷·소품·가방) |
| **피할 것** | 사막·건조 환경 장기 체류 / 땀 많이 흘리는 격렬 운동 매일 / 빨강·주황 과한 옷차림 |

### 1-2. 화(火) 부족 (또는 용신이 화)
연애 의미: 표현·열정·드러냄의 결이 옅음 → 적극성 보강

| 영역 | 처방 |
|---|---|
| **행동** | 햇볕 산책 / 가벼운 유산소 운동 / 모임에 적극 참여 / 자신 의견 한 줄로 짧게 말하기 연습 |
| **장소** | 햇볕 잘 드는 카페·테라스 / 등산 (낮은 산) / 캠프파이어·바비큐 자리 |
| **사물** | 따뜻한 색 인테리어 (조명·쿠션·러그) / 빨간 꽃·작은 캔들 |
| **색상** | 빨강·주황·핫핑크·노랑 (포인트로 1~2개) |
| **피할 것** | 어두운 지하 공간 장기 / 차가운 음료만 마시기 / 밤늦은 활동 중심 |

### 1-3. 목(木) 부족 (또는 용신이 목)
연애 의미: 시작·성장·새로움의 결이 옅음 → 변화·도전 보강

| 영역 | 처방 |
|---|---|
| **행동** | 식물 키우기 / 새 취미 시작 / 산책 (공원·숲) / 책 읽기 |
| **장소** | 수목원·식물원 / 공원·숲길 / 도서관·서점 |
| **사물** | 화분·관엽식물 / 나무 소재 가구·소품 / 책장 정돈 |
| **색상** | 녹색·연두·진초록 (옷·소품) |
| **피할 것** | 금속 가득한 공간 장기 / 콘크리트 밀집 지역만 머물기 |

### 1-4. 금(金) 부족 (또는 용신이 금)
연애 의미: 결단·정리·기준의 결이 옅음 → 명확한 판단 보강

| 영역 | 처방 |
|---|---|
| **행동** | 정리정돈 자주 / 운동 (근력 위주) / 매일 한 가지 결정 명확히 내리기 |
| **장소** | 도서관·서점·미술관 / 깔끔한 카페 / 헬스장 |
| **사물** | 금속 장신구 (시계·반지·목걸이) / 흰 도자기·식기 / 깔끔한 책상 |
| **색상** | 흰색·은색·회색·하늘색 (메인) |
| **피할 것** | 어수선한 공간 / 결정 미루기 습관 / 단 음식 과다 |

### 1-5. 토(土) 부족 (또는 용신이 토)
연애 의미: 안정·중재·받아줌의 결이 옅음 → 단단한 마음 보강

| 영역 | 처방 |
|---|---|
| **행동** | 흙·정원 가꾸기 / 도자기 만들기 / 명상·요가 / 단 음식 적절히 |
| **장소** | 정원·텃밭 / 도예 공방 / 산속 펜션·황톳길 |
| **사물** | 도자기·자기 / 흙·돌 소품 / 황토 침구 |
| **색상** | 황색·갈색·베이지·카키 |
| **피할 것** | 자주 이사·이동 / 약속 자꾸 바꾸기 / 한곳에 오래 못 있기 |

## 2. 신살 활용 처방

### 2-1. 도화살(桃花殺)
의미: 매력·이성 끌림 강함

처방:
- 사람 많은 모임·전시·공연 자주 참여 → 자연스러운 끌림 발휘
- 외모 정돈에 시간 투자 (큰 변화 X, 작은 디테일)
- 주의: 가벼운 끌림이 잦아 진심 확인 시간 필요

### 2-2. 천을귀인(天乙貴人)
의미: 어려울 때 도움 받는 인덕

처방:
- 지인 소개·주선 자리에 열린 마음으로 응하기
- 인생 멘토·가까운 어른에게 상의하기
- 가족·친구 모임 자주 → 그 자리에서 인연 받음

### 2-3. 월덕귀인(月德貴人) / 천덕귀인(天德貴人)
의미: 덕·운이 따라줌

처방:
- 봉사·기부 활동 → 덕 쌓는 흐름 강화
- 약속 한 가지 절대 안 어기기 (덕의 시작)

### 2-4. 양인살(陽刃殺)
의미: 강한 추진력·결단력. 반대로 갈등·과격함 위험

처방:
- 결단 필요 시기에 활용 (관계 정리·고백 등)
- 갈등 시 한 박자 쉬고 대화 (즉각 반응 자제)
- 운동·운동 경기로 에너지 발산

### 2-5. 도화살 + 홍염살 동시
의미: 매력 + 끌림 둘 다 강함. 인기 많지만 정착 어려움 위험

처방:
- 한 사람에게 집중하는 시간 의식적으로
- 가벼운 만남 반복 자제

### 2-6. 역마살(驛馬殺)
의미: 이동·변화 많음

처방:
- 여행·이사·새 환경에서 인연 만날 가능성 높음
- 한곳에 정착하기 어려우면 그걸 받아들이는 사람과 매칭

### 2-7. 화개살(華蓋殺)
의미: 학문·예술·종교 친화

처방:
- 책방·전시·강의·종교 모임에서 인연
- 깊은 대화 자리 선호

### 2-8. 귀문관살(鬼門關殺)
의미: 직관·예민·신비 감각

처방:
- 직감 신뢰해도 됨. 첫인상에 강한 호불호
- 단 예민함이 관계에 부담 안 되도록 거리 두기 연습

### 2-9. 금여(金輿)
의미: 재물·배우자 복

처방:
- 자연스러운 만남 흐름 → 운명 짝꿍 가능성
- 무리한 노력보다 여유 유지

### 2-10. 현침살(懸針殺)
의미: 예리·날카로움

처방:
- 의료·정밀 분야 인연 가능성
- 말투 부드럽게 다듬기

## 3. 세운(올해 운) 흐름 처방

### 3-1. 강해지는 오행별

**올해 화 강한 해**:
- 좋은 흐름: 표현·만남 활발 / 적극 추진해도 OK
- 피할 것: 너무 뜨거운 자리 자제 (감정 격해짐)
- 피할 장소: 한낮 땡볕 장시간 / 매운 음식 모임 매일

**올해 수 강한 해**:
- 좋은 흐름: 깊은 대화·정서 교감 / 결혼 결단 시기
- 피할 것: 감정 과몰입 / 물가 야간 운전
- 피할 장소: 음주 모임 잦음 / 폐쇄 공간 장시간

**올해 목 강한 해**:
- 좋은 흐름: 새 시작·새 사람 / 도전·이사·이직
- 피할 것: 너무 많이 벌리지 말고 한두 가지에 집중
- 피할 장소: 산행 위험 시기엔 자중 (충 걸린 해)

**올해 금 강한 해**:
- 좋은 흐름: 판단력·결단 / 정리·고백·이별 결정
- 피할 것: 너무 단호해서 관계 끊지 말 것
- 피할 장소: 칼·금속 다루는 위험 활동 자중

**올해 토 강한 해**:
- 좋은 흐름: 안정·정착 / 결혼·집·계약 결정
- 피할 것: 너무 머물러 새 기회 놓치지 말 것
- 피할 장소: 토지 분쟁·이사 갈등 가능성

### 3-2. 충(沖) 걸린 해

해당 지지 충 시기엔:
- 큰 결정 자제 (이혼·이사·이직 신중)
- 산행·운전·여행 안전 주의
- 관계 충돌 가능성 → 대화 신중

### 3-3. 합(合) 들어온 해

해당 지지 합 시기엔:
- 만남 기회 활발
- 결혼·약혼 결단 시기로 좋음
- 함께 떠나는 여행 권장

## 사용자 검토 요청

이 매핑은 풍수·명리 통설을 모은 초안이야. 책마다 약간 차이 있고, 사용자 미감에 안 맞는 처방도 있을 수 있음.

검토 포인트:
1. **OK인 것** / **빼야 할 것** / **수정할 것** 표시
2. **추가하고 싶은 처방** (사용자 사주 경험 기반)
3. 각 처방 길이 — 너무 많으면 LLM이 본문에 한꺼번에 박을 수 있어 sub당 2~3개로 제한 예정

OK 받으면 → `lib/hongsil/yongsin-prescription.ts` helper에 코드로 박고 → solo-escape·yearly-flow prompt가 helper 데이터에서만 골라 쓰게 강제.
