# 아이기질+부모양육 v1 검수 체크리스트

## 1. 사주 판단 체크

- [ ] 아이 6요소가 명식의 실제 특징과 연결되는가.
- [ ] 기질 설명이 십성/오행/강약 흐름과 충돌하지 않는가.
- [ ] 부모 사주 설명이 부모 역할 조언으로 자연스럽게 이어지는가.
- [ ] 부모궁 요약이 억지 해석처럼 보이지 않는가.
- [ ] 같은 샘플 안에서 판단끼리 서로 모순되지 않는가.

## 2. 상품성 체크

- [ ] 무료 일반 운세처럼 얕게 느껴지는 문장이 있는가.
- [ ] 부모가 돈을 내고 읽을 만큼 구체적인가.
- [ ] 아이를 단정하거나 낙인찍는 표현이 없는가.
- [ ] 조언이 실제 생활 장면으로 연결되는가.
- [ ] 엄마/아빠 각각의 차이가 충분히 드러나는가.

## 3. 문장 흐름 체크

- [ ] 제목, 요약, 본문, 조언의 흐름이 끊기지 않는가.
- [ ] 앞 문장과 뒤 문장이 같은 말을 반복하지 않는가.
- [ ] 너무 강한 표현이나 불안감을 주는 표현이 없는가.
- [ ] 사주 용어가 과하지 않고 부모가 이해할 수 있는가.
- [ ] 문장 길이가 보고서로 읽기 편한가.

## 4. 수정 우선순위

1. 사주적으로 틀린 판단
2. 부모에게 상처가 될 수 있는 표현
3. 유료 보고서로 보기에는 얕은 일반론
4. 흐름이 끊기는 연결 문장
5. 더 좋아질 수 있는 표현 다듬기

## 5. 최종 통과 기준

- [ ] 샘플 4명 모두 큰 사주 오류가 없다.
- [ ] 형이 수정한 문장을 자동 반영할 수 있다.
- [ ] QA에서 hard error가 0개다.
- [ ] 미리보기 HTML에서 샘플 4명을 바로 볼 수 있다.
- [ ] 다음 단계인 캐시 확장 또는 API 연결로 넘어갈 수 있다.
