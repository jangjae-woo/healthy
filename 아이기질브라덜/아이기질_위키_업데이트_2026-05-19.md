## 오늘 확정한 운영 방향

아이기질도 평생사주와 같은 방식으로 간다.

1. 계산 엔진이 먼저 판단값을 만든다.
2. 판단값에 따라 조합표, 축, variant를 고른다.
3. 보고서 블록은 template + cache + override 구조로 조립한다.
4. 형 피드백은 원문을 직접 덮어쓰기보다 overrides 또는 후보 문장 교체로 반영한다.
5. 검수용 샘플과 운영용 대량 결과물을 분리한다.

## Cloudflare R2 기준

앞으로 캐시 생성 결과물은 Cloudflare R2에 넣는다.

```text
GitHub = 코드 / 규칙 / 템플릿 / 검수 문서 / 소수 샘플
Cloudflare R2 = 캐시 생성 결과물 / 대량 JSON / 고객별 산출물 / LLM 사전생성 결과
```

기억해야 할 관련 흐름:

- `scripts/r2-smoke-test.mjs`
- `scripts/upload-youa-cache-to-r2.mjs`
- `scripts/precompute-child-cache-pilot.mjs`

현재는 예전보다 캐시 생성량이 많이 줄었다.
이유는 모든 조합 문장을 대량으로 미리 쌓는 방식이 아니라, 계산 판단값과 블록 조립 구조를 먼저 세우고 필요한 후보만 쓰는 방식으로 바뀌었기 때문이다.
