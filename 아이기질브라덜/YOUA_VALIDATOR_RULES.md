# 아이기질 대량 생성 validator 규칙 v1

이 문서는 Cloudflare R2에 저장하기 전 생성 결과를 걸러내는 규칙이다.

## 1. 점수-등급 검증

반드시 다음 구간과 일치해야 한다.

```text
0-20 매우낮음
21-40 낮음
41-60 중간
61-80 높음
81-100 매우높음
```

실패 예:

```text
28점 중간
70점 중간
75점 매우높음
```

## 2. 필수 금지 문자열

본문 어디에도 아래 문자열이 있으면 실패다.

```text
undefined
null
NaN
child0
child1
mother
father
validator
[object Object]
```

단, JSON 키 이름으로 쓰인 `mother`, `father`는 허용한다. 사용자에게 보이는 본문 문자열에서는 금지한다.

## 3. 이름 검증

사용자에게 보이는 본문에는 입력 이름이 치환되어야 한다.

허용 예:

```text
김수민 양
박지영 어머님
김재훈 아버님
```

실패 예:

```text
child 양
어머니
아버지
mother님
father님
```

단, 사용자가 부모 이름을 입력하지 않은 경우에는 `어머님`, `아버님`을 기본값으로 허용한다.

## 4. 사주 인자 검증

LLM 출력에 들어간 사주 인자는 입력 facts에 존재해야 한다.

검사 대상:

- 일간
- 십성
- 오행 강약
- 조후
- 12운성
- 신살
- 천간합
- 생극 관계
- 부모 자리

입력 facts에 없는 인자가 본문에 나오면 실패 또는 repair 대상이다.

## 5. 시간 모름 검증

`birthKnownHour=false`일 때:

- 시주 인자를 본문 근거로 쓰면 실패다.
- 시지, 시간, 시주 위치를 근거 표에 넣으면 실패다.
- "시간을 몰라 정보가 빈약하다" 같은 문장은 쓰지 않는다.
- 없음 패널티를 주지 않는다.

시간 있음/없음 비교 샘플에서 같은 생년월일의 6요인 점수 차이는 원칙적으로 최대 5점 안에 있어야 한다.

## 6. 문장 품질 검증

아래 패턴은 실패 또는 재생성 대상이다.

```text
활기가 높아서 활기가 높습니다.
조심이 낮아서 조심이 낮습니다.
이 결은 좋은 결입니다.
부모와 자녀가 잘 맞습니다.
```

검수 기준:

- 일상 장면에 장소, 시간, 행동 중 2개 이상이 들어가야 한다.
- 양육팁은 시간/소통/환경 3축이 모두 있어야 한다.
- `왜 이런 결인가`는 도입, 근거 표, 종합 산문이 모두 있어야 한다.
- 부모 사주는 일간 비유와 강한 기운 설명이 모두 있어야 한다.
- 궁합은 일간 관계와 일상 사례가 모두 있어야 한다.

## 7. 매트릭스 카드 검증

시너지 카드:

- `이렇게 풀어보세요`가 있으면 실패다.
- 일상 사례는 최소 2개 권장, 최소 1개 필수다.

충돌 카드:

- `이렇게 풀어보세요`가 없으면 실패다.
- 부모의 결, 자녀의 결, 충돌 메커니즘이 모두 있어야 한다.

## 8. 반복 검증

같은 보고서 안에서 동일 문장이 2회 이상 반복되면 경고다.

강한 실패:

- 서로 다른 요인의 `일상에서는` 본문이 70% 이상 동일
- 양육팁 3축의 제목만 다르고 본문 구조가 동일
- 부모-자녀 궁합에서 어머님/아버님만 바뀌고 내용이 사실상 동일

## 9. R2 저장 전 필수 통과 조건

R2에 업로드하려면 아래 조건을 통과해야 한다.

```json
{
  "scoreLevelChecked": true,
  "noUndefinedText": true,
  "noInventedFacts": true,
  "hasSixFactorSections": true,
  "hasThreeParentingTipsPerFactor": true,
  "hasParentSections": true,
  "hasCompatibilitySections": true,
  "jsonParseOk": true
}
```
