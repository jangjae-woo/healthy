# 콘텐츠 설계

## 🎯 두 가지 상품 라인

### 1. 부모-자녀 사주 (Parent-Child Saju)
- 자녀의 사주를 부모를 위해 풀이하는 양육 매뉴얼
- 양육 코칭 톤 + 발달심리학 프레임 활용
- 연령 자동 매칭 (만 0세~18세, 8단계)
- **포지셔닝**: "사주 + 발달심리 = 우리 아이 사용 설명서"

### 2. 인연 사주 (Romantic Saju) — 기획 단계
- 연애·결혼 인연 분석
- **5개 카테고리**: 연인 / 배우자 / 전 연인 / 썸남썸녀 / 짝사랑
- 짝사랑은 상대 생년월일 필수
- **포지셔닝**: "두 사람의 결을 풀어내는 인연 풀이"

## 🐯 동물 유형 시스템 (20개)

일간(10) × 신강/신약(2) = 20동물:

| 일간 | 신강 | 신약 |
|---|---|---|
| 갑(목) | 🐯 호랑이 (虎) | 🦌 사슴 (鹿) |
| 을(목) | 🦚 공작 (孔雀) | 🐰 토끼 (兔) |
| 병(화) | 🦁 사자 (獅) | 🦊 여우 (狐) |
| 정(화) | 🦋 나비 (蝶) | 🐿 다람쥐 (栗鼠) |
| 무(토) | 🐻 곰 (熊) | 🦔 고슴도치 (蝟) |
| 기(토) | 🐘 코끼리 (象) | 🐶 강아지 (犬) |
| 경(금) | 🦅 매 (鷹) | 🐺 늑대 (狼) |
| 신(금) | 🦢 백조 (鵠) | 🐈 고양이 (猫) |
| 임(수) | 🐋 고래 (鯨) | 🐬 돌고래 (海豚) |
| 계(수) | 🦦 수달 (獺) | 🐢 거북이 (龜) |

**판정 기준**: 일간 오행 비중 + 인성 오행 비중 합산
- ≥ 40% → 신강
- < 40% → 신약

각 동물마다: 한자명, 태그라인, 일간 본질, 오행, 컬러 팔레트(메인/서브/액센트).
일간별 ■ traits 5개 + 신강·신약별 ⚠️ cautions 5개 + 🧁 tips 6개.

## 👶 연령 카테고리 (8단계)

| key | 라벨 | 만 나이 | 색상 | 보고서 |
|---|---|---|---|---|
| `infant_pre` | 영아 미만 | 만 0세 (~12개월) | 🍼 분홍 | ✅ 제한적 |
| `infant` | 영아 | 만 1~2세 | 👶 핑크 | ✅ |
| `preschool` | 유아 미취학 | 만 3~6세 | 🧒 보라 | ✅ |
| `elem_lower` | 초등 저학년 | 만 7~9세 | 🎒 파랑 | ✅ |
| `elem_upper` | 초등 고학년 | 만 10~12세 | 📚 초록 | ✅ |
| `middle` | 중학생 | 만 13~15세 | 🎓 노랑 | ✅ |
| `high` | 고등학생 | 만 16~18세 | 🎓 주황 | ✅ |
| `adult` | 성인 | 만 19세+ | 🧑 회색 | ❌ 별도 안내 |

각 카테고리마다 AI 프롬프트에 자동 주입되는 작성 지침 (`reportToneInstruction`):
- 영아·유아: 떼쓰기·분리불안·어린이집·또래 중심
- 초등: 학습·친구·자존감 중심
- 중·고: 사춘기·진로·정체성·독립 중심
- ⚠️ 영아에게 입시 얘기, 고등학생에게 떼쓰기 얘기 같은 미스매치 방지

전환 임박 시 (≤6개월) 다음 시기 보고서 미리보기 안내 자동 노출.

## 💗 PART 2 우리 아이의 마음 — 9페이지 상세 설계

### 페이지 구조 (모든 페이지 공통)

```
┌──────────────────────────────────────────┐
│ 우리 아이의 마음 · X/9                    │ ← 페이지 번호
│ 페이지 제목                                │
│ 부제 (사주 요소 매핑)                      │
│ ─────────────────                        │
│ <Lead> 도입 단락 (1-3문장 컨텍스트)        │
│                                          │
│ [비주얼 — 페이지마다 다른 시각화]           │
│                                          │
│ ┃ <Insight> 인사이트 블록                  │
│ ┃ • 데이터 해석 + 양육 조언                │
│ ┃ • 1-2단락                              │
└──────────────────────────────────────────┘
```

### 9페이지 비주얼 + 사주 도출

| # | 페이지 | 비주얼 | 사주 도출 (어떻게) |
|---|---|---|---|
| 1 | 외향-내향 스펙트럼 | 그라데이션 슬라이더 + 📍 마커 | 양 기운(목화+식상재성) vs 음 기운(금수+인성관성) |
| 2 | 9가지 기질 차원 | 9각 레이더 (토마스-체스) | 활동수준=화·식상, 규칙성=토·정관, 접근회피=양/음, 적응성=목+식상, 반응강도=화+편관, 반응역치=신강도, 기분의질=식신+정인, 주의산만=편재+상관+신약, 주의지속=정인+정관+토 |
| 3 | 6가지 행동 결의 강도 | 6색 가로 막대 (0-100) | 활동성·표현력·감수성·끈기·창의성·자기조절 |
| 4 | 좋아함 vs 싫어함 | 좌우 분할 카드 (3+3) | 일간이 끌리는 오행/관계 ↔ 답답해하는 오행/관계 |
| 5 | 감정 표현 4결 | 2×2 매트릭스 + 강도 도트 | 기쁨(식신)·분노(편관)·슬픔(편인)·두려움(겁재) |
| 6 | 스트레스 신호 5가지 | 카드 그리드 (사주 신살 동적) | 충→짜증, 형→몸증상, 식상약→말수↓, 인성과다→잠↑, 양인→폭발, 신약→위축 |
| 7 | 회복 처방전 | 즉효/일상/회피 컬러 칩 | 가장 약한 오행 → 회복 채널 매핑 (목→자연, 화→사람, 토→안정, 금→정리, 수→혼자) |
| 8 | 안정 환경 4채널 | 4분면 + need 뱃지 + 게이지 | 토 약→공간, 화 약→빛, 금 약→소리, 수 약→리듬 |
| 9 | 자존감 코어 | 3겹 동심원 + 좌우 보호/위협 | 코어=일간, 보호=인성·식신·길성, 위협=충·형·관성과다·귀문 |

### 텍스트와 비주얼 균형

각 페이지에 **3가지 텍스트 블록** 강제:
1. **부제**: 사주 요소 매핑 노출 (예: "양 기운(목·화·식상·재성) ↔ 음 기운(금·수·인성·관성)")
2. **Lead 단락** (~3문장): 페이지 주제의 의미 도입
3. **Insight 블록** (~2단락): 데이터 기반 해석 + 양육 조언

→ 데이터 대시보드가 아닌 **잡지 기사** 톤.

### 데이터 연동 예시 (Insight 자동 생성)

| 페이지 | 동적으로 만들어지는 핵심 문장 |
|---|---|
| p1 | *"외향 75% — 평균보다 바깥으로 뻗는 결이 두드러집니다"* |
| p2 | *"가장 두드러지는 결은 접근-회피(100점)과 적응성(100점)..."* |
| p3 | *"가장 강한 결은 창의성(96점)... 가장 약한 결은 감수성(5점). [자동 양육 조언]"* |
| p5 | *"기쁨(60%)을 가장 자유롭게 드러냅니다... 분노(0%)는 안으로 삭이는 편"* |
| p6 | 발동된 신살별 신호 자동 변환 (양인→폭발, 신약→위축 등) |
| p7 | 가장 약한 오행 자동 감지 → 처방 매핑 |
| p8 | high need 채널 자동 추출 → 우선순위 안내 |
| p9 | 일간별 코어 본질 + 신살·신강도 기반 보호/위협 자동 도출 |

## 🎴 강점·주의점 카드 시스템

`lib/trait-cards.ts` 의 `deriveTraits(saju)` 도출 규칙:

| 규칙 | 트레이트 |
|---|---|
| 강한 오행 (≥22%) 상위 2개 | ✅ 강점 (목→성장, 화→빛남, 토→한결같음, 금→단단함, 수→흐름) |
| 강한 십성 (2회 이상) 상위 3개 | ✅ 강점 (10개 십성 각각 결 매핑) |
| 십성 과다 (3회+) | ⚠️ 주의 (겁재→고집, 편관→팽팽, 상관→튀는) |
| 약한 오행 (<10%) 하위 2개 | ⚠️ 주의 (각각 약한 결로 변환) |
| 균형형 (강 오행 0개) | 상위 2개 오행으로 보충 |

최대 6장. 강점 먼저, 같은 카테고리 안에서는 score 큰 순.

## 💞 인연 사주 (5개 카테고리, 기획 단계)

### 카테고리 정의

| 카테고리 | 핵심 질문 | 사주 분석 포인트 |
|---|---|---|
| 💑 연인 | "더 깊어질 수 있나?" | 일간 관계 + 일지 합·충 + 오행 보완 + 다음 대운 |
| 💍 배우자 | "결혼생활 어디가 통하고 어디가 갈등?" | 일지(배우자궁) 깊이 + 평생 흐름 + 자녀 인연 |
| 💔 전 연인 | "왜 헤어졌고 다시 만나도 되나?" | 헤어진 시기 대운 + 충의 본질 + 재회 가능성 |
| 🌸 썸남/썸녀 | "관계 시작해도 될까?" | 첫인상 케미 + 단기 vs 장기 가능성 |
| 🍀 짝사랑 | "고백할 가치가 있나? 가능성?" | 일간 끌림 + 오행 매칭 + 타이밍 (대운 진입 여부) |

### 짝사랑 정책
- 상대 생년월일 **필수**
- 진입 시 안내 박스: *"깊이 있는 풀이를 위해 두 분의 사주를 함께 봐야 합니다. 상대의 생년월일이 꼭 필요해요."*
- 정보를 모르는 사용자는 안내 후 이탈 유도 (만족도·후기 퀄리티 보호)

### 톤
- 연인·배우자: 따뜻한 코칭 톤
- 전 연인: 차분한 정리 톤
- 썸·짝사랑: 설레면서도 객관적인 톤

## 🔤 호칭 가이드라인

자녀를 부를 때:
- ✅ **호민이** (받침 + 이) — 가장 권장
- ✅ **호민** (이름만) — 깔끔
- ❌ **이호민** (성+이름) — 거리감, 의료·법률 톤
- ❌ **자녀·아이** — 일반화, 개인화 효과 ↓

받침 자동 판정:
- 받침 있음 (호민, 영현, 다은) → 이름 + "이"
- 받침 없음 (지수, 채아) → 이름만
- 이미 "이"로 끝남 (진이) → 그대로

## 📝 AI 프롬프트 핵심 원칙

[`app/api/compatibility/route.ts`](../app/api/compatibility/route.ts) 의 `buildCompatPrompt`에서:

### 작성 원칙 (11개)
1. 결혼·연애·이성적 매력 표현 금지 (부모-자녀 분석)
2. 점쟁이 톤 X, 양육 코칭 톤 O
3. 약점은 "단점"이 아닌 "개성·캐릭터"로
4. 인물 예시는 실존 유명인 X, 한국사·문학 캐릭터 O
5. 발달심리학 프레임은 단순 인용 X, 실제 적용 O
6. 마크다운 형식: `#`=부, `##`=장, `###`=소제목
7. 자녀는 호칭 (이름 + 이) 으로
8. 각 소제목 3~5문장
9. **압축형 라벨 불릿 절대 금지** (좋은 예/나쁜 예 직접 명시)
10. 사주 용어 처음 등장 시 한 줄 풀이 강제
11. 데이터 단순 나열 X, 일상 장면으로 묘사

### 연령별 톤 자동 주입
연령 카테고리의 `reportToneInstruction` 이 프롬프트 상단에 자동 삽입됨 → 미스매치 콘텐츠 방지.
