3. 캐릭터 매핑 (M0)
3.1 M0a — 여자 6캐릭터 (내적 이미지만, 외모·스펙 X)
#   캐릭터   내적 이미지   사주 신호
1   옥순   자유분방·솔직 직진녀   식상(食傷) 강 + 도화살(桃花) + 양일간
2   현숙   쿨·시크 차도녀·완벽주의   편관(偏官)+식상 결합 + 도화 일부 + 양일간
3   정숙   강단·성숙·안정·차분   정관(正官)+인성(印星) 안정 + 재성(財星) 결합
4   순자   활발·애교·감수성·마이웨이   식상 강 + 음일간 + 비겁(比劫) 활성
5   영숙   참한·맞춰주는·다정·부드러운   정관+식상 균형 + 인성 결합
6   영자   무난·평범·따스함·일상적   재성+정관 안정 + 균형 사주 (fallback)
3.2 M0b — 남자 5캐릭터 (내적 이미지만)
#   캐릭터   내적 이미지   사주 신호
1   영철   자신감·매력 자연스러운   식상 강 + 도화 + 양일간
2   영호   포용력·외향·인싸·점잖   정관 + 식상 + 비겁 결합
3   광수   이지적·진중·깊이·신중   인성 강 + 정관 + 깊이 있는 결
4   영수   중후·진중·안정·든든한   정관·인성 안정 + 중후한 결
5   상철   무난·편안·밸런스·부담 없는   균형 사주 + 재성·식상 안정 (fallback)

여자 6명
1순위: 식상 강 + 도화살 + 양일간 → 옥순
2순위: 편관+식상 결합 + 도화 일부 → 현숙
3순위: 정관+인성 안정 + 재성 결합 → 정숙
4순위: 식상 강 + 음일간 + 비겁 활성 → 순자
5순위: 정관+식상 균형 + 인성 결합 → 영숙
6순위 (fallback): 그 외 → 영자
남자 5명
1순위: 식상 강 + 도화 + 양일간 → 영철
2순위: 정관 + 식상 + 비겁 → 영호
3순위: 인성 강 + 정관 + 깊이 → 광수
4순위: 정관·인성 안정 + 중후 → 영수
5순위 (fallback): 균형 + 재성·식상 안정 → 상철
