순서 1장 → 3장 → 4장 → 2장 → 5장 → 6장으로 재정렬. 흐름이 더 자연스러워짐 (자기 진단 → 짝꿍 → 회고 → 미래 시기 → 친밀 → 편지).

## 📐 새 흐름 — 왜 이 순서가 자연스러운가

```
1장 내 매력 (본인 자가 진단)
   ↓ "내가 어떤 결의 사람인가" 알았으니
3장 내 짝꿍 (짝꿍 진단)
   ↓ "내 짝꿍은 어떤 결인가" 알았으니
4장 반복 패턴 (과거 회고·자가 성찰)
   ↓ "왜 못 만났는지" 짚었으니
2장 사랑타이밍 (미래 시기 예고)
   ↓ "언제 만날 수 있을지" 단언
5장 19금 (친밀의 결)
   ↓ "만나면 어떻게 깊어질지"
6장 편지 (마무리 종합)
```

→ **자기 → 짝꿍 → 과거 → 미래 → 친밀 → 종합** 자연 흐름.

## 📊 기존 순서 vs 새 순서 비교

| 항목 | 기존 (1→2→3→4→5→6) | 새 순서 (1→3→4→2→5→6) |
|---|---|---|
| 흐름 | 본인 → 시기 → 짝꿍 → 반복 → 친밀 → 편지 | 본인 → 짝꿍 → 반복 → 시기 → 친밀 → 편지 |
| 후킹 위치 (1·3·6장) | 1번 / 9번 / 22번 | 1번 / 8번 / 22번 |
| 후킹 간격 | 시작·중반·끝 (균등) | 시작·1/3지점·끝 (더 빠른 후킹) |
| 자가 성찰 (4장) 위치 | 중반 후 | 짝꿍 직후 (회고 자연 연결) |
| 시기 챕터 (2장) 위치 | 본인 직후 | 회고 후 (과거 후 → 미래로 전환) |
| 인스타 캡쳐 흐름 | 본인 캐릭터 → 시기 → 짝꿍 캐릭터 | **본인 캐릭터 → 짝꿍 캐릭터 (빨리 후킹)** → 회고 → 시기 |

→ **새 순서는 후킹 2번을 더 빨리 연달아 발산** (1번 1장 첫 + 8번 3장 첫). 인스타 공구 컨버전에 유리.
