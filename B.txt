## II. ② 근거 단락 — 인자 압축 룰 (변경 없음)

### A. 인자 4분류

| 분류 | 정의 | 생략 가능? |
|---|---|---|
| 🔴 **1차 인자** | Lead 결론의 정체를 정의하는 인자 (없으면 결론이 떠 보임) | **불가** — 반드시 노출 |
| 🟡 **보강 인자** | 결론을 더 깊게 뒷받침. 1차만으로도 결론 성립 | 권장 노출, 양보 가능 |
| 🟢 **흡수 인자** | 노출된 상위 인자에 부분 포함 | 생략 OK |
| 🟢 **카테고리 중복 인자** | 노출된 인자와 같은 카테고리·작용 | 대표 1개만 노출, 나머지 생략 |

### B. 압축 룰

| 조건 | 룰 |
|---|---|
| 핵심 인자 ≤ 3개 | 단락에 모두 노출 |
| 핵심 인자 ≥ 4개 | 단락엔 **2~3개만** 자연스럽게 녹임 |
| 우선 노출 기준 | ① 1차 인자 / ② 처음 등장 인자 / ③ 종류 분산 |
| 이전 챕터 등장 인자 | 단락 텍스트에서 생략 (풀이 로직은 유지) |

### C. 생략 결정 트리

```
인자가 단락 노출 후보일 때
│
├─ Lead 결론의 정체를 정의하는가?
│   ├─ YES → 🔴 1차 인자
│   │   ├─ 이전 챕터 등장 X → 반드시 노출
│   │   └─ 이전 챕터 등장 O → 한자 노출 X, 결론 회수 패턴으로 암묵적 회수 ★
│   │
│   └─ NO → 보강·흡수·중복 인자
│       ├─ 상위 인자가 흡수 → 🟢 생략 OK
│       ├─ 같은 카테고리 대표 있음 → 🟢 생략 OK
│       ├─ 이전 챕터 등장 → 🟢 생략 OK
│       └─ 그 외 → 🟡 노출 권장, 양보 가능
```

### D. 암묵적 회수 패턴 (1차 인자 생략 시)

| 패턴 | 형태 | 예시 |
|---|---|---|
| 결론 회수형 | "앞서 말씀드린 ㅡㅡ 결을 떠올려 보세요" | "앞서 말씀드린 환한 빛의 결을 한 번 떠올려 보세요" |
| 전제 회수형 | "이 결을 가지신 분에게 사주가 함께 새겨둔" | (이전 챕터 결론을 전제로 진행) |
| 짧은 인용형 | "강한 빛의 결을 가지신 만큼" | (한자 없이 의미만) |

## III. 단락 간 연결어미 룰 (변경 없음)

### A. 슬롯별 권장 연결어미

| 위치 | 카테고리 | 권장 표현 |
|---|---|---|
| **① → ②** | 인과형 | "그 결의 바탕에는", "그 결의 근거는", "이러한 결을 지니신 이유는" |
| **① → ②** (1차 인자 회수 시) | 회수+인과 | "앞서 말씀드린 ㅡㅡ 결을 떠올려 보세요" |
| **② 안 인자 사이** | 첨가형 | "여기에 ~까지 함께 자리해", "그리고 ~이 더해져", "이와 함께 ~이 놓여 있어" |
| **② → ③** | 비유 도입형 | "이 결을 자연에 빗대보면", "비유하자면", "마치 ~처럼" |
| **③ → ④** | 장면 전환형 | "이 결이 가장 잘 보이는 자리는", "그 모습은 일상에서 이렇게 켜져요", "예를 들어 ~ 자리에서는" |
| **④ → ⑤** | 전환·반전형 | "다만", "그렇다고 ~만은 아니에요", "한편으로는", "안쪽 결을 들여다보면" |
| **⑤ → ⑥** | 요약·재단언형 | "그래서 이○○님은,", "결국", "한 마디로 말씀드리면", "이렇게 정리하면" |
| **⑥ 안 미끼** | 호기심 유발형 | "다만 ~ 순간에는 또 다른 결이 켜져요 →", "이 결은 다음 자리에서 보여드릴게요 →" |

### B. 카테고리별 정의

| 카테고리 | 역할 |
|---|---|
| 인과형 | 앞 단락의 결론을 받아 그 이유를 풀이로 연결 |
| 회수+인과 | 이전 챕터 결론을 한자 노출 없이 끌어와 새 단락의 인과 시작 |
| 첨가형 | 단락 안에서 인자나 풀이를 자연스럽게 더함 |
| 비유 도입형 | 사주 풀이 → 자연 비유로 전환 |
| 장면 전환형 | 추상 → 구체 일상 장면으로 전환 |
| 전환·반전형 | 표면 결 → 이면 결로 전환 (단조로움 해소) |
| 요약·재단언형 | 풀이 흐름을 마무리하며 결론 재단언 |
| 호기심 유발형 | 페이지 끝에서 다음 페이지로 흐름 이어주기 |

## VI. ★ 캐릭터 후킹 룰 (신설)

### A. 캐릭터 직접 노출 위치 (3곳만)

| 페이지 순서 | 위치 | 캐릭터 노출 | 활용 캐릭터 |
|---|---|---|---|
| **1번** | 1장 "내 매력은?" Lead | 🔴 여자 매칭 직접 노출 | 옥순·현숙·정숙·순자·영숙·영자 중 1명 |
| **8번** | 3장 "내 짝꿍 미리 보기" Lead | 🔴 남자 매칭 직접 노출 | 영철·영식·영호·광수·영수·상철 중 1명 |
| **22번** | 6장 "마지막 편지" 종합 한 줄 | 🟡 두 캐릭터 종합 한 줄 | 매칭 여자 + 매칭 남자 결합 |

→ **나머지 19개 페이지 = 캐릭터 단어 0회**.

### B. 캐릭터 매칭 우선순위 캐스케이드 (No match 0%)

#### 여자 6명 캐스케이드
1. 식상 강 + 도화살 + 양일간 → **옥순**
2. 편관+식상 결합 + 도화 일부 + 양일간 → **현숙**
3. 정관+인성 안정 + 재성 결합 → **정숙**
4. 식상 강 + 음일간 + 비겁 활성 → **순자**
5. 정관+식상 균형 + 인성 결합 → **영숙**
6. (fallback) 그 외 → **영자**

#### 남자 6명 캐스케이드
1. 식상(상관) 강 + 도화 + 양일간 → **영철**
2. 정관 + 정인 + 식신 균형 + 음일간 → **영식**
3. 정관 + 식상(상관) + 비견 결합 → **영호**
4. 편인 강 + 정관 + 깊이 → **광수**
5. 정관·정인 안정 + 중후 → **영수**
6. (fallback) 균형 + 정재·식신 안정 → **상철**

### C. 후킹형 단락 구조

```
[① Lead — 캐릭터 매칭 단언]
이○○님은 ○○상의 결을 가진 분이에요.
(캐릭터 내적 이미지 한 줄 부연)

[② 근거 — 캐릭터 사주 신호 자연 인용]
그 결의 바탕에는 (캐릭터 1차 인자) 자리한 까닭이 있어요.
여기에 (보강 인자)까지 함께 더해진 결이에요.

[③ ~ ⑥ 표준형 흐름]
비유 → 실생활 → 이면 → Close
```

## VII. ★ V3 캐릭터 매트릭스 백그라운드 활용 룰 (신설)

### A. 6×6 매트릭스 — 캐릭터 단어 X, 결만 풀이에 작용

매트릭스 36칸은 **풀이 결의 톤·방향 결정**에만 사용. 캐릭터 이름은 노출 X.

| 매트릭스 작용 페이지 | 활용 방식 |
|---|---|
| 6번 끌리는 vs 잘 맞는 | 본인 행 6칸 분석 → 끌림(편관 쪽) vs 적합(정관 쪽) 결로만 풀이 |
| 11번 운명을 잡는 한 수 | 본인 칸 결 → 두 결 결합 행동 결로 풀이 |
| 12번 결혼이 가까워지는 자리 | 본인 칸 결 → 두 결 결합이 깊어지는 시기 톤으로 풀이 |
| 21번 깊어지는 분위기 | 본인 칸 결 → 친밀 결의 톤으로 풀이 |

### B. 매트릭스 풀이 결의 톤 분배 (참고)

| 본인 칸 결 예시 | 풀이 톤 |
|---|---|
| "빠르게 뜨거워지는 결" (옥순×영철) | 즉시 발화·빠른 속도 |
| "진심에 마음 여는 결" (현숙×영식) | 천천히·진중·정성 |
| "가장 안정된 결혼 적합" (정숙×영식) | 단단한·신뢰·장기 |
| "활기와 정성 시너지" (순자×영식) | 따스함·활기·다정 |
| "둘 다 바른생활 가장 평화" (영숙×영식) | 평온·일관·부드러움 |
| "따스하고 부담 없는 결" (영자×영식) | 일상·편안·자연 |

→ 캐릭터 단어 노출 X. 결의 결로만 풀이.

## VIII. 누적 룰 11개 요약 ★

| 룰 | 내용 |
|---|---|
| 1 | **6단락 표준형 짜임** — Lead → 근거 → 비유 → 실생활 → 이면 → Close |
| 2 | **이중 두괄식** — 페이지 첫 줄 + 각 단락 첫 줄에 결론 |
| 3 | **② 근거 단락** — 인자 분리 단락 X, 하나의 흐름으로 |
| 4 | **인자 압축** — 4개 이상이면 단락엔 2~3개만 노출 |
| 5 | **챕터 간 중복 회피** — 이전 챕터 명시 인자는 단락에서 생략 (풀이 로직은 유지) |
| 6 | **단락 간 연결어미** — 8개 위치 × 카테고리별 표현 |
| 7 | **톤 유지** — "~에요/지요" / 한자 괄호 / 자연 비유 |
| 8 | **생략 판정** — 1차 인자는 보존, 보강·흡수·카테고리 중복만 생략 |

## X. 룰 적용 예시 — 후킹형 (1번 페이지 "내 매력은?") ★

```
[① Lead — 후킹형 캐릭터 매칭 단언]
이○○님은 옥순상의 결을 가진 분이에요.
자유분방하고 솔직한, 자신의 마음을 그대로 표현하시는 분이지요.

[② 근거 — 캐릭터 사주 신호 + 본인 사주 인자 자연 인용]
그 결의 바탕에는 식상(食傷)이 강하게 자리한 까닭이 있어요.
여기에 도화살(桃花)이 함께 놓여 있어, 평소부터 매혹의 결을
은은하게 발산하는 결이지요. 양일간(陽日干)의 활기까지 더해져
주변을 환하게 밝히는 결을 가지셨어요.

[③ 비유 — 자연 비유]
이 결을 자연에 빗대보면, 한낮의 들판에 핀 붉은 꽃처럼 굳이
손을 흔들지 않아도 시선이 모이고, 그 결을 따라 사람이 다가오는
분이에요.

[④ 실생활 — 일상 자리 2~3장면]
이 결이 가장 잘 보이는 자리는 일상 곳곳이에요. 카페에 친구들과
앉아 계실 때, 분위기를 주도하며 환한 미소로 그 자리의 중심이
되시지요. 처음 보는 사람과 인사를 나누는 순간에도, 솔직한
한 마디로 상대의 마음을 한 박자 빨리 여는 결을 만들어주세요.

[⑤ 이면 — 다만]
다만 그 환한 결의 안쪽에는, 사랑할 때 누구보다 깊이 빠지는
직진의 결도 함께 자리해 있어요. 평소의 자유분방함과 다른
한 면이지요.

[⑥ Close — 재단언 + 미끼]
그래서 이○○님 매력의 본질은, 옥순상 솔직 직진의 결이에요.
다만 이성 앞에서는 이 결이 또 다른 모습으로 켜져요 →
```

→ **룰 10 후킹 적용** (Lead에 캐릭터 직접 노출) + 룰 1~9 모두 적용.

## XI. 룰 적용 예시 — 표준형 (2번 페이지 "이성이 처음 보는 나의 결") ★

```
[① Lead — 두괄 (캐릭터 단어 X)]
이○○님이 이성 앞에 처음 섰을 때, 가장 먼저 비치는 결은
환한 자신감이에요.

[② 근거 — 인자 자연 인용 (캐릭터 단어 X)]
그 결의 바탕에는 일주(日柱)의 양일간이 자리한 까닭이 있어요.
여기에 도화살(桃花)이 외형에 자연스럽게 비쳐, 표정과 눈빛에서
은은한 매혹이 흐르는 결이지요.

[③ 비유]
이 결을 자연에 빗대보면, 한낮 햇볕이 닿은 강물처럼 잔잔하면서도
반짝임이 멈추지 않는 결이에요.

[④ 실생활]
이성과 처음 마주한 자리, 이○○님의 미소가 먼저 한 결을
만들어주시지요. (~)

[⑤ 이면 — 다만]
다만 이 첫인상은 평소의 결과 사뭇 달라, 가까이 다가올수록
또 다른 결이 드러나기도 해요.

[⑥ Close]
이것이 이성이 이○○님을 처음 본 그 1초의 결이에요.
이 결이 썸 단계에 들어가면 어떻게 바뀔까요 →
```

→ **룰 10 적용 (캐릭터 단어 X)** + 룰 1~9 모두 적용.

## XII. 본문 작성 워크플로 ★

```
1. 페이지 변형 패턴 결정 (IX 표 참조)
   ↓
2. 캐릭터 노출 위치인가? (룰 10)
   ├─ YES (1번/8번/22번) → 후킹형 Lead에 캐릭터 단언
   └─ NO → 표준 Lead (캐릭터 단어 X)
   ↓
3. 매트릭스 백그라운드 작용 페이지인가? (룰 11)
   ├─ YES (6번/11번/12번/21번) → 본인 칸 결의 톤으로 풀이
   └─ NO → 본인 사주 인자만으로 풀이
   ↓
4. ② 근거 단락 — 인자 압축 (룰 4·5·8)
   ├─ 4개 이상 → 2~3개만
   ├─ 이전 챕터 등장 인자 → 생략
   └─ 1차 인자 생략 시 → 룰 9 암묵적 회수
   ↓
5. 연결어미 8개 위치 모두 적용 (룰 6)
   ↓
6. 이중 두괄식 (룰 2) — 페이지 첫 줄 + 각 단락 첫 줄 결론
   ↓
7. 톤 (룰 7) — "~에요" / 한자 괄호 / 자연 비유 / 직접 호명
```
