## 4-2. 사주 인자 박스 카드 6개 (8-a, 8-b) — 2026-05-17 신규

> 본인 결정 (2026-05-17): 한눈에 보기 쉬운 시각 자산 보완.
> 부모 6축 점수는 본문 노출 X지만, **부모 사주 본기 인자 6개를 박스 카드로 시각화**.
> 인싸이트 8박스 카드 톤 카피 + 사주 정체성 강화.

### 사양

- 인자 6개 박스 카드 그리드 (2×3 또는 3×2)
- 각 박스 구성:
  - 인자명 (한자 병기) — 예: "정인(正印)"
  - 결의 별 한 줄 — 예: "받쳐주는 결의 별"
  - 명리 강도 막대 (0~100) + 라벨 (옅음/평이함/강함)
  - 명리 원전 인용 1구절 (선택)
- 8-(a) 페이지: 어머님 사주 8자 박스 (상단) + 인자 박스 카드 6개 (중단) + 본문 산문 (하단)
- 8-(b) 페이지: 동일 (아버님)

### 6개 인자 선택 (고정 셋)

| 인자 | 한자 | 결의 별 | 명리 의미 |
|---|---|---|---|
| 정인 | 正印 | 받쳐주는 결의 별 | 자기를 받쳐주는 본질 (적천수) |
| 식신 | 食神 | 표현의 결의 별 | 일주의 빛이 부드럽게 밖으로 (적천수) |
| 정관 | 正官 | 절제의 결의 별 | 자기를 절제하는 별 (자평진전) |
| 정재 | 正財 | 결과의 결의 별 | 결과·성취의 별 |
| 양인 | 羊刃 | 결단의 결의 별 | 일간의 가장 강한 발현 (적천수) |
| 조후 | 調候 | 한열조습 균형 | 일주의 안정 (궁통보감) |

### 강도 산출 — 3단 공식 ①번 그대로 활용

`2_child_6factors.md` 1단계 명리 강도 산출법 그대로:

```
인자 명리 강도 = 
  (월령 사령 보정) + (통근 보정) + (투출) + (글자 수) 
  × (왕상휴수사 보정)
  → clamp(0, 100)
```

3구간 절단:
- **옅음**: 0~40
- **평이함**: 41~65
- **강함**: 66~100

조후·양인은 별도 산출법 (`2_child_6factors.md` 참조).

## 8. 동물 캐릭터 셋 (B-1 작명)

### 7동물 — 12지 6동물 + 균형형 1동물

| 동물 | 본기 요인 | 명리 출처 | 결 한 줄 (STS 양극 키워드) |
|---|---|---|---|
| **호랑이의 결** | 활기 | 양목(寅) 양인 결단 | 활동량이 많고 대근육 활동을 선호하는, 도전적이고 적극적인 결 |
| **토끼의 결** | 조심 | 음목(卯) 신중 | 조심성이 많고 수줍어 하는, 안전을 중시하는 결 |
| **말의 결** | 만족 | 양화(午) 양기 사교 | 낙관적이고 유쾌한, 만족스러운 결 |
| **돼지의 결** | 흔들림 | 양수(亥) 깊은 정서 | 예민하고 민감한, 감정에 충실한 결 |
| **양의 결** | 어울림 | 음토(未) 받아들임 | 공감적이고 사교적인, 분위기를 잘 읽는 결 |
| **소의 결** | 끈기 | 음토(丑) 인내·꾸준 | 인내심이 강하고 끈기 있는, 부지런한 결 |
| **용의 결** | 균형형 | 양토(辰) 중심·받쳐줌 | 모든 결이 두루 균형 잡힌, 고른 결 |

### 동물 매칭 룰

```ts
function matchAnimal(scores: FactorScore[]): Animal {
  const allMid = scores.every(s => s.score >= 41 && s.score <= 65);
  if (allMid) return '용';
  
  const max = scores.reduce((a, b) => (a.score > b.score ? a : b));
  if (max.score <= 65) return '용'; // max도 중간이면 균형형
  
  switch (max.factor) {
    case 'hwalgi':  return '호랑이';
    case 'salpim':  return '토끼';
    case 'hwanham': return '말';
    case 'jjitum':  return '돼지';
    case 'eoullim': return '양';
    case 'dajaeum': return '소';
  }
}
```

## 9. 동물 일러스트 발주 (미정)

### 발주 방식 옵션

| 방식 | 장점 | 단점 |
|---|---|---|
| **외주 디자이너** (크몽·라우드소싱) | 일관성 ↑, 브랜드 자산 | 비용 70~150만원, 시간 2~4주 |
| **AI 생성** (Midjourney·SDXL·Imagen) | 빠름, 저비용 | 캐릭터 일관성 ↓ |

│ 김수민 양의 동물 유형을 정해드렸어요.        │
│ 함께 강하게 자리한 결도 양 유형의 결을      │
│ 더 깊게 만듭니다.                          │
└─────────────────────────────────────────┘
```

#### 13-2. 매칭 점수 시각 (bar-row 재활용 + 라벨 변형)

```
어울림 [━━━━━━━━░░] 78  가장 두드러짐  ← 매칭 본기
흔들림   [━━━━━━━━░░] 75  함께 깊음
조심   [━━━━━━━━░░] 72  함께 깊음
```

- bar-row 3개 (상위 3요인 점수 sorted)
- 색은 각 요인 고유 색 (어울림 분홍·흔들림 보라·조심 초록)
- bar-label은 기존 "낮음/중간/높음" 대신 **"가장 두드러짐 / 함께 깊음"** 으로 변형
- 매칭 본기 1개 + 보조 2개 = 합 3개
- 하단 종합 한 줄 문장:
  > "어울림이 가장 두드러져 양의 결이 본 유형으로 정해졌고, 흔들림과 조심이 함께 강하게 자리해 받쳐주는 결·깊이 느끼는 결·신중한 결이 모이는 자리가 만들어집니다."

#### 13-3. 동물 컷 박스 (신규 인라인 스타일)

```
┌─ 그라데이션 박스 (동물 색 0% → 흰색 100%) ─┐
│                                          │
│              🐑 (54px)                   │
│       김수민 양은 양의 결                  │
│   받쳐주는 기운 + 깊이 느끼는 결           │
│      + 신중한 결이 모이는 자리             │
│                                          │
└──────────────────────────────────────────┘
```

- 배경: `linear-gradient(135deg, [동물색 강]0%, #fff5f7 100%)`
- 동물 emoji 54px (p.4의 72px보다 작게)
- 동물 이름 15px bold
- 결 조합 한 줄 12px

#### 13-4. "○○ 유형 아이는…" 박스 (strength-box 재활용)

- 헤더: "🌸 ○○ 유형 아이는…"
- ul 4~5개 bullet (자녀 일상 모습 톤, STS 양극 키워드 흡수)

#### 13-5. "이런 점은 유의해 주세요" 박스 (care-box 재활용)

#### 13-6. 양육 코칭 박스 (tip-box 재활용 + 3축)

│ 👨‍👩‍👧 ○○의 결 자녀를 위한 양육 코칭     │
│                                          │
│ ┌─ tip-item ────────────────────────┐   │
│ │ 🕐 시간 — 감정을 비울 수 있는 ...  │   │
│ │ [본문 100~150자]                   │   │
│ └────────────────────────────────────┘   │
│ ┌─ tip-item ────────────────────────┐   │
│ │ 💬 소통 — 자기 감정과 친구 감정... │   │
│ └────────────────────────────────────┘   │
│ ┌─ tip-item ────────────────────────┐   │
│ │ 🌿 환경 — 안전하고 예측 가능한 ... │   │
│ └────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

- 3축 (시간·소통·환경) 강제 (6요인 챕터 (c) 양육 Tip 박스와 동일 패턴 — 룰 18)

## 14. v1.7 — 동물 노출 단일화 (p.1 이모지 + p.4 폐기)

### 배경

### 14-1. p.1 표지 — 동물 이모지(🐑) 제거

기존 cover 영역의 `<div class="emoji">🐑</div>` 자산 제거. 표지는 title + subtitle + info + 자도인 마크만 표시.

```
[v1.6까지]              [v1.7부터]
🐑                       (이모지 없음)
김수민 양의 결            김수민 양의 결
사주 6요인 + ...          사주 6요인 + ...
검사일 ...                검사일 ...
— 자도인 —                — 자도인 —
```

이유: 표지에서 동물 정체성을 노출하면 종합 해석 페이지(p.10)의 임팩트가 분산. 동물은 본문 안에서, 종합 단계에서 한 번만 노출.

### 14-2. p.4 동물 캐릭터 페이지 폐기

기존 p.4 동물 캐릭터(인사 컷) 페이지 전체 삭제. v1.6의 "p.4 ↔ p.11 시각 차원 분리" 룰 폐기. 폐기 후 후속 페이지 모두 -1 (5~10 → 4~9, 11 → 10, 12 → 11, ..., 18 → 17). 총 페이지 수 18p → **17p**.
