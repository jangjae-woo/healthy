## 3. AI 사주 정확도 한계 — **업계 보편 인정**

- 컴투스온 분석: "AI는 명리학 논리를 깨우친 것이 아니라 빈도 높은 문장 패턴 암기"

## 4. STS 6요인 + 사주 매핑 사례 — **없음**

검색 결과 **STS 6요인 기질검사를 사주와 매핑한 상업 서비스 없음**. 인싸이트가 STS 단독으로 판매 (영아용·유아용 분리).

→ **우리 SKU의 STS + 사주 매핑은 진짜 시장 차별축**. 단점도 있음:
- STS 표준화 = 인싸이트 코호트 기반. 우리는 사주 매핑이라 STS 표준화와 다름
- "STS 6요인" 이름만 차용 시 인싸이트 저작권 위험

→ Phase 0-Z에서 v2.0 룰 30(저작권 회피)으로 결정한 게 정확.

## 6. 진짜 적용 가능한 발견

### 발견 1 — 점수 노출 톤다운이 시장 표준

봄날의해답·사주쏙쏙도 점수 수치보다 본문 풀이 위주. **점수 분포 쏠림 문제를 시장은 점수 노출 톤다운으로 우회**.

→ 우리도 **옵션 X(하이브리드)** 가장 시장 친화적.

### 발견 2 — 점수 표시 시 신뢰성 확보 필요

점수 명시 시 사용자가 분포 인지 가능. 통계 표준화 없으면 트집 잡힘.

→ 옵션 X에서 "점수는 명리학 강도 표시이지 STS 표준 점수가 아님" 디스클레이머 추가 권고.

### 발견 3 — 한국 명리계 비율 가이드

년 20% / 월 40% / 일 20% / 시 20% — 이걸 우리 위치 가중치에 참고 가능:

| 우리 가중치 | 한국 명리 통설 |
|---|---|
| 일간 1.0 / 월령 1.0 / 일지 0.8 / 월간 0.7 / 시 0.5 / 연 0.4 | 월 40% > 일·시·연 각 20% |
| 합 = 4.4 | 합 = 100% |

비율 환산:
- 우리: 월 23% / 일 21% / 시 18% / 연 9.5% 등
- 명리 통설: 월 40% / 일·시·연 각 20%

→ **우리 월령 가중치가 명리 통설보다 낮음**. 분포 쏠림 원인일 수도. 월령 가중치 1.0 → 1.5로 강화 + 다른 위치 약화 = 명리 통설 수렴 시 분포 개선 가능.

### 발견 4 — FengShuiOCD 25점 시스템

- 위치별 점수 합 = 25
- 임계값 13 = 50% 이상이면 강

→ 우리도 **본기 가산 항목 합 상한을 두고 임계값 50% 기준 적용** 시 분포 안정 가능.

### 발견 5 — 산업 표준이 없다는 사실 자체가 차별축

봄날의해답·사주쏙쏙 다 같은 상태. **우리가 표준 만들면 차별축 확보**.

## 7. 종합 권고

### 시장 검증된 패턴 따라가기

1. **점수 노출 톤다운** — 시안 시각(레이더·바)은 유지, 본문은 본기 인자 매핑 위주 (옵션 X)
2. **위치 가중치 명리 통설 수렴** — 월령 1.0 → 1.5로 강화, 분포 개선
3. **본기 가산 항목 동시 적용 제한** — ≤2개 본기만 가산 (분포 쏠림 차단)
4. **디스클레이머 강화** — "STS 6요인은 학술 기질 척도 + 사주 매핑은 명리 통설로 재구성한 양육 안내"

### 시장에 없는 차별축 강화

1. **STS + 사주 + 동물 + 부모 양육 결합** — 우리만 있는 차별축
2. **결정론 + LLM 분리** — AI 정확도 한계 극복
3. **모바일 17p 친화** — PDF 60p 대비 짧고 강력

### 빅 결정 형에게 보고

검색 결과 = **사용자 우려가 학계·산업 보편 문제임을 확인**. 형이 받아들이기 쉬운 톤:

> 분포 쏠림은 우리 공식만의 문제가 아니라 사주 점수화의 보편 한계.
> 상업 서비스는 점수 노출 톤다운으로 우회.
> 우리도 동일 전략(옵션 X 하이브리드) 채택 시 시장 표준 진입.
> 단 위치 가중치 명리 통설 수렴 + 본기 동시 가산 제한 = 분포 개선 1단계.
