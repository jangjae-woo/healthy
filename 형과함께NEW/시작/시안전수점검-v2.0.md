## 4. 8-(d) 매트릭스 카드 4개 정밀 검증

매트릭스 카드 헤더·서브 줄은 결정론 매핑 결과. 명리 정합성보다 점수 산출이 정확한지가 핵심.

| 카드 | 서브 줄 점수 | 검증 |
|---|---|---|
| 시너지 1: "어머님 안정시키는 자리" | 어머님 받쳐주는 기운 80 × 자녀 깊은 정서 75 | 어머님 인성 본기 점수 = 편인 통근 강 → 80 정합 가능, 자녀 흔들림 75 = 자녀 사주 검증 필요 |
| 시너지 2: "어머님 한결같음" | 어머님 안정의 기운 70 × 자녀 깊은 정서 75 | 어머님 일관 = 토 오행 + 관인상생. 토 2(戊·辰) + 관인(편관 약 + 인성 강) = 70 정합 가능 |
| 시너지 3: "아버님 기준이 끈기 받쳐줌" | 아버님 절제하는 기운 82 × 자녀 끈기 68 | 아버님 관성 = 편관(칠살) 약 + 정관 X. **편관 약하면 82 점수 불가**. **오류 가능성** |
| 충돌 4: "아버님 기대" | 아버님 결과 기대 75 × 자녀 신중 72 | 아버님 재성 = 정재 강(乙·乙 천간) + 편관 = **바람 본기 정합**. 75 정합 가능 |

→ **시너지 3 카드의 아버님 절제 기운 82점은 명리 정합 의심**. 아버님 사주에 정관 없음(편관만 있음). v2.1 점수 재산정 필요.

## 5. 자녀 사주 fixture 후보 검증

### 후보: `壬子年 庚申月 乙亥日 戊寅時`

| 검증 항목 | 결과 |
|---|---|
| 일간 乙木 | ✓ 시안 명시 |
| 정인·편인 강 (어울림 본기) | 壬(정인) + 子 본기 癸(편인) + 亥 본기 壬(정인) → 인성 천간 1 + 지지 2 = 매우 강 ✓ |
| 정관 강 (조심·끈기 본기) | 庚(정관, 음↔양) + 申 본기 庚 → 정관 천간 1 + 지지 1 = 강 ✓ |
| 일지 합 (어울림 본기) | 亥 + 寅 = 寅亥합 ✓ |
| 천을귀인 (어울림 상조) | 을일간 천을귀인 = 子·申. **둘 다 있음** ✓ 매우 강 |
| 한열 편중 (만족 본기 감산·흔들림 본기) | 수 3(壬·子·亥) + 금 2(庚·申) + 토 1(戊) + 목 1(乙) + 화 0 = **음기 편중** ✓ |
| 충 (흔들림 본기) | 寅申충 ✓ |
| 양인 자리 X (활기 본기 미충족) | 을목 양인 = 寅. 시지 寅 → **양인 자리 있음!** ⚠️ |
| 식상 약 (활기·만족 본기 미충족) | 식상 = 화. 화 0 ✓ |
| 칠살 약 (흔들림 본기 약) | 칠살 = 양관 X (을목한테 정관 = 양금 = 庚, 편관 = 음금 = 辛). 사주에 辛 없음. 칠살 X ✓ |

### 문제 발견 — 양인 자리 있음 (寅)

을목의 양인 = 寅(인목). 후보 사주 시지 = 寅 → **양인 자리 있음**.

영향:
- 활기 본기 = 식상+양인+신강. 양인 시지 있으면 활기 점수가 30보다 높을 가능성
- 단 양인이 일간 옆이 아니라 시지에 있어 영향 약함
- 신강 = 인성 강 + 비견(寅) 1 → 신강
- 식상 = 0
- 활기 = -음일간(-0.5) + 신강 + 양인 시지(약) + 수오행 강(-0.5) + 식상 0 + 12운성 = 변수 많음
- 추정 활기 점수: 30~50 (시안 30 재현 가능성 50%)

### 수정 후보: `壬子年 庚申月 乙亥日 戊辰時`

시지 寅 → 辰으로 변경:
- 戊辰 = 정재 + 정재 통근
- 일지 亥 + 시지 辰 = 합 X (亥辰 = 무 관계)
- 양인 = X ✓
- 일지 합 = X ❌ (어울림 본기 일지 합 본기 미충족)

→ 일지 합 본기 미충족이 더 큰 문제 (어울림 78 재현 X).

### 대안 후보: `壬寅年 庚戌月 乙亥日 戊子時`

- 壬寅: 정인 + 비견(寅=을목 양인) ← 양인 寅이 년지에 있음 (일간 옆 아님, 영향 약)
- 庚戌: 정관 + 정재(戌 본기 戊)
- 乙亥: 일주
- 戊子: 정재 + 편인(子 본기 癸)

- 일지 亥 + 년지 寅 = 寅亥합 ✓ (어울림 본기)
- 천을귀인 = 子(시지) ✓
- 정인 = 壬 + 亥 + 子 = 강
- 정관 = 庚 + 戌 천간/지지 모두 ✓
- 양인 寅 = 년지 (약하게 작용)
- 식상 = 화 0
- 칠살 = X
- 한열: 수 3(壬·亥·子) + 금 2(庚·辛戌중) + 토 2(戊·戌) + 목 2(乙·寅) + 화 0 → 음기 편중
- 충: 寅(년지) + 申 = X (申 없음)

→ 충 없음. **흔들림 본기 충 미충족 (75점 재현 X 가능성)**

### 결론: 단일 사주로 시안 6점수 모두 ±2점 재현은 어려움

후보 산출 결과: 시안 점수가 너무 극단적(낮음 2개·높음 4개)이라 단일 사주로 정확 재현이 어려움. 옵션:
- **A**: 시안 점수를 ±5점 허용 범위로 조정 → 후보 사주 사용
- **B**: 시안 점수를 사주에 맞춰 재계산 (예: 활기 35, 흔들림 70 등)
- **C**: 점수 산출 공식의 정규화 상수를 조정 → 후보 사주로 시안 점수 정확 재현

→ **형 결정 필요**. 가장 깔끔한 건 B(시안 점수 재계산). 시안 점수는 fixture 산출 결과로 갱신.
