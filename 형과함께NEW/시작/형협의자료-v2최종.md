# 형에게 — 옵션 W 최종 권고 (2026-05-17 v2)

> **이전 v1 권고(옵션 X) 정정**. 사용자 의도 잘못 읽은 결과. 최종 권고 = **옵션 W (Y + X 하이브리드)**.

---

## 1. 사용자 원래 컨셉 (다시 확인)

```
[입력]            [매핑]            [출력]              [노출]
사주 인자  →  결정론 조합  →  STS 6요인  →  부모 친화 본문
인성·식상·         (점수 산출)      활기·조심·만족·       (양육 가이드)
관성·재성·                          흔들림·어울림·끈기
비겁·조후
```

= **인자는 입력 (명리 정확성), 6요인은 출력 (양육 친화 표현)**.

이게 시안 v1~v2.0의 핵심. 우리 SKU의 차별축 자체.

## 2. 현재 부딪힌 문제 (다시 확인)

### 진짜 만세력 100개 캘리브레이션 = 6/6 분포 위반
- 활기·조심·만족·흔들림·어울림·끈기 모두 낮음 0~1%
- 호랑이+소 합 72% 편중
- 자녀 점수가 다 50~80에 몰림 = 변별력 부족

### 진짜 원인
- 인자 → 6요인 매핑 공식의 본기 가산 항목 동시 적용 (3~5개)
- 가산 점수 큼 (각 50~100)
- 감산 비대칭
- 정규화 ÷6이 너무 약함

**문제 위치 = 매핑 공식만**. 6요인 자체나 시안 구조는 정상.

## 5. 옵션 W 핵심 — 6요인 유지

### 작업 1. 매핑 공식 정밀화
- 본기 가산 동시 ≤2개 제한 (한 사주에 3~5개 본기 동시 가산하던 거 제한)
- 본기 가산 점수 상한 30 (지금 50~100)
- 월령 가중치 1.0 → 1.5 (한국 명리 통설 수렴)
- 정규화 ÷6 → ÷10
- 감산 항목 대칭 강화

### 작업 2. 시안 시각 조정 (소폭)
- 6각 레이더 = **그대로 유지**
- 점수 바 = **숫자 노출 X. 강도 라벨만** (낮음·중간·높음)
- 양극 아코디언 = **그대로 유지**
- 6요인 챕터 = **그대로 유지**
- 6요인 명칭(활기·조심·만족·흔들림·어울림·끈기) = **그대로 유지**

### 작업 3. 분포 캘리브레이션 반복
- 100개 사주 → 분포 검증
- 6/6 위반 → 4/6 → 2/6 → 0/6 통과까지 반복
- 예상: 2~4회

---

## 6. 분포 통과 못 하면? → 안전망

- 점수 숫자 노출 톤다운 = 강도 라벨만 표시 (상업 서비스 표준)
- 분포는 내부 로직만, 사용자에겐 라벨만 보임
- = 옵션 X 우회 자동 적용 (최후 안전망)

## 8. 김수민 양 결정 (형 결정)

- 시안 사주(壬子 庚申 乙亥 戊寅 / 을목)와 **완전 다름**

## 10. 형 결정 카드 (3가지)

### Q1. 옵션 W 채택 동의?
- YES = 1주 안에 출시 준비. 시안 95% 보존
- NO = 옵션 Z (6요인 폐기, 1~2개월) 또는 출시 보류

### Q2. 김수민 양 가상 유지 동의?
- YES = 시안 점수·동물·매트릭스 그대로
- NO = 실제 만세력 사주로 갱신. 모두 재산출

### Q3. 분포 통과 못 하면 점수 숫자 노출 톤다운 동의?
- YES = 안전망 작동. 강도 라벨만 표시
- NO = 분포 통과까지 무한 캘리브레이션

**동생 권고: 모두 YES**.
