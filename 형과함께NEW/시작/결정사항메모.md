## 2026-05-17 검증 안정화 결정

### D1. 6요인 유지 + percentile 보정 채택

기존 `50 + sum / 6` 절대점수 방식은 낮음이 거의 안 나오고 동물 편중을 만들었다.

결정:
- 6요인 이름과 시안 구조는 유지.
- raw/base0 값은 내부 추적용으로 보존.
- 고객용 score는 percentile 위치값으로 사용.
- 고객에게는 숫자보다 `낮음/중간/높음`, `두드러진 편/은은한 편` 중심으로 표시.

### D2. 어울림 인성 중복 완화

결정:
- 어울림 본기에서 인성을 내리고, 일지 합/천을귀인/도화살 중심으로 재매핑.
- 인성은 상조로 유지.

근거:
- 인성이 조심·어울림·끈기에 동시에 강하게 작동해 여러 요인을 같이 끌어올리는 문제가 있었다.

### D3. 동물 매칭은 score 숫자보다 level 기준

결정:
- 모두 mid이거나 high가 없으면 용.
- top1~top3 차이가 6 이하이면 상위 비등.
- top1이 명확하면 해당 동물.

근거:
- percentile 보정 이후 숫자는 절대 강도가 아니라 표본 내 위치이므로, 고객용 분기는 `level`이 더 안전하다.

### D4. Edge case는 fixture 이름이 아니라 검증 의도로 관리

결정:
- “균형형 fixture”라고 부른 사주가 실제로 all-mid를 보장하지 않으면 실패로 보지 않는다.
- 동물 분기 규칙은 합성 factorScores로 직접 검증한다.
- 실제 fixture edge case는 “카드가 비지 않는가”, “천간합 우선이 지켜지는가”처럼 행동 중심으로 검증한다.

### D5. 이관 전까지 본 프로젝트 운영 코드 수정 금지

결정:
- 현재 작업 범위는 `C:/Users/new/Desktop/saju/형과함께NEW/시작`.
- `saju-site` 본 프로젝트 이관은 사람 눈 QA와 형 검토 뒤에만 시작.

### 2. 두 차원 혼재 (일간 직접 vs 자녀 사주 인성궁) — 분리 명시 필요
- **차원 A**: 자녀 일간 vs 부모 일간 오행 관계 (정확한 명리 룰)
- **차원 B**: 자녀 사주 안 인성(어머니궁)/정관(아버지궁) 자리 (정확한 명리 룰)

- **판정**: LLM 프롬프트에서 두 차원 명확 구분 강제. 자연 비유는 부드러운 톤, 차원 B는 명리 정합 톤.

### 3. 활기 본기 = 식상+양인+신강 — 명리 정합 ✓
- 식상 = 일주가 밖으로 흐르는 기운 ✓ 신체 활동량
- 양인 = 일간의 가장 강한 발현 ✓ 결단·추진
- 신강 = 일간 에너지 강 ✓ 활동 지속력
- **판정**: 통설 정합. 유지.

### 4. 어울림 본기 = 정인+편인+일지 합 — STS 정의 채택 시 정합, 봉인
- 정인 = 학습·수용 (받쳐주는 결). 사회성과 직접 매핑은 한 단계 비약.
- 대안 후보 = 식상·재성·도화살 (사람 끄는 결)
- 그러나 STS "사회적 민감성" 학술 정의 = "타인 감정 민감 + 분위기 영향 + 공감" = **공감·흡수 측면**. 인성(받아들임)과 정합 가능.
- **판정**: 봉인. Phase 7 분포 검증.

### 5. 만족 본기 = 조후 균형 + 식신 — 한 단계 비약, 시안 재현 정합, 봉인
- 조후 균형 = 일주의 안정 (정서 진폭 작음). "안정 ≈ 만족"은 한 단계 비약 (안정 ≠ 낙관).
- 대안 후보 = 식신 본기(현재) 유지 + 양일간+화 강 본기 격상 + 천을귀인 본기 격상
- 김수민 양 만족 35점 = 조후 한습 편중 -1.0 + 식신 옅음 → 시안 점수 재현 정합
- **판정**: 봉인. Phase 7 만족 점수 분포 한쪽 쏠림 발견 시 본기 재조정.

## Phase 1-A 재작성 시 추가 결정 (2026-05-16)

### 사용자 통찰 정정
- **시안 점수 = 형이 임의로 박은 가상 예시**. 사주 fixture와 무관
- 공식 정합성 ≠ 시안 점수 일치
- 공식 산출 결과가 정답. 시안 점수는 갱신 대상

→ 1차 폐기된 factors.mjs는 시안 30·68 맞추는 회로에 빠져 위치 가중치 누락·임의 임계값 추가. **재작성**.

### 결정 1 — 위치 가중치 적용 방식

**룰 표** (2_child_6factors.md):
- 명리 강도 = 월령 사령 + 통근 + 투출 + 글자 수 × 왕상휴수사 (인자별 raw 0~100)
- 위치 가중치 = 일간 1.0 / 월령 1.0 / 일지 0.8 / 월간 0.7 / 시간·시지 0.5 / 연간·연지 0.4
- 인자 점수 = 명리 강도 × 등급 × 위치 가중치

**모호**: 인자가 여러 위치에 있을 때 (예: 자녀 인성이 년간·년지·월지중기·일지 4곳).

**결정**:
- 위치별 raw 강도 × 위치 가중치를 **위치별로 산출 후 합산**
- 즉 `weightedStrength = Σ(positionRawStrength × positionWeight)` for each position
- fixture에 인자별 `positions[]` 배열 + 사전 산출 `weightedStrength` 박음
- factors 함수는 weightedStrength × 등급 × 부호만 처리

**근거**: 룰 표 정확 해석. 인자가 여러 자리에 있으면 강도와 위치 영향이 자연 누적.

### 결정 2 — 신강 레벨 → 점수 매핑 = 캘리브레이션 대상

**임의 매핑 (1차)**:


### 결정 3 — 정규화 ÷6 = 캘리브레이션 대상

룰 명시 "직관 추정". Phase 7에서 분포 검증.

### 결정 4 — 임의 임계값 폐기

1차 코드의 다음 임계값 폐기:
- "인성 ≥ 50일 때 감산" → **삭제**, 룰 그대로 "인성 강도 상조 -0.5" 항상 적용
- "일주 안정 = 관성·인성·재성 모두 ≥ 30" → **삭제**, 룰의 "정관·정인·정재 조합"은 별도 산출 헬퍼 필요

### 결정 5 — 명리 강도 vs 오행% 통일

룰 표에 "화 오행 강도 (상조 +0.5)"가 있는데, 1차 코드는 오행%를 사용. 일관성 위해:
- 오행 강도 0~100 = (해당 오행 raw 분포 / 전체 분포 합) × 100 (백분율)
- 다른 인자(인성·관성)는 weightedStrength 0~100 (사전 산출)
- 같은 0~100 스케일이라 등급 곱하기에 정합

### 결정 6 — 사주 속성(음/양·12운성·신살) 50점 정량값 변환

룰 그대로:
- 음일간/양일간 → 50점 상조 가산 또는 감산
- 12운성 강세(장생·관대·건록·제왕) → 50점 여기 가산
- 12운성 약세(태·묘·절) → 50점 여기 감산 (활기·만족), 약세 여기 +0.2 (흔들림)
- 역마살·도화살·천을귀인·문창귀인·화개살 → 자리 있으면 50점 여기 가산 (인자별 부호)
