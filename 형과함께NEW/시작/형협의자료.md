# 형, 한 번 같이 정리해보자 (2026-05-17)

## 한 줄 결론

> **점수 공식이 모든 자녀를 비슷한 점수대로 만드는 구조 문제 발견. 외부 조사 결과 이건 우리만의 문제가 아니라 산업·학계 보편 한계. 시장은 점수 노출 톤다운으로 우회 중. 우리도 동일 전략 + 위치 가중치 명리 통설 수렴이 현실적 길.**

## 1. 지금 어디에 부딪혀 있나

### 1-1. 진짜 만세력 검증 통과 완료
- npm `manseryeok` + saju-core 시작 폴더에 통합
- 김수민 양 (2022-02-15 인시 양력) 진짜 사주 = **임인 임인 기해 병인 / 일간 기토(작은 흙)**
- 형이 시안에 박은 사주(壬子 庚申 乙亥 戊寅 / 을목) = **2022-02-15와 무관한 가상 사주**
- → 시안 김수민 양 = **가상 디자인. 진짜 만세력과 일치 안 함**

### 1-2. 100개 진짜 사주 캘리브레이션 = 6/6 분포 위반

```
요인     낮음   중간   높음
활기      0%   54%   46%   ⚠ 높음 쏠림
조심      1%   57%   42%   ⚠ 높음 쏠림
만족      0%   67%   33%   ⚠ 중간 쏠림
흔들림    0%   95%    5%   ⚠ 거의 모두 중간 (분산 좁음)
어울림    0%   55%   45%   ⚠ 높음 쏠림
끈기      0%   44%   56%   ⚠ 매우 높음 쏠림
```

이상 분포(낮음 25~30% / 중간 40~50% / 높음 25~30%)에서 모두 벗어남. **모든 자녀에게 비슷한 점수 → 변별력 부족**.

### 1-3. 동물 매칭도 편중

```
호랑이 34% + 소 38% = 72%   ← 두 동물에 압도 쏠림
토끼   8%
말     8%
양     6%   ← 시안의 김수민 양 동물
용     6%
돼지   0%   ← 흔들림 본기 자녀가 0명
```

### 1-4. 진짜 진단

단순 정규화 조정으로 못 잡음. **본기 가산 항목 동시 적용(3~5개) × 가산 점수 큼(50~100점) × 감산 비대칭** = 구조적 쏠림.

이게 형이 시안 만들 때 가정한 점수 공식의 한계가 코드로 드러난 결과.

## 2. 외부 조사 결과 — **이건 우리만의 문제가 아님**

### 발견 1. 학계·산업에 사주 점수화 표준 없음
- 한국 명리계: 학파별 다름 (월 40% / 일·시·연 각 20% 정도가 통설)
- BaZi GitHub 라이브러리: 분포 캘리브레이션 자료 없음
- 한국 특허 (KR101402779B1): 룰 기반 매핑 + **점수화 자체가 없음**
- 학술 (KCI 신강신약 sensitivity 연구): **통계 표준화 미해결**
- arxiv 2510.23337 (AI BaZi 시뮬레이션): **표준화 모색 중**

### 발견 2. 상업 서비스는 모두 "점수 노출 톤다운"
| 서비스 | 분량 | 점수 |
|---|---|---|
| 사주아이 (990원) | 짧음 | 본문 위주 |
| 봄날의해답 (9.9k~55k) | PDF 100p | 시각만, 본문 중심 |
| 사주쏙쏙 | PDF 62p | 시각만 |
| 인스타 공구 (4~5만원) | 가변 | 본문 |

→ **분포 쏠림 문제를 시장은 점수 노출 톤다운으로 우회**. 우리도 같은 길 가능.

### 발견 3. 우리만의 차별축은 시장에 없음
- STS 6요인 + 사주 매핑 = 우리 SKU만 있음
- 결정론 + LLM 분리 = AI 정확도 한계 극복
- 17p 모바일 친화 = PDF 60p 대비 짧고 강력
- 부모-자녀 36셀 매트릭스 = 유일

## 3. 시뮬레이션 점수 → 실제 노출 톤 결정 시 3가지 선택지

### 옵션 X — 점수 시각 유지 + 본문 인자 기반 (시장 표준)
- 6각 레이더·점수 바 = 그대로 (시안 정체성 보존)
- 본문 = 점수 기반 아니라 본기 인자 조합 매핑
- 점수 분포 쏠림은 시각에만 보임 (사용자가 분포 인지 X — 본인 점수만 봄)
- **비용 작음. 시안 정체성 유지. 시장 표준**

### 옵션 Y — 점수 공식 본기 가산 룰 정밀화
- 본기 가산 항목 동시 ≤2개로 제한
- 월령 가중치 1.0 → 1.5 (명리 통설 수렴)
- 본기 가산 점수 상한 50→30
- 정규화 ÷6 → ÷10
- 분포 검증 후 시안과 정합되는지 형이 결정
- **중간 비용. 캘리브레이션 1~2회 반복 가능**

### 옵션 Z — 점수 폐기, 본기 조합 직접 노출
- 점수 자체 없앰
- 본기 인자 조합 → 본문 직접 매핑 (전통 사주 책 방식)
- 분포 문제 자연 소멸
- **시안 정체성 v3 재설계. STS 6요인 차별축 폐기. 큰 작업.**

## 4. 현실적 출시 가능성 판단

### 시장 비교
| 항목 | 우리 | 시장 |
|---|---|---|
| 가격 | 2만 원 초중반 | 1~5만 원 |
| 분량 | 17p 모바일 | PDF 60~100p |
| 시각 | 강함 (레이더·매트릭스·동물·삼각구도) | 단순 |
| 차별축 | STS + 사주 + 부모 양육 | 사주 단독 |
| LLM 가드 | 4중 검증 + 결정론 facts | 단순 프롬프트 |

### 진단
- **시각·차별축 = 시장보다 강함**
- **분량 = 시장보다 짧음 (모바일 친화)**
- **공식 분포 쏠림 = 시장 평균과 동일 문제 (시장은 톤다운으로 우회)**
- **명리 정합 = 통설 100% 정합 X, 단 시장 평균과 동일**

### 현실적 출시 가능 여부

**옵션 X 채택 시 = 출시 가능**.

근거:
1. 시장 검증된 패턴 (사주아이·봄날의해답·사주쏙쏙 다 점수 톤다운)
2. 우리 차별축은 시장에 없음 (STS·매트릭스·동물·결정론+LLM)
3. 분포 쏠림은 사용자에게 보이지 않음 (본인 점수만 봄, 100명 분포는 모름)
4. 디스클레이머 강화로 트집 방어 가능

**옵션 Y 채택 시 = 출시 +1~2주**. 캘리브레이션 반복 필요.

**옵션 Z 채택 시 = 출시 +1~2개월**. 시안 v3 재설계 + 본기 조합 매핑 데이터 작성.

## 5. 동생이 권장하는 길 (단도직입)

### 권장 = **옵션 X + 위치 가중치 미세 조정**

이유:
1. 시장 표준 패턴
2. 시안 v1~v2.0 작업 100% 보존
3. 1주 안에 출시 준비 가능
4. 분포 쏠림은 사용자에게 안 보임
5. 우리 차별축(STS + 매트릭스 + 동물) 그대로

세부 적용:
- 점수 시각(레이더·점수 바)은 그대로 표시
- 본문 LLM 프롬프트는 **본기 인자 조합 기반**으로 작성 (점수 직접 인용 최소화)
- 결과지 점수 옆에 "사주 명리 강도 표시" 안내 (STS 표준 점수와 구분)
- 월령 가중치 1.0 → 1.5 (1단계 미세 조정. 명리 통설 수렴)

### 형이 결정해야 할 3가지

| # | 결정 | 권고 |
|---|---|---|
| Q1 | 옵션 X 채택 (점수 시각 유지 + 본문 인자 기반) | YES |
| Q2 | 월령 가중치 1.0 → 1.5 (분포 1단계 개선) | YES |
| Q3 | 시안 김수민 양 = 가상 캐릭터 유지 vs 진짜 만세력 자녀로 교체 | **가상 유지 권고** (시안 일관성) |

Q3 = 가상 유지 시 시안 그대로. 진짜 만세력으로 교체 시 = 동물·점수·매트릭스 다 변경.
