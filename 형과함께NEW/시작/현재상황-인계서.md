- 화면 문구: 데모 화면의 `점수 산출` 표현을 `결 위치/결 분석`으로 톤다운.
- package script: `calibrate`, `fixture`, `edge-cases`가 실제 존재하는 스크립트를 가리키도록 정리.
- 사람 눈 QA 보조: `npm run human-qa` 추가.
- 매트릭스 주의 문구: `부담/평가/과잉 자극/위축/잃을 수/과부하` 반복 표현을 완화.
