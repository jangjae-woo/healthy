## 2026-05-17 추가 업데이트 — Critical 재분류

아래 Critical 항목은 옵션 W 이전 기록이다. 오늘 검증 안정화 후 상태는 다음과 같다.

해결/완화:
- C1 분포 위반: `base0 raw + percentile-v1` 및 부모축 percentile 보정으로 `npm run calibrate` 500개 통과.
- C2 edge case 실패: percentile 이후 기준에 맞게 검증 의도를 재정의했고 `npm run edge-cases` 7/7 통과.
- W1 Mock LLM 분량/금지표현: validator `valid: true`, 위반 0건.
- package script 깨짐: `calibrate`, `fixture`, `edge-cases` 정상 실행.
- 사람 눈 QA 보조: `npm run human-qa` 추가. 동물/카드/주의 표현 반복 후보를 확인 가능.
- 매트릭스 강한 표현 반복: `부담/평가/과잉 자극/위축/잃을 수/과부하` 표현을 완화했고, `human-qa` 기준 주의 표현 빈도 0으로 확인.

남은 관찰:
- 매트릭스 카드 축에서 `표현`과 `중심`이 약간 높고 `자율`이 낮은 편이다. 지금은 산식 수정 대상이 아니라 사람 눈 QA 관찰 후보.
- 동물 분포는 실행마다 `용/돼지`가 20%대까지 올라올 때가 있다. 기존 70% 편중과는 다르며 관찰 후보로 둔다.
- 김수민 양 수동 fixture와 진짜 만세력 결과는 여전히 다르다. 단, 김수민 양은 의사결정 대상이 아니라 시안/fixture 샘플로만 다룬다.
- `saju-site` 본 프로젝트 이관은 아직 금지. 출시 확정 전까지 `시작` 폴더 검증 중심.

## 🔴 Critical — 출시 전 반드시 해결

### C1. Phase 7 캘리브레이션 분포 위반 (2~3건)
- **현상**: 100개 무작위 사주 → 6요인 분포가 한쪽 쏠림. 이상(낮음 25~30 / 중간 40~50 / 높음 25~30) 범위 벗어남
- **예상 원인**:
  - 본기 가산이 너무 강 (등급 1.0 + 다수 본기 자리 합산 → 점수 폭발)
  - SHINKANG_SCORE 매핑에서 중화 = 50점이 너무 큼
  - 정규화 ÷6이 직관값 (미검증)
- **시작 폴더에서 못 잡는 이유**: 무작위 사주 생성기가 진짜 만세력 X (60갑자 임의 조합)
- **해결**: saju-site 이관 후 진짜 만세력 100개로 재실행

### C2. Phase 8 edge case 4개 실패
- **현상**: Case 2(균형형) / 3(상위 비등) / 4(본기 0개) / 일부 검증 실패
- **원인**:
  - Case 2 (갑인·정묘·무진·신유): 편관·식상·정인이 동시 강 → 진짜 균형 X
  - Case 3 (경신·경신·을미·갑신): 관성 극단 강 → 단독 두드러짐(A) 됨, 비등 X
  - Case 4 (갑인·갑인·갑인·갑인): 비겁만 극단. auto-fixture-builder가 일부 인자에 의도치 않은 점수 부여 가능성
- **해결**: 이관 후 진짜 만세력 사주로 fixture 재선정 + 검증 룰 정밀화

### C3. 김수민 양 fixture inconsistency (구조적)
- **현상**:
  - 수동 fixture (`fixtures/child-kimsumin.mjs`): 인성 75, 관성 65, ...
  - auto-fixture-builder로 같은 사주 재산출: **다른 weightedStrength**
- **원인**:
  - 수동 = 형이 명리 통설 추정 박은 값
  - 자동 = saju-helpers.mjs 룰로 산출 (일부 단순화)
  - **두 방식이 inconsistent**
- **영향**: Phase 1~5 검증과 Phase 7·8 검증이 다른 점수 기반
- **해결**: 이관 시 `convertSajuCoreToFixture()` 신규 함수로 통일. 김수민 양 fixture도 자동 빌더로 재산출
