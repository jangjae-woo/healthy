## 2. 오늘 완료한 안정화

### 자녀 6요인

기존:

```text
score = 50 + sum / 6
```

문제:

- 낮음이 거의 안 나옴.
- 특정 동물로 몰림.
- 사주별 차이가 고객 화면에서 변별력 있게 보이지 않음.

현재:

- `base0Score = sum / 6` 별도 보존.
- 고객용 `score`는 percentile 기준으로 변환.
- `rawScore`, `rawLevel`, `base0Score`는 내부 추적용으로 유지.
- 고객에게는 숫자보다 `낮음/중간/높음`, `두드러진 편/은은한 편` 중심으로 표현.

### 어울림 재매핑

기존에는 인성이 `조심`, `어울림`, `끈기`에 반복적으로 강하게 작용했다. 그래서 인성 강한 사주가 여러 요인을 동시에 올리는 문제가 있었다.

현재 어울림:

```text
본기: 일지 합 / 천을귀인 / 도화살
상조: 인성 / 수 오행 / 목 오행
```

### 동물 매칭

기존:

- `score >= 66` 같은 고정 숫자 임계값 중심.

현재:

- 요인의 `level` 기준.
- 모두 중간권이거나 상위권 요인이 없으면 `용`.
- 상위 3개가 비슷하면 `상위 비등`.
- 1등이 명확하면 해당 동물.

### 부모 6축

부모축도 raw 점수가 특정 축으로 쏠려서 percentile 보정을 적용했다.

현재:

- 부모축 원점수는 `rawScore`로 보존.
- 카드 선택용 `score`는 `parent-axis-percentile-v1`.
- 고객에게 부모축 숫자는 노출하지 않음.

- 실패/통과 판정용이 아니라 관찰 보조용.

최근 결과:

```text
동물 분포: 7동물 모두 9~20% 범위
edge case: 별도 7/7 통과
주의 표현 빈도: 0
```

수정한 문구:

- `부담`, `평가`, `과잉 자극`, `위축`, `잃을 수`, `과부하`처럼 반복되던 강한 표현을 완화.
- 예: `부담될 수 있는 자리` → `신중함보다 앞서갈 수 있는 자리`
- 예: `평가가 마음에 오래 남을 수 있는 자리` → `기대가 마음에 깊게 남을 수 있는 자리`

남은 관찰:

- 매트릭스 카드 축에서 `표현`이 여전히 23~25% 안팎으로 높게 나오는 편.
- `자율`은 9~11% 안팎으로 낮게 나오는 편.
- 지금은 카드 선택 규칙 특성으로 보고, 실제 샘플 본문에서 지루하게 반복되는지 먼저 확인한다.

## 4. 김수민 양에 대한 정리

김수민 양은 의사결정 대상이 아니다.

`2022-02-15 인시 양력`으로 진짜 만세력을 돌리면:

```text
수동 fixture: 임자 경신 을해 무인 / 일간 을
진짜 만세력: 임인 임인 기해 병인 / 일간 기
```

즉 시안 김수민 양은 실제 생년월일과 일치하는 모델이 아니라, 형 시안 작업 중 만들어진 **가상 fixture**다.

권고:

- 시안/샘플용으로만 유지.
- 실제 상품 의사결정은 랜덤 다수 사주 QA와 분포 검증 기준으로 판단.

## 5. 형이 봐야 할 결정 포인트

### Q1. 현재 분포 안정화 수준으로 다음 단계 진행해도 되는가?

동생 판단:

```text
YES
```

이유:

- 6요인 낮음/중간/높음이 실제로 살아남.
- 동물 편중이 치명 수준에서 벗어남.
- 부모축도 이전보다 균형화됨.

### Q2. 매트릭스 카드 축에서 표현 24~25%, 자율 11%를 당장 조정할까?

동생 판단:

```text
NO
```

이유:

- 부모 강축 자체는 균형.
- 매트릭스 카드 선택은 축×자녀요인×패턴 정렬 결과라 1:1 균등이 목표가 아님.
- 지금 조정하면 새 편중이 생길 가능성이 있음.
- 사람 눈 QA에서 “표현 카드가 반복돼 지겹다”가 확인되면 그때 조정.

### Q3. 고객 화면에 숫자를 보여줄까?

동생 판단:

```text
NO
```

이유:

- 현재 score는 절대점수가 아니라 표본 안의 위치값.
- 숫자를 보여주면 “정확한 점수”처럼 오해될 수 있음.
- 화면에는 막대 길이와 `낮음/중간/높음` 라벨 중심이 안전.
