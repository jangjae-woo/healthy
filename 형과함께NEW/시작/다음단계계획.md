아래 이관 계획은 보류한다. 오늘 기준 다음 순서는 이렇다.

1. 사람 눈 QA

   - `npm run human-qa`로 동물/카드/주의 표현 반복 후보를 먼저 확인한다.
   - 동물/요인/부모카드 문맥이 납득되는지 목록화한다.

   - 고객 화면에서 `점수` 표현이 과하게 보이지 않는지 확인한다.

   - LLM 본문은 validator로 숫자 점수 노출을 금지한다.

   - 김수민 양은 가상 fixture이며, 실제 의사결정 기준이 아님을 명시한다.

4. 이관 판단

### 2-2. `saju-converter.ts` 실제 구현 (1일) ⭐ 가장 큰 작업
시작 폴더 stub을 실제 만세력 변환으로 교체:

```typescript
// lib/youa/saju-converter.ts
import { computeFullSajuCore } from '@/lib/saju-core';
import { convertSajuCoreToFixture } from './core-to-fixture';

export function convertToSaju(formInput, role) {
  const sajuCore = computeFullSajuCore({
    year: formInput.birthDate.slice(0, 4),
    month: formInput.birthDate.slice(5, 7),
    day: formInput.birthDate.slice(8, 10),
    hour: formInput.hour,
    calendar: formInput.calendar === 'lunar' ? '음력' : '양력',
    gender: role === 'child' ? (formInput.gender === 'female' ? '여' : '남') : undefined,
  });
  if (!sajuCore) throw new Error('사주 변환 실패');
  return convertSajuCoreToFixture(sajuCore, formInput, role);
}
```

### 2-3. `core-to-fixture.ts` 신규 ⭐ 시작 폴더 inconsistency 해결
`SajuAnalysisCore` (saju-core.ts) → fixture 스키마 변환:
- pillars, ilgan, ilju, yinyang
- sipseong (saju-calculator의 정확 십성)
- jijangan
- factorStrength (6셋 통칭 자동 산출 — 위치 가중치 정확 적용)
- sinsal (saju-traditional `calcSinsal` 활용)
- unseong (saju-traditional `calcUnseong` 활용)
- shinkang (`getDayMasterStrength`)
- branchInteractions (`calcIljiRelation` + 천간합)
- elements (`calcElements`)

**이게 시작 폴더 auto-fixture-builder의 진짜 버전**. 김수민 양 fixture 수동 vs 자동 불일치도 자동 해결.

## Stage 3 — 진짜 만세력 기반 재검증 (1~2일)

### 3-1. 김수민 양 fixture 재산출
- 폼에 김수민 양 입력 (2022-02-15·여·인시·양력)
- `computeFullSajuCore()` + `convertSajuCoreToFixture()`로 진짜 fixture 생성
- 수동 fixture(시작 폴더)와 비교
- 차이 분석 → 어느 게 명리 정합인지 결정 → 통일

### 3-2. Phase 7 진짜 캘리브레이션
스크립트: `scripts/calibrate-youa-factors.ts`
- 무작위 양력 생일 100개 생성 (2020-01-01 ~ 2023-12-31)
- 무작위 시지 12개 분포
- 각 사주에 `computeFullSajuCore` + `calcAll6Factors`
- 6요인 분포 분석 → 이상(낮음 25~30 / 중간 40~50 / 높음 25~30) 검증

### 3-3. 조정 결정 (분포 위반 시)
**오류및미해결.md의 C1·W2·W3 해결**:
- 옵션 A: `SHINKANG_SCORE` 매핑 조정 (중화 50→35 등)
- 옵션 B: 정규화 ÷6 → ÷5 or ÷7
- 옵션 C: GRADE 본기 1.0 → 0.8
- 옵션 D: 본기 매핑 Phase 0-B 봉인 풀기 (어울림·만족 재검토 — 형 협의)

**1회 일괄 조정**으로 도미노 영향 흡수.

### 3-4. Phase 8 진짜 edge case 재선정
- Case 2 균형형: 진짜 양력 생일 + 12시지 조합에서 6요인 모두 41~65인 사주 탐색
- Case 3 상위 비등: top1-top3 ≤6 사주 탐색
- Case 4 본기 0개: 비겁만 강한 사주 탐색
- Case 5 모두 충돌: 부모 사주가 바람 강 + 자녀 신중·정서 강 조합 탐색
- 검증 룰 정밀화 (실제 케이스에 맞춰)
