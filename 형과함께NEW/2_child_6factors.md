### 양극 본문 (v2.0 재작성 — 저작권 회피 + 본질 충실)

| 요인 | 낮음 | 높음 |
|---|---|---|
| **활기** | 활동량이 적고 얌전하며 차분한 결. 소근육 놀이(만지작거리기·그림 그리기 등)가 자연스럽고, 가만히 있는 시간이 편안한 결입니다. | 활동량이 많고 열정적인 결. 대근육 놀이(뛰기·오르기·매달리기 등)를 즐기고, 에너지가 풍부한 결입니다. |
| **조심** | 도전적이고 적극적인 결. 새 자극 앞에서 겁이 적고 대담하게 먼저 한 걸음 내딛는 결이며, 낯선 환경에도 적응이 빠르고 주도적인 결입니다. | 조심성이 많고 수줍어 하는 결. 새 사람·새 장소 앞에서 한 번 더 살피고 안전한 자리부터 찾는 결이며, 경계심이 높아 실수가 적은 결입니다. |
| **만족** | 긍정정서 표현이 적은 결. 마음에 잘 들지 않으면 표정에 그대로 비치고 시큰둥하며 애정 표현이 적은 결이며, 쉽게 만족하기까지 시간이 걸리는 결입니다. | 낙관적이고 유쾌한 결. 일상에서 좋은 결을 자주 발견하고, 작은 일에도 만족하며 행복을 자주 느끼는 결입니다. |
| **흔들림** | 마음이 안정되고 침착한 결. 이완된 상태로 흔들리는 자리에서도 참을성 있게 빠르게 안정을 찾는 결입니다. | 예민하고 감정에 민감한 결. 한 번 마음에 새겨진 감정이 오래 머물고, 기분 회복에 시간이 필요한 결입니다. |
| **어울림** | 독립적이고 개인적인 결. 혼자의 시간이 편안하고 자기 페이스로 노는 결이며, 타인의 영향을 덜 받고 외로움도 덜 타는 결입니다. | 공감적이고 사교적인 결. 타인의 감정에 민감하고 주변 분위기에 영향을 받는 결이며, 함께하는 놀이를 좋아하는 결입니다. |
| **끈기** | 관심사가 다양하고 자신의 욕구에 충실한 결. 한 자리에 오래 머무는 것보다 여러 자리를 가볍게 옮겨가며 자라고, 욕심을 부리기보다 현실과 가볍게 타협하는 결입니다. | 인내심이 강하고 끈기 있는 결. 한 번 시작한 것을 끝까지 꾸준히 들고 가는 결이며, 주의집중력이 높고 부지런한 결입니다. |

> **v2.0 변경**: 기존 "STS 양극 키워드 그대로 인용" 룰 폐기 (저작권 회피). 형용사 나열 → 풀어쓴 문장 + 우리 결 톤. STS 본질 키워드(낙관·유쾌·예민·민감·인내심·꾸준·부지런 등 학술 공통 자산)는 흡수하되, 나열 방식·문장 구조는 우리 저작.

### 자도인 톤 (낮음을 결점으로 풀지 X)

"낮음 = 부정 의역" 금지 룰 v1 그대로 유지. 예: "흔들림이 낮음 = 마음이 안정된 결" (긍정 의역 X, 본질 그대로). "마음이 안정되고 침착한 결" 표현은 본질 묘사이지 긍정 윤색 X.

## 점수 산출 — 3단 공식

```
인자 점수 = (명리 강도 0~100) × (요인 기여 등급 0~1.0) × (위치 가중치 0~1.0)
요인 총점 = clamp( 50 + Σ(인자 점수 × 부호) / 6, 0, 100 )
구간: 낮음 0~40 / 중간 41~65 / 높음 66~100
```

### 톤 가이드 예시 (활기 78점, 높음)

> [결 한눈에 박스] 활동량이 많고 대근육 활동을 선호하는, 도전적이고 적극적인 결입니다.
>
> [왜 이런 결인가 본문]
> OO 양의 활기는 78점, 높은 결입니다. 사주에 양인(羊刃)이 강하게 자리한 결과로, 결단과 추진의 본기가 단단합니다. 자평진전의 「식상자 일주지기야」가 그대로 발현된 결로, 일주의 기운이 밖으로 흐르는 결이 자연스럽게 신체 활동량과 에너지로 나타납니다. 신강한 일간이 받쳐주어 오래 가는 결입니다.

```ts
  // 투출 (+15)
  // 글자 수 (천간 +10 / 지지 +8)
  // 왕상휴수사 보정 (×0.5~1.5)
  return Math.min(100, strength);
}

// ② 요인 기여 등급
const GRADE = {
  bongi: 1.0,    // 본기
  sangjo: 0.5,   // 상조
  yeogi: 0.2,    // 여기
};

// ③ 위치 가중치
const POSITION = {
  ilgan: 1.0,    // 일간
  wolji: 1.0,    // 월령
  ilji: 0.8,     // 일지
  wolgan: 0.7,   // 월간
  sigan: 0.5,    // 시간
  siji: 0.5,     // 시지
  yeongan: 0.4,  // 연간
  yeonji: 0.4,   // 연지
};

// 활기 점수 산출 (다른 요인도 동일 패턴)
export function calcHwalgi(saju: Saju): FactorScore {
  let sum = 0;
  
  // 본기 (계수 1.0)
  sum += getMyeongriStrength('식상', saju) * GRADE.bongi * getPositionWeight('식상', saju);
  sum += getMyeongriStrength('양인', saju) * GRADE.bongi * getPositionWeight('양인', saju);
  sum += getSinkangStrength(saju) * GRADE.bongi;
  
  // 상조 (계수 0.5)
  sum += getOhaengStrength('화', saju) * GRADE.sangjo;
  sum += getOhaengStrength('목', saju) * GRADE.sangjo;
  if (isYangIlgan(saju)) sum += 50 * GRADE.sangjo;
  
  // 여기 (계수 0.2)
  if (hasYeokma(saju)) sum += 50 * GRADE.yeogi;
  if (has12UnseongStrong(saju)) sum += 50 * GRADE.yeogi;
  
  // 감산
  if (isEumIlgan(saju)) sum -= 50 * GRADE.sangjo;
  sum -= getOhaengStrength('수', saju) * GRADE.sangjo;
  if (has12UnseongWeak(saju)) sum -= 50 * GRADE.yeogi;
  sum -= getMyeongriStrength('인성', saju) * GRADE.sangjo;
  
  // 정규화 (÷6) — 캘리브레이션 후 조정
  const score = clamp(50 + sum / 6, 0, 100);
  
  return {
    factor: 'hwalgi',
    score,
    level: score <= 40 ? 'low' : score <= 65 ? 'mid' : 'high',
    mainFactors: extractMainFactors(saju, 'hwalgi'),
  };
}

function clamp(x: number, min: number, max: number): number {
  return Math.max(min, Math.min(max, x));
}
```

다른 요인 5개도 동일 패턴. 본기·상조·여기 인자만 위 6요인 표에 따라 교체.

## 캘리브레이션 (필수, 코드 작업 후)

정규화 상수(현재 ÷6)는 직관 추정값. 무작위 사주 100개 분포 검증으로 조정 필요.

### 절차

```ts
// scripts/calibrate-youa-factors.ts

import { generateRandomSaju } from './fixtures';
import { calcHwalgi, calcSalpim, /* ... */ } from '../lib/youa/factors';

const samples = Array.from({ length: 100 }, () => generateRandomSaju());

const distributions = {
  hwalgi: samples.map(calcHwalgi),
  // ... 6요인 모두
};

// 분포 히스토그램 그리기 (예: console table)
for (const [factor, scores] of Object.entries(distributions)) {
  const low = scores.filter(s => s.level === 'low').length;
  const mid = scores.filter(s => s.level === 'mid').length;
  const high = scores.filter(s => s.level === 'high').length;
  console.log(`${factor}: 낮음 ${low}% / 중간 ${mid}% / 높음 ${high}%`);
}
```

### 이상적 분포

각 요인이 **낮음 25~30% / 중간 40~50% / 높음 25~30%** 정도.

한쪽으로 쏠리면 정규화 상수 조정 (÷6 → ÷5 또는 ÷7 등) 또는 본기/상조/여기 가중치 미세 조정.

## 가중치 한계 — 정직한 인정

- 본기/상조/여기 계수(1.0/0.5/0.2) = 명리 지지장간 비례 환산 (임의 아님)
- 위치 가중치 = 명리 위치 영향력 통설 (임의 아님)
- 인자별 본기/상조/여기 배정 = 명리 통설 (자평진전·적천수 인용 가능)
- **단** 정규화 상수(÷6) = 직관 추정. 캘리브레이션 필수
- 통계 표준화는 불가능 (영유아 사주+행동 매칭 코호트 없음)
- 우리 신뢰 근거 = **명리학적 정합성** (인싸이트 통계적 정확도와 다른 종류)

## 시안 검토 누적 변경 (2026-05-17 v1.1~v1.5)

### 결과지 노출 톤 정정 (계산 자체는 그대로)

본 문서의 가산·감산 표·계수·공식은 **내부 산출 로직**으로 그대로 유지. 단 결과지(`preview/index.html`) 노출 시 다음 룰이 추가됨.

#### 1. 가산·감산 표 점수·합계 노출 X (룰 16)

- 결과지 본문에는 인자명만 노출. 점수·합계는 노출 X
- 인자 카드는 **2열 그리드**로 한눈에 6개 보이게
- 인자 카드 = 위치 표시 ("📍 월간·본기 통근") + 탭 시 작용 디테일 펼침 (아코디언)
- 점수는 산출 로직 내부값 + 6요인 종합 점수(레이더·바)·각 챕터 헤드라인 점수에만 노출

#### 2. 사주 인자 호명 = "X 기운" (룰 13)

| 십성·신살 | 결과지 호명 |
|---|---|
| 정인 | 받쳐주는 기운 |
| 식신 | 표현하는 기운 |
| 정관 | 절제하는 기운 |
| 정재 | 결과의 기운 |
| 양인 | 결단하는 기운 |
| 칠살 | (그대로) 또는 외부 자극의 기운 |
| 천을귀인 | 사람을 끌어들이는 상서로운 기운 |
| (표 헤더) | 활기를 만드는 기운 / 누르는 기운 |

본 문서 본문의 "정인 강도"·"식신 강도" 등 명리 표준 호명은 **계산 로직 그대로 유지**. 결과지 출력 단계에서만 "기운" 변환 적용.

#### 3. 사주 용어 풀어쓰기 변환 룰 (룰 12)

본 문서에서 사용하는 명리 용어는 결과지에서 다음과 같이 풀어쓴다:

| 어려운 용어 | 일상어 풀이 |
|---|---|
| 본기 / 본기로 자리 | 사주의 큰 흐름 / 가장 강하게 자리한 / 가장 큰 영향 |
| 조후 / 한열조습 | 따뜻함과 차가움의 균형 / 따뜻함과 차가움 |
| 한열조습 편중 / 조후 불균형 | 사주 안 따뜻함과 차가움이 한쪽으로 기움 |
| 신강 / 신약 | 일간의 에너지가 강함 / 작음 |
| 양화/음화·양금/음금 | 큰 불/작은 불·큰 쇠/작은 쇠 |

본 문서 가산·감산 표의 **"조후 균형(한열조습 차이 ≤ 1)"** 항목은 결과지에서 "**따뜻함과 차가움의 균형**" 카드로 표시.

#### 4. 명리 원전 박스 삭제 (룰 20)

본 문서의 "**명리 근거**" 섹션(자평진전·적천수·궁통보감 인용)은 **계산 로직의 근거 주석**으로 유지. 단 결과지 6요인 챕터 본문에는 **명리 원전 박스를 노출하지 않음** (현장 검토 결과 사용자가 와닿지 X).

- 자도인의 톤·풀이 안에서 원전 정신을 자연스럽게 흡수
- 명리 한자 병기는 본 문서 → 동생 코드 주석에만 유지

#### 5. 6요인 챕터 (c) = 양육 Tip 박스 (룰 18·19)

각 6요인 챕터(2~7장)의 (c) 박스는 v1.1에서 자도인 한 마디 박스 → **양육 Tip 박스**로 변경.

- 양육 Tip 3축 = **시간 · 소통 · 환경** (모든 6요인 챕터 통일)
- 톤 = 사주 풀이 + 일상어 권고 (B안)
  - 각 Tip 첫 문장에 사주 인자 자연 흡수
  - 권고는 일상어로 구체
- 일상 박스 (자녀 모습 관찰) ↔ 양육 Tip (부모 행동) 차원 분리. 예시 단어 중복 X

#### 6. 자리 X 인자 카드 부연 라벨 (룰 17)

가산·감산 표의 본기 인자가 사주 천간·지지에 **직접 자리하지 않는** 경우, 카드 하단에 **자동 부연 라벨** 표시:

> ⓘ 직접 없음 — 다른 인자 영향으로 작게 표시

이유: 점수가 base 50에서 가산·감산 결과이므로 자리 X여도 0이 아닐 수 있음. 사용자 혼란 방지.

#### 7. 캘리브레이션·검증 순서는 그대로

- 100개 무작위 사주 분포 검증 → 정규화 상수(÷6) 조정 → 본기/상조/여기 미세 조정
- 검증 후 결과지 노출 룰(1~6) 적용은 동생 코드 단계에서 처리
