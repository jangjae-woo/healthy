# 4. 36셀 결합 매트릭스 — 부모 6축 × 자녀 6요인

## 매트릭스 개요

- **행**: 부모 6축 (온기·중심·일관·자율·표현·바람)
- **열**: 자녀 6요인 (활기·조심·만족·흔들림·어울림·끈기)
- **셀**: 그 조합의 본기 톤 한 줄 + 시너지/충돌 패턴

8장 (d) "함께 살펴줄 결" 본문 풀이의 결정론 분기에 사용. 부모별로 각각 36셀 적용 (어머님 36셀 + 아버님 36셀).

---

## 매트릭스 사용 룰

```
1. 어머님 6축 점수 산출 → 상위 1~2축 추출 (점수 ≥ 66 = 높음)
2. 자녀 6요인 점수 산출 → 상위/하위 1~2 요인 추출
3. 어머님 상위 축 × 자녀 상위/하위 요인 = 해당 셀 본기 톤 추출
4. 아버님도 동일
5. 8-(d) 본문에 강한 시너지 1~2개 + 강한 충돌 1~2개 풀이
```

## 8장 (d) 본문 풀이 흐름

```
function generate8d(motherAxes, fatherAxes, childFactors) {
  // 1. 어머님 매트릭스 매칭
  const motherStrongAxes = motherAxes.filter(a => a.score >= 66);
  const motherSynergies = [];
  const motherConflicts = [];
  for (const axis of motherStrongAxes) {
    for (const factor of childFactors) {
      const cell = MATRIX[axis.name][factor.name];
      if (cell.pattern === 'strong_synergy') motherSynergies.push({ axis, factor, cell });
      if (cell.pattern === 'strong_conflict') motherConflicts.push({ axis, factor, cell });
    }
  }
  
  // 2. 아버님 매트릭스 매칭 (동일)
  // ...
  
  // 3. 본문 풀이 — 카드형 1~2개씩
  return {
    intro: "두 분이 함께 들여다볼 결이 있습니다.",
    synergies: motherSynergies.slice(0, 1).concat(fatherSynergies.slice(0, 1)),
    conflicts: motherConflicts.slice(0, 1).concat(fatherConflicts.slice(0, 1)),
    outro: "이 결들을 함께 살피실 때 OO 양은 가장 잘 자랍니다.",
  };
}
```

본문 톤 가이드:
> **[시너지 카드]**
> 어머님의 일관 결과 OO 양의 흔들림이 만나는 자리는 강한 시너지입니다. 예측 가능한 어머님의 일상 흐름이 OO 양의 깊은 정서 회복에 가장 큰 약이 됩니다. 같은 시간·같은 자리·같은 어휘가 OO 양의 정서를 빠르게 가라앉힙니다.
>
> **[충돌 카드]**
> 아버님의 바람 결이 OO 양의 조심 결과 만나는 자리는 살펴줄 자리입니다. 신중한 결의 자녀에게 결과 압력은 큰 부담이 될 수 있습니다. 아버님의 성취 기대를 직접 표현하시기보다 OO 양이 스스로 결을 다듬을 시간을 주시는 것이 자도인의 마지막 당부입니다.

## 9분기 확장 (코드 작업 시점에 추가 가능, 1차에선 미반영)

각 셀을 양쪽 점수 강도 조합으로 9분기 = 36 × 9 = 324 풀이 분기.

```
부모 축 高 × 자녀 요인 高 → 분기 1
부모 축 高 × 자녀 요인 中 → 분기 2
부모 축 高 × 자녀 요인 低 → 분기 3
부모 축 中 × 자녀 요인 高 → 분기 4
... (총 9분기)
```

1차는 36셀 본기 톤만 사용. 9분기는 코드 작업 + 1차 출시 후 v2 향상안에서 추가.

## 매트릭스 카드 5요소 구조 (2026-05-17 v1.5 신규 룰)

8-(d) 본문에서 각 카드는 다음 5요소로 구성. 시안 검토에서 확정.

### 5요소

| # | 요소 | 내용 |
|---|---|---|
| 1 | **헤더** | 결합 결과를 직접 표현 (예: "김수민 양이 흔들릴 때 어머님이 안정시키는 자리") — 추상 표현 금지 |
| 2 | **서브** | 패턴 + 점수 메커니즘 (예: "강한 시너지 — 어머님의 받쳐주는 기운(80) × 김수민 양의 깊은 정서(75)") |
| 3 | **본문 3단** | (1) 부모 결 풀이 — 부모가 어떤 결인지 구체 / (2) 자녀 결 풀이 / (3) 결합 결과 |
| 4 | **일상 사례 박스** | 🌸 시너지(분홍) / ⚠ 충돌(회색) — 부모 공감 포인트 1~2개 |
| 5 | **권고 박스** | 충돌 카드만 — 🌿 "이렇게 풀어보세요" 짧은 양육 권고 |

### 카드 본문 룰

- 점수는 서브 줄에 한 번만 노출 (본문에는 X)
- 부모 결·자녀 결 풀이 = 한 문장씩 구체 묘사
- 결합 결과 = "두 결이 만나면 ~ 자리가 됩니다" 톤
- 일상 사례 = 부모가 매일 보는 장면 1~2개

### 헤더 변환 룰

| 추상 (금지) | 결합 결과 (필수) |
|---|---|
