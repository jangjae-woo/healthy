## 룰 1 — 사주 한자 표기

### 규칙

- 사주 인자(십성·신살·일주 등) 첫 등장 시 **한자 병기 + 일반어 풀이**
- 같은 인자 두 번째 등장부터는 한자 X, 한글만
- 한자 미사용 옵션(c)·한글 전용 옵션(b) 배제

### 예시

```
✅ 첫 등장: "양인(羊刃)은 강한 결단의 결입니다."
✅ 이후:    "양인이 본기로 자리한 OO 양은…"
❌ 매번:    "양인(羊刃)이 본기로… 양인(羊刃)이 또…"  (반복 부담)
```

### 어떤 인자에 적용?

- 십성: 비견(比肩)·겁재(劫財)·식신(食神)·상관(傷官)·편재(偏財)·정재(正財)·편관(偏官)·정관(正官)·편인(偏印)·정인(正印)
- 신살: 양인(羊刃)·도화(桃花)·천을귀인(天乙貴人)·문창귀인(文昌貴人)·역마(驛馬)·화개(華蓋)·괴강(魁罡)·등
- 합·충·해·원진: 합(合)·충(沖)·해(害)·원진(怨嗔)
- 명리 원전 직접 인용 시 한자 그대로 (예: 「관성위제(官星爲制)」)

## 룰 4 — 본문 구조

### 박스+산문 혼합 (인싸이트 톤)

각 챕터는 박스(시각 강조) + 산문(메커니즘 설명) 혼합. 산문체 강제 X, 박스 금지 X (V2 자도인 룰 폐기).

### 챕터별 본문 구조 예시 (2장 활기)

```
[페이지 1 — 결 한눈에]
- 헤더 박스: 활기 (주황색)
- 6각 레이더 차트
- 점수 막대 6개
- 결 단정 박스: "OO 양의 활기는 78점, 높은 결입니다. 움직임이 많고 에너지가 풍부한 결입니다." (v2.0 양극 본문 풀어쓰기, 룰 30)

[페이지 2 — 왜 이런 결인가]
- 본문 산문 250~300자:
  단정 한 줄 + 사주 메커니즘 (한자 병기 1회) + 위치·강도 디테일
- 명리 원전 박스: v1.6부터 노출 X (룰 20)

[페이지 3 — 양육 Tip (v1.1 변경)]

  - 환경 — 사주 인자 흡수 + 일상어 권고
```

## 룰 5 — 자녀 호칭

### 규칙

- **여자아이**: ○○ 양 (예: "수민 양은…")
- **남자아이**: ○○ 군 (예: "도현 군은…")

### 격식 호칭 사용 이유

- 임상 검사 톤 정합 (인싸이트 톤)
- 결과지 신뢰감 ↑
- "수민이는" 같은 일상 호칭은 인스타 톤이지만 임상 검사 톤과 충돌

### 코드 변수

```ts
const childTitle = child.gender === 'female' ? `${child.name} 양` : `${child.name} 군`;
```

## 룰 6 — 부모 호명

### 규칙

- **어머님·아버님** (격식 호칭)
- "엄마·아빠"는 인스타 톤이지만 임상 검사 톤·결과지 신뢰감과 충돌 — 사용 X
- "부모님" (총칭)은 어머님·아버님이 둘 다 본문에 동시 등장할 때만

### 코드 변수

```ts
const motherTitle = '어머님';
const fatherTitle = '아버님';
const parentsTitle = (hasMom && hasDad) ? '어머님·아버님' : hasMom ? '어머님' : '아버님';
```

## 룰 9 — 시그너처 어휘

### 규칙

- **"타고난 결"** — 챕터당 1~2회 절제 사용
- V2 자도인 "결" 단독 시그너처 어휘 X (V2 자산이라 배제)
- "결"은 본문에 자연스럽게 등장하되 도배 X

```

❌ "활기로운 결, 단단한 결, 깊은 결, 넓은 결..." (도배)
```

## 룰 10 — 마무리 톤 (v1.9 갱신)

### 규칙

- 각 챕터 끝 = 양육 Tip 박스 (인싸이트 톤)
- 보고서 outro = **"자도인의 마지막 당부"** 5문단 산문 (v1.9 재작성)
- V2 자도인 "부모님이 기억해야 할 한 가지는…" 마무리 톤 X (V2 자산)

### outro 톤 가이드 (v1.9 자도인의 마지막 당부)

```
[자도인의 마지막 당부]

여기까지 OO 양의 결을 함께 들여다봐 주셔서 감사합니다.

아이의 기질을 안다는 건 아이를 더 깊이 이해할 수 있는 자리를 얻는 일입니다.
같은 행동도 그 아이의 타고난 결을 알고 보면 다르게 보입니다.
답답해 보이던 모습이 신중한 결로, 산만해 보이던 모습이 활기 있는 결로,
예민해 보이던 모습이 깊이 느끼는 결로 보이기 시작합니다.

그리고 한 가지 더 — 부모님 자신의 결을 아는 것도 그만큼 중요합니다.
부모님이 어떤 결로 자녀를 받아들이고 있는지, 어떤 자리에서 자녀와 부드럽게 만나고
어떤 자리에서 부딪히기 쉬운지를 알고 계시면, 자녀에게 더 맞는 양육의 결을 만들어 주실 수 있습니다.

아이의 결과 부모님의 결, 그 두 결이 만나는 자리를 알고 가시면 양육이 더 자연스러워집니다.
OO 양이 가장 잘 자라는 길은 그 자리에서 만들어집니다.

어머님 · 아버님의 자리에서, OO 양의 결을 함께 살펴주세요.

※ 본 풀이는 사주명리학을 현시대 부모의 언어로 재표현한 양육 안내이며,
의학적 진단·치료가 아닙니다.
사주는 타고난 결이며 실제 행동·양육은 환경·경험·선택에 따라 달라질 수 있습니다.

— 자도인(慈道人) —
```

### 본문 5문단 구조 (v1.9 신규)

1. **인사·감사** (1문장) — "여기까지 ○○ 양의 결을 함께 들여다봐 주셔서 감사합니다"
2. **아이 기질 이해의 가치** (3문장) — 같은 행동도 결을 알면 다르게 보임 (구체 예시 3개: 답답해→신중 / 산만해→활기 / 예민해→깊이 느낌)
3. **부모 자기 결 이해의 가치** (2문장) — 부모님이 자기 결을 알면 자녀에게 맞는 양육 가능
4. **두 결의 만남 종합 메시지** (2문장) — 양육이 자연스러워지는 자리
5. **마지막 당부** (1문장, 중앙 정렬 + 강조 색) — "어머님·아버님의 자리에서, ○○ 양의 결을 함께 살펴주세요"

### 금지·허용 톤

| 금지 | 허용 |
|---|---|
| ❌ 자녀 결을 종합 단정 ("OO 양은 ~한 아이입니다") | ✅ 부모님 인사·감사 |
| ❌ V2 시그너처 어휘 ("자도인이 바라보매") | ✅ 가치 발견 톤 ("~을 얻는 일입니다") |
| ❌ 양육 Tip 추가 (8장·종합 페이지에서 다 함) | ✅ 부모 자기 인식 권유 |
| ❌ "기억해야 할 한 가지는…" V2 톤 | ✅ "~을 함께 살펴주세요" 따뜻한 당부 |

## V2 자도인 배제 룰 (중요)

## 룰 30 — 양극 본문 v2 (저작권 회피, 2026-05-17 v2.0 신규)

### 배경 (v1 룰 폐기 이유)

v1에서는 "STS 양극 키워드 그대로 인용" 룰을 명시했음. 그러나 인싸이트 STS 양극 키워드 셋(예: "활동량이 많은, 열정적인, 대근육 신체 활동을 선호하는, 에너지가 넘치는")은 **인싸이트의 한국어 표준화 저작물**. 상업 서비스(우리 SKU = 인스타 공구 2만 원 보고서)에서 그대로 인용 시 저작권 침해 위험 중~상.

특히 인스타 공구로 노출량 ↑ → 발각 확률 ↑. 의도적 위험 회피를 위해 v2.0에서 **양극 본문 풀 재작성**.

### 규칙

- 자녀 6요인 양극 본문은 **풀어쓴 문장 + 우리 결 톤**으로 작성
- STS 본질 키워드(낙관·유쾌·예민·민감·인내심·꾸준·부지런 등 학술 공통 자산)는 **본질 흡수 OK**
- 단 **나열 방식·문장 구조**는 STS와 다르게 (우리 저작)
- "~한 결입니다" 시그너처 톤 유지
- "낮음 = 부정 의역" 금지 룰 v1 그대로 유지 ("낮음을 긍정 의역" 금지)

### 6요인 양극 본문 풀 (v2.0)

| 요인 | 낮음 | 높음 |
|---|---|---|
| **활기** | 활동량이 적고 얌전하며 차분한 결. 소근육 놀이(만지작거리기·그림 그리기 등)가 자연스럽고, 가만히 있는 시간이 편안한 결입니다. | 활동량이 많고 열정적인 결. 대근육 놀이(뛰기·오르기·매달리기 등)를 즐기고, 에너지가 풍부한 결입니다. |
| **조심** | 도전적이고 적극적인 결. 새 자극 앞에서 겁이 적고 대담하게 먼저 한 걸음 내딛는 결이며, 낯선 환경에도 적응이 빠르고 주도적인 결입니다. | 조심성이 많고 수줍어 하는 결. 새 사람·새 장소 앞에서 한 번 더 살피고 안전한 자리부터 찾는 결이며, 경계심이 높아 실수가 적은 결입니다. |
| **만족** | 긍정정서 표현이 적은 결. 마음에 잘 들지 않으면 표정에 그대로 비치고 시큰둥하며 애정 표현이 적은 결이며, 쉽게 만족하기까지 시간이 걸리는 결입니다. | 낙관적이고 유쾌한 결. 일상에서 좋은 결을 자주 발견하고, 작은 일에도 만족하며 행복을 자주 느끼는 결입니다. |
| **흔들림** | 마음이 안정되고 침착한 결. 이완된 상태로 흔들리는 자리에서도 참을성 있게 빠르게 안정을 찾는 결입니다. | 예민하고 감정에 민감한 결. 한 번 마음에 새겨진 감정이 오래 머물고, 기분 회복에 시간이 필요한 결입니다. |
| **어울림** | 독립적이고 개인적인 결. 혼자의 시간이 편안하고 자기 페이스로 노는 결이며, 타인의 영향을 덜 받고 외로움도 덜 타는 결입니다. | 공감적이고 사교적인 결. 타인의 감정에 민감하고 주변 분위기에 영향을 받는 결이며, 함께하는 놀이를 좋아하는 결입니다. |
| **끈기** | 관심사가 다양하고 자신의 욕구에 충실한 결. 한 자리에 오래 머무는 것보다 여러 자리를 가볍게 옮겨가며 자라고, 욕심을 부리기보다 현실과 가볍게 타협하는 결입니다. | 인내심이 강하고 끈기 있는 결. 한 번 시작한 것을 끝까지 꾸준히 들고 가는 결이며, 주의집중력이 높고 부지런한 결입니다. |

LLM 프롬프트에 위 본문 풀을 시스템 메시지로 박아두고 결 단정 본문 생성 시 위 톤으로 작성.

### 결 단정 박스 짧은 한 줄 (각 챕터 페이지 1)

위 양극 본문을 압축한 짧은 단정 한 줄:

| 요인 | 낮음 한 줄 | 높음 한 줄 |
|---|---|---|
| 활기 | 움직임이 적고 차분히 머무는 결 | 움직임이 많고 에너지가 풍부한 결 |
| 조심 | 새 자극 앞에서 망설임 없이 다가가는 결 | 새 자극 앞에서 신중하고 안전한 자리부터 찾는 결 |
| 만족 | 감정 표현이 차분하고 쉽게 만족하지 않는 결 | 일상에서 좋은 결을 자주 발견하는 결 |
| 흔들림 | 마음의 진폭이 잔잔한 결 | 감정에 민감하고 기분 회복에 시간이 필요한 결 |
| 어울림 | 혼자의 시간이 편안한 독립적인 결 | 공감적이고 사교적이며 함께 노는 결을 좋아하는 결 |
| 끈기 | 관심이 자유롭게 흐르는 결 | 인내심이 강하고 한 자리에 꾸준히 들고 가는 결 |

## 신규 핵심 룰 — 양육 진단 X (2026-05-17 추가)

새 SKU의 가장 중요한 신뢰도 룰. **반드시** 적용.

### 배경

- 사주는 **진단 도구가 아님**. 가능성·경향만 추출 가능.
- 부모(성인)는 30~40년 환경·경험·선택 누적이 많아 사주 본기와 실제 행동 괴리 큼.
- 사주로 부모 양육 행동·자녀 영향을 단정 → 부모 본인이 "안 그런데?" 반응 → 보고서 전체 신뢰 무너짐.
- 본인이 2026-05-17 명시 지시: "사주로 진단은 위험. 행동 패턴·심리 상태 알아야 진단 가능."

### 룰

**1. 부모 양육 행동 단정 금지**

- ❌ "어머님은 자녀를 따뜻하게 받아들이시는 분입니다"
- ❌ "아버님은 명확한 기준을 주시는 양육을 하십니다"
- ✅ "어머님 사주에는 정인(正印)이 본기로 자리합니다" (사주 분석)
- ✅ "정인은 명리에서 받쳐주는 결의 별로 풀이됩니다" (명리 자체 설명)

**2. 부모 → 자녀 영향 단정 금지**

- ❌ "어머님의 따뜻한 결이 자녀에게 안전한 정서 환경을 줍니다" (인과 단정)
- ❌ "어머님 사주의 온기로 ○○ 양이 받쳐지는 결입니다"
- ✅ "이 결이 ○○ 양의 결과 만나는 자리는 8장 마지막에서 정리됩니다" (연결 신호만)

**3. 부모 6축 이름·점수 본문 노출 금지**

- ❌ "어머님은 온기 78점, 일관 72점이 두드러집니다"
- ❌ "어머님 6축 점수: 온기 80 / 중심 55 / 일관 70 ..."
- ✅ "어머님 사주에는 정인이 본기로 자리합니다" (인자명만)
- ✅ "받쳐주는 결과 안정의 결이 안정되어 있습니다" (결 표현만)

**중요**: 부모 6축 점수는 **내부 로직** (`3_parent_6axes.md`)으로 산출되어 **36셀 매트릭스 매칭에만 사용**. 결과지 본문에는 6축 이름·점수가 표면에 나타나지 않음. 본문에서는 사주 본기 인자명(정인·식신·정관 등)과 결 표현("받쳐주는 결", "안정의 결" 등)으로만 전달.

**4. 자녀 시점 인과도 단정 금지**

- ❌ "어머님 사주에서 ○○ 양이 받을 결: 따뜻하게 받아들이는 결" (받을 결 단정)
- ✅ "어머님 사주의 받쳐주는 결과 ○○ 양의 깊은 정서가 만나는 자리" (36셀 매트릭스 카드에서만, 결정론 결과만 표시)

**5. 디스클레이머 명시**

표지·도입 페이지 또는 8장 헤더에 다음 디스클레이머 1회 명시:

> ※ 본 보고서의 사주 풀이는 타고난 결을 분석한 것이며, 실제 행동·양육은 환경·경험·선택에 따라 달라질 수 있습니다.

### 적용 영역

| 영역 | 양육 진단 X 룰 적용 |
|---|---|
| 1장 본질결 | △ (자녀 결 분석은 OK. 환경 변수 적음) |
| 2~7장 6요인 | △ (자녀 결 분석은 OK. 영유아라 비교적 안전) |
| 2~7장 (c) 자도인 한 마디 | ✅ 자녀 결 종합만, 양육 권고 X |
| 8장 (a)(b) 부모 사주 결 | ✅ 사주 인자 풀이만, 양육 단정 X |
| 8장 (c) 부모-자녀 사주 궁합 | ✅ 일간 관계 명리 분석만 |
| 8장 (d) 함께 살펴줄 결 | △ 36셀 매트릭스 결과 카드 — 부모 6축×자녀 6요인 결정론 매칭 결과만. "어머님의 받쳐주는 결과 ○○ 양의 깊은 정서가 만나는 자리" 같은 결 표현 |
| outro | ✅ 자녀 결 종합 + 짧은 한 줄, 양육 권고 X |

### 8장 (d) 매트릭스 카드 톤 가이드

매트릭스 카드는 결정론 결과를 보여주는 자리라 가장 양육 권고에 가까움. 그러나 톤은:

- ✅ "어머님의 받쳐주는 결과 ○○ 양의 깊은 정서가 만나면, 회복이 빠르게 흐르는 결입니다" (결 표현)
- ❌ "어머님이 따뜻하게 받아주실 때 ○○ 양이 빠르게 회복합니다" (행동 단정)

차이: "행동 → 결과" 단정 X, "결 → 결" 만남으로 풀이.

### 룰 12 — 사주 용어 풀어쓰기 변환 룰 (필수)

부모님이 명리 용어 모르고 이해 가능하게 일상어로 풀어쓰기. 한자 병기는 첫 등장만 유지.

| 어려운 용어 | 일상어 풀이 |
|---|---|
| 본기 / 본기로 자리한 | 사주의 큰 흐름 / 가장 강하게 자리한 / 가장 큰 영향 |
| 본기 인자 | 가장 큰 영향의 결 / 사주에서 가장 강한 기운 |
| 조후 | 사주 안 따뜻함과 차가움의 균형 |
| 한열조습 | 따뜻함과 차가움 |
| 한열조습 편중 | 사주 안 따뜻함과 차가움이 한쪽으로 기움 |
| 양화 / 음화 | 큰 불 / 작은 불 |
| 양금 / 음금 | 큰 쇠(도구) / 작은 쇠(도구) |
| 양목 / 음목 | 큰 나무 / 작은 나무(새순) |
| 양수 / 음수 | 큰 물(강·바다) / 작은 물(이슬·샘) |
| 양토 / 음토 | 큰 흙(산) / 작은 흙(들판) |
| 신강 | 일간의 에너지가 강함 |
| 신약 | 일간의 에너지가 작음 |
| 신약 가까운 중화 | 일간의 에너지가 작은 쪽에 가까운 균형 |
| 일지 | 자녀(본인)의 마음 자리 |
| 월령 / 월지 | 사주의 가운데 자리 |
| 통근 | (천간이) 뿌리내림 |
| 투출 | 지지장간이 천간에 떠오름 |

### 룰 13 — 사주 인자 호명 = "X 기운" (필수)

기존 "X결의 별" 호명 폐기. 모두 "기운"으로 통일.

| 인자 | 호명 |
|---|---|
| 정인 | **받쳐주는 기운** |
| 식신 | **표현하는 기운** |
| 정관 | **절제하는 기운** |
| 정재 | **결과의 기운** |
| 양인 | **결단하는 기운** |
| 칠살 | 외부 자극의 기운 |
| 천을귀인 | 사람을 끌어들이는 상서로운 기운 |
| 조후 | 따뜻함과 차가움의 균형 |
| 가산 인자 (표) | "X를 만드는 기운" |
| 감산 인자 (표) | "X를 누르는 기운" |
| 흐름 결합 | 두 기운이 흐름을 이루는 자리 |

### 룰 14 — 일간 오행 비유 = "큰 X / 작은 X" (필수)

일간 오행 풀이 시 양/음 단어 빼고 큰/작은 비교로.

```
[기존] 양화(陽火)는 한낮의 햇볕 / 음화(陰火)는 촛불
[새]   큰 불은 한낮의 햇볕 / 작은 불은 촛불

[기존] 양금(陽金)은 큰 쇠·도끼 / 음금(陰金)은 정밀한 칼
[새]   큰 쇠는 도끼·기둥 / 작은 쇠는 칼·바늘
```

### 룰 15 — 일간 풀이에 함의 한 문장 추가 (필수)

일간 비유 다음에 "그 결의 함의" 한 문장 추가. 부모님이 "그래서 어떤 결?" 의문 해소.

```
[예시]
어머님은 정화(丁) 일간입니다. 정화는 촛불·작은 등불처럼
안에서 따스하게 비추는 작은 불의 기운입니다.

[함의 추가]
작은 불은 강하게 빛나지는 않지만 안에서 오래 따스함을 머무는
결로, 정밀하고 세심하게 곁에 있는 사람을 은은하게 비추는
흐름이 자연스럽습니다.
```

### 룰 16 — 가산·감산 표 (점수·합계 노출 X)

| 항목 | 룰 |
|---|---|
| 만드는 기운 / 누르는 기운 | 표로 분리 표시 |
| 인자별 점수 (+5, -10 등) | **노출 X** |
| 합계·산출식 ("+5/-25 → 30점") | **노출 X** |
| 표 시각 색 | 만드는 기운 = 초록 / 누르는 기운 = 주황 |
| 본문 종합 | "만드는 기운 N가지 vs 누르는 기운 M가지" 직관 표현 |

**이유**: 점수·산출식 노출 = 임의 가중치 약점 노출 위험. 인자명만 보여줘도 신뢰도 충분.

### 룰 17 — 자리 X 인자 카드 부연 라벨 (필수)

부모 사주 인자가 천간·지지에 직접 자리하지 않을 때 카드 하단에 자동 표시:

```
ⓘ 직접 없음 — 다른 인자 영향으로 작게 표시
```

**이유**: 점수가 0이 아닌 작은 값(예: 22점)으로 나오면 부모님이 "왜 22점?" 의문 → 부연 라벨로 해소.

### 룰 18 — 6요인 챕터 (c) = 자도인 한 마디 → 양육 Tip 박스

룰 10 "마무리 톤"의 자도인 한 마디 박스를 **양육 Tip 박스로 교체**.

#### 양육 Tip 박스 구조

```
[👨‍👩‍👧 양육 Tip — 활기가 낮은 결의 자녀에게]
  Tip 1: 시간 배치 (예: 외출 일정 격일)
  Tip 2: 소통 방식 (예: 또래 비교 X)
  Tip 3: 환경 구조 (예: 예측 가능한 일과)
```

**3축 강제**: 시간 · 소통 · 환경 (모든 6요인 챕터 동일 패턴)

#### 사주 풀이 + 일상어 권고 통합

각 Tip 첫 문장에 사주 인자 자연 흡수:
> "안으로 들이는 부드러운 일간이 본기로 자리한 사주라 활동 후 회복에 시간이 더 필요한 결입니다. 외부 활동 일정을 격일로 잡고..."

### 룰 19 — 일상 박스 vs 양육 Tip 차원 분리

같은 자료를 다른 차원에서:

| 영역 | 차원 |
|---|---|
| **일상 박스** | 자녀 행동 양상 **관찰** ("이런 모습이 나타납니다") |
| **양육 Tip** | 부모가 해야 할 **행동** ("이렇게 해주세요") |

**예시 단어 중복 X** (둘 다 "미끄럼틀·손가락 놀이" 같은 단어 쓰면 안 됨).

### 룰 20 — 명리 원전 박스 삭제

다음 위치에서 **명리 원전 인용 박스 삭제**:
- 6요인 챕터 (2~7장) — 모든 명리 원전 박스 삭제
- 8-(c) 부모-자녀 사주 궁합 본문 — 명리 원전 박스 삭제
- 동물 캐릭터 페이지 (p.4) — 적천수 인용 문구 삭제

**유지**: 마케팅 톤의 결과지 마지막 "본 풀이의 근거" 페이지 (전체 명리 출처 안내)

### 룰 21 — 동물 캐릭터 살펴줄 결 박스 — 괄호 부연 삭제

기존: "장난감을 잃어버린 자리에서 오래 머무는 결입니다 **(흔들림 75, 회복 시간 필요)**"
새: "장난감을 잃어버린 자리에서 오래 머무는 결입니다"

### 룰 22 — 부모-자녀 일간 양방향 풀이 5유형 (필수)

부모 일간 × 자녀 일간 관계별 양방향 풀이 톤 규칙.

| 관계 유형 | 명리 관계 | 양방향 풀이 톤 |
|---|---|---|
| **천간합** (갑기·을경·병신·정임·무계) | 두 천간이 합해서 새 오행 화함 | "두 사람의 결이 합해서 새 결을 만드는 흐름" (양방향 OK) |
| **생(生)** | 부모가 자녀를 생 → 정인/편인 | 부모 → 자녀: "받쳐주는 흐름" / 자녀 → 부모: "부모 결의 근원" (양방향 OK) |
| **극(剋)** | 부모가 자녀를 극 → 정관/편관 | 부모 → 자녀: "기준·통제" / 자녀 → 부모: 명리 양방향 X. **단 천간합 있으면 합 패턴 우선** |
| **동기** (비견·겁재) | 같은 오행 | "비슷한 결로 함께 가는 흐름" (양방향 OK) |
| **재성/식상** | 부모가 자녀를 결과·표현으로 봄 | 부모 → 자녀: "결과·표현" / 자녀 → 부모: 양방향 약함 (일반 표현으로) |

**룰 우선순위**: 천간합 > 다른 관계. 천간합 있으면 합 패턴 우선 적용.

**금지**: 명리 근거 없는 양방향 풀이 (예: "작은 나무가 쇠를 무뎌지게 한다" 같은 임의 비유).

### 룰 23 — 8-(d) 매트릭스 카드 5요소 구조 (필수)

각 카드 = 다음 5요소:

```
1. [헤더] — 결합 결과를 직접 표현
   예: "김수민 양이 흔들릴 때 어머님이 안정시키는 자리"
   금지: "어머님 사주의 받쳐주는 기운 × 김수민 양의 깊은 정서" (추상)

2. [서브] — 패턴 + 점수 메커니즘
   예: "강한 시너지 — 어머님의 받쳐주는 기운(80) × 김수민 양의 깊은 정서(75)"

3. [본문 3단 풀이]
   (1) 부모 결 풀이 — 어머님/아버님이 어떤 결인지 구체
   (2) 자녀 결 풀이 — 자녀가 어떤 결인지 구체
   (3) 결합 결과 — 두 결이 만났을 때 무슨 일

4. [일상 사례 박스] — 부모 공감 포인트 1~2개
   시너지: 🌸 분홍 배경
   충돌: ⚠ 회색 배경

5. [권고 박스] — 충돌 카드만
   🌿 "이렇게 풀어보세요" 짧은 양육 권고
```

### 룰 24 — 8-(d) 카드 구성 룰 (필수)

| 케이스 | 카드 수 |
|---|---|
| 어머님·아버님 각각 시너지·충돌 적절히 분포 | 어머님 2장 + 아버님 2장 = 4장 (기본) |
| 한쪽 부모 카드가 **모두 충돌**인 경우 | 시너지 1장 추가 = **3장** (균형 보장) |

**카드 그룹 분리**: "어머님과 김수민 양의 결합" / "아버님과 김수민 양의 결합" 소제목 분리.

**8-(d) 페이지 상단 균형 메시지 박스 추가**:
```
어머님과 아버님의 결은 서로 다른 자산입니다.
어머님의 받쳐주는 결과 아버님의 기준을 주는 결이
함께 만나 자녀의 균형 잡힌 양육 환경이 됩니다.
```

### ③번 케이스 분기 룰 3유형

| 케이스 | 조건 | ③번 톤 |
|---|---|---|
| **A. 단독 두드러짐** | max ≥ 66 + (1등 - 2등) > 10 | "○○ 양은 **{본기요인}**이 가장 두드러져 **{동물}의 결**이 본 유형이 되었어요. {결의 한 줄 요약}이 사주에서 가장 강하게 자리한 결입니다." |
| **B. 상위 비등** | max ≥ 66 + (1등 - 3등) ≤ 6 | "○○ 양은 **{본기요인}**이 가장 두드러져 **{동물}의 결**이 본 유형이 되었고, **{보조요인2}과 {보조요인3}도 함께 깊어** {결의 조합 3개}이 모이는 자리가 만들어졌어요." |
| **C. 균형형** | 모든 요인 41~65 또는 max ≤ 65 | "○○ 양은 여섯 결이 모두 비슷한 높이로 자리해 **어느 한 결도 두드러지지 않는 균형의 결**입니다. **용의 결**로 정해드렸어요. 어떤 환경에도 자연스럽게 어울리는 결을 가진 자리입니다." |

### 케이스 판정 의사코드

```ts
function caseBranchForAnimal(scores: FactorScore[]): 'A' | 'B' | 'C' {
  const sorted = [...scores].sort((a, b) => b.score - a.score);
  const allMid = scores.every(s => s.score >= 41 && s.score <= 65);

  // C. 균형형
  if (allMid || sorted[0].score <= 65) return 'C';

  // B. 상위 비등 (1등과 3등 차이 6 이하 = 상위 3이 모두 비슷)
  const top3Gap = sorted[0].score - sorted[2].score;
  if (top3Gap <= 6) return 'B';

  // A. 단독 두드러짐 (기본)
  return 'A';
}
```
