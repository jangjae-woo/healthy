### 부모-자녀 일간 양방향 풀이 룰 (영향: `6_rules.md` 신규 룰)

부모 일간 × 자녀 일간 관계별 양방향 풀이 톤 규칙. 명리 표준 매핑.

| 관계 유형 | 명리 관계 | 양방향 풀이 톤 |
|---|---|---|
| **천간합** (갑기·을경·병신·정임·무계) | 두 천간이 합해서 새 오행 화함 | "두 사람의 결이 합해서 새 결을 만드는 흐름" (양방향 OK) |
| **생(生)** | 부모가 자녀를 생 → 정인/편인 | 부모 → 자녀: "받쳐주는 흐름" / 자녀 → 부모: "부모 결의 근원" |
| **극(剋)** | 부모가 자녀를 극 → 정관/편관 | 부모 → 자녀: "기준·통제" / 자녀 → 부모: 명리 양방향 X. 단 천간합 있으면 합 패턴 우선 |
| **동기** (비견·겁재) | 같은 오행 | "비슷한 결로 함께 가는 흐름" (양방향 OK) |
| **재성/식상** | 부모가 자녀를 결과·표현으로 봄 | 부모 → 자녀: "결과·표현" / 자녀 → 부모: 양방향 약함 |

**룰 우선순위**: 천간합 > 다른 관계. 천간합이 있으면 합 패턴 우선 적용.

**예시 (본 사례)**:
- 어머님 정화 → 자녀 을목 = 생(정인) → 양방향 풀이: "받쳐주는 흐름" + "자녀가 부모 결의 근원"
- 아버님 경금 → 자녀 을목 = 극(정관) + 을경합 → **천간합 우선** → "두 사람의 결이 합해서 단단한 결을 만드는 흐름"

## 2026-05-17 — 추가 변경 (시안 검토 5차)

### 8-(d) 매트릭스 카드 재설계 (영향: `1_structure.md`, `6_rules.md`)

기존 카드 헤더 "X 사주의 받쳐주는 기운 × Y의 깊은 정서"가 추상적이라 와닿지 X. 카드 구조 전면 재설계.

#### 새 카드 구조 (5요소)

1. **헤더** — 결합 결과를 직접 표현 (예: "김수민 양이 흔들릴 때 어머님이 안정시키는 자리")
2. **서브** — 패턴 + 점수 메커니즘 (예: "강한 시너지 — 어머님의 받쳐주는 기운(80) × 김수민 양의 깊은 정서(75)")
3. **본문 3단 풀이**:
   - (1) 부모 결 풀이 — 어머님/아버님이 어떤 결인지 구체
   - (2) 자녀 결 풀이 — 자녀가 어떤 결인지 구체
   - (3) 결합 결과 — 두 결이 만났을 때 무슨 일
4. **일상 사례 박스** (🌸 시너지 분홍 / ⚠ 충돌 회색) — 부모 공감 포인트 1~2개
5. **권고 박스** (충돌 카드만) — 🌿 "이렇게 풀어보세요" 짧은 권고

#### 카드 본문 룰
