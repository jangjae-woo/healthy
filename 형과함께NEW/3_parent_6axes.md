# 3. 부모 양육 6축 점수 산출

> ⚠️ **2026-05-17 갱신 — 부모 6축은 내부 로직으로만 사용**:
> 부모 양육 행동 단정은 신뢰도 위험 (성인은 환경·경험·선택 누적이 많아 사주 본기와 실제 행동 괴리 큼).
> 부모 6축 점수는 **결과지 본문에 노출 X**. **36셀 매트릭스 매칭(8장 (d))에만 내부적으로 사용**.
> 본문에서는 6축 이름(온기·중심·일관·자율·표현·바람) 표면에 나타나지 않음. 사주 본기 인자명(정인·식신·정관 등)과 결 표현("받쳐주는 결", "안정의 결" 등)으로만 전달.
> 자세한 양육 진단 X 룰은 `6_rules.md` 참조.

## 6축 정의 (C안 — 2026-05-16 확정, 2026-05-17 사용 범위 한정)

| # | 축 | 의미 |
|---|---|---|
| 1 | **온기** | 정서적 수용·공감 — 자녀를 따뜻하게 받아주는 결 |
| 2 | **중심** | 기준·통제·일관성 — 명확한 한계와 기준을 주는 결 |
| 3 | **일관** | 예측가능성·꾸준함 — 흔들림 없는 일상의 결 |
| 4 | **자율** | 자율 부여·기다림 — 자녀에게 흐를 자리를 주는 결 |
| 5 | **표현** | 마음·기대 표출 — 자기 결을 입 밖으로 꺼내는 정도 |
| 6 | **바람** | 결과·성취 압력 — 자녀에게 거는 기대의 결 |

**중요**: 부모 양육태도는 **자기보고 설문 X**. 부모 사주에서 결정론적으로 추출 (`자녀 6요인`과 같은 3단 공식).

---

## 점수 산출 — 3단 공식 (자녀 6요인과 동일)

```
인자 점수 = (명리 강도 0~100) × (요인 기여 등급 0~1.0) × (위치 가중치 0~1.0)
축 총점 = clamp( 50 + Σ(인자 점수 × 부호) / 6, 0, 100 )
구간: 낮음 0~40 / 중간 41~65 / 높음 66~100
```

**3단 공식 디테일은 `2_child_6factors.md` 동일** (명리 강도·요인 기여 등급·위치 가중치 표 그대로 재사용).

부모별로 6축 산출:
- 어머님 사주 → 어머님 6축 점수
- 아버님 사주 → 아버님 6축 점수
- 각 부모별 6각 다이아몬드 시각 자산 분리

**명리 근거**:
- 자평진전 「인수자 인지자야(印綬者 仁之資也) — 인성은 인(仁)의 자질」
- 적천수 — 식신은 일주의 빛이 부드럽게 밖으로 나오는 결
- 궁통보감 조후론 — 한열조습 균형은 일주의 안정

## 부모 6축 직교성 검토

| 축 | 핵심 본기 인자 | 다른 축과 겹침 |
|---|---|---|
| 온기 | 정인·식신·조후균형 | 일관(정인 상조)·자율(식상 본기) — 약함 |
| 중심 | 정관·양인·신강 | 바람(정관 상조·양인 상조) — 약함 |
| 일관 | 토 오행·관인상생·일주 안정 | 거의 없음 |
| 자율 | 식상·재성·신강신약 균형 | 표현(식상 본기) — 본기 1개 겹침 |
| 표현 | 상관·식신 | 자율(식상)·온기(식신 본기) — 본기 겹침 |
| 바람 | 편재·정재·칠살 | 중심(칠살 상조) — 약함 |

**약한 겹침 2곳** (자율 vs 표현 — 식상 본기 공유, 온기 vs 표현 — 식신 본기 공유):
- 본기 본질상 자연스러운 겹침
- 풀이 톤으로 구분:
  - **자율 식상** = "자녀에게 흐름을 줌"
  - **표현 식상** = "부모가 밖으로 꺼냄"
  - 둘 다 식상이 본기지만 풀이 방향이 다름

> [8-(a) 어머님 사주의 결]

> 이 결이 OO 양의 결과 만나는 자리는 본 장 마지막 "함께 살펴줄 결"에서 정리됩니다.

## 코드 의사코드 (TypeScript)

```ts
// lib/youa/parent-axes.ts

import type { Saju } from '../saju-traditional';
import { GRADE, POSITION, getMyeongriStrength, getOhaengStrength, /* ... */ } from './factors';

interface AxisScore {
  axis: 'ongi' | 'jungsim' | 'ilgwan' | 'jayul' | 'pyohyeon' | 'baram';
  score: number;
  level: 'low' | 'mid' | 'high';
  mainFactors: Array<{ name: string; strength: number }>;
}

// 온기 점수 산출 (어머님·아버님 사주 각각 호출)
export function calcOngi(parentSaju: Saju): AxisScore {
  let sum = 0;
  
  // 본기 (계수 1.0)
  sum += getMyeongriStrength('정인', parentSaju) * GRADE.bongi * getPositionWeight('정인', parentSaju);
  sum += getMyeongriStrength('식신', parentSaju) * GRADE.bongi * getPositionWeight('식신', parentSaju);
  if (isJohuBalance(parentSaju)) sum += 100 * GRADE.bongi;
  
  // 상조
  if (isEumIlgan(parentSaju)) sum += 50 * GRADE.sangjo;
  if (hasCheoneuli(parentSaju)) sum += 50 * GRADE.sangjo;
  if (hasGwaninSangsaeng(parentSaju)) sum += 50 * GRADE.sangjo;
  
  // 여기
  if (hasIljuStable(parentSaju)) sum += 50 * GRADE.yeogi;
  
  // 감산
  if (hasChilsalStrongAndInbumeOmni(parentSaju)) sum -= 100 * GRADE.bongi;
  if (hasYangin(parentSaju)) sum -= 100 * GRADE.sangjo;
  if (isJohuExtreme(parentSaju)) sum -= 100 * GRADE.sangjo;
  
  const score = clamp(50 + sum / 6, 0, 100);
  
  return {
    axis: 'ongi',
    score,
    level: score <= 40 ? 'low' : score <= 65 ? 'mid' : 'high',
    mainFactors: extractMainFactors(parentSaju, 'ongi'),
  };
}

// 다른 5축도 동일 패턴
```

## 부모 1명만 입력 시

```ts
interface YouaInput {
  childSaju: Saju;
  motherSaju?: Saju;  // 옵셔널
  fatherSaju?: Saju;  // 옵셔널
}

function calcParentAxes(input: YouaInput) {
  const motherAxes = input.motherSaju ? calcAllAxes(input.motherSaju) : null;
  const fatherAxes = input.fatherSaju ? calcAllAxes(input.fatherSaju) : null;
  return { motherAxes, fatherAxes };
}
```

2. 사주 설명 산문 2단락 (일간 비유 + 사주 큰 흐름)
3. 사주 인자 박스 카드 6개 (정인·식신·정관·정재·양인·조후)
4. 각 카드: 아코디언 패턴 (탭 시 작용 디테일 펼침)

→ 부모 6축은 코드 내부 로직(매트릭스 매칭용)으로만 사용. 결과지에는 사주 인자 자체로 표시.

| 부모 6축 (내부) | 결과지 노출 호명 (8-d 카드 헤더용) |

| 온기 | 받쳐주는 결 / 받쳐주는 기운 |

8-(d) 카드 헤더는 "결합 결과 직접 표현"으로 (룰 23·헤더 변환 룰). 예: "어머님의 한결같음이 자녀의 정서를 가라앉히는 자리" (일관 × 흔들림).
