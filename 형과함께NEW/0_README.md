## 동생에게

이 폴더는 **유아용(36~72개월) 부모-자녀 궁합 사주 SKU**의 기획 설계 패키지야.

형이 기획·설계·룰을 정리하고, 동생이 프롬프트 작성·코드 반영·배포를 담당해.

### 중요 — V2 자도인과 분리

V2 자도인(부모-자녀 궁합 보고서, `app/parent-child-v2/`)의 룰·코드 자산은 **일절 가져오지 마**. 별도 worktree에서 백지로 신규 구축.

V2 자도인 폐기 사유:
- 사주 인자 약 50개 ÷ 25 소제목 = 같은 인자 평균 2.5회 등장 = **구조적 중복 강제**
- 룰(절대원칙 A~L)을 더 추가해도 해결 X — 사주 외 입력(STS 6요인)이 본질 해법
- 그 룰셋 자체가 V2 SKU에 맞춰진 거라 새 SKU(유아용)에 가져오면 모순·충돌 재발

자세한 사유는 `6_rules.md`의 "V2 자도인 배제 룰" 섹션 참조.

## 차별축 (인싸이트 STS 대비)

| 항목 | 인싸이트 STS | 우리 SKU |
|---|---|---|
| 입력 | 부모가 ~36문항 체크 (20분) | 생년월일시만 (30초) |
| 자녀 분석 차원 | 6요인 (활동성·조심성·긍정정서·부정정서·사회적 민감성·의도적 조절) | **6요인 — 활기·조심·만족·흔들림·어울림·끈기** (v2.0 명칭 재정의) + 일주 본질결 + 동물 캐릭터 |
| 부모 분석 | 없음 (자녀만) | 양육태도 6축 — 사주 추출 |
| 부모-자녀 결합 | 없음 | 6×6 = **36셀 결정론 매트릭스** |
| 검사 결과 신뢰 근거 | 한국 코호트 표준화 | 결정론적 사주 매핑 + 명리 원전 |
| 양육 Tip | 일반 발달심리 톤 | 사주 인자 + 기질 결합 풀이 |

이 6개가 인플루언서 공구 카피의 핵심 셀링포인트.

## 형이 동생에게 자주 받을 질문 예상

**Q. V2 자도인 코드 일부라도 재활용 가능?**
A. 사주 계산 모듈(`lib/saju-traditional.ts` 같은 명리 표준 계산 함수)은 가능. 단 자도인 프롬프트·V2 절대원칙 A~L·시그너처 어휘·박스 금지 룰 등은 일절 X. 6_rules.md 참조.

**Q. 정규화 상수 ÷6은 어디서 온 값?**
A. 직관 추정값. 100개 사주 샘플 캘리브레이션 후 조정 필요. 2_child_6factors.md 끝 캘리브레이션 섹션 참조.

**Q. 동물 일러스트는 누가 그리나?**
A. 미정. 외주 디자이너 또는 AI 생성(Midjourney·SDXL 등). 5_visuals.md 끝 일러스트 발주 섹션 참조.

**Q. 결제·랜딩은?**
A. 기존 paljawon.com 인프라 재활용. 별도 SKU 라우트만 추가하면 됨.

**Q. 모르는 사주 인자나 명리 표현 나오면?**
A. 형에게 물어봐. 명리 통설 검증은 형 책임.

**Q. 결과지 본문에서 "본기"·"조후"·"양화" 같은 명리 한자어 그대로 써도 되나?**
A. **No**. `6_rules.md` 룰 12 (사주 용어 풀어쓰기 변환 룰) 그대로 적용. 첫 등장 시 한자 1회 병기만 OK.

**Q. 사주 인자 호명을 "정인"·"식신" 그대로 노출해도 되나?**
A. **No**. 룰 13 "X 기운"으로 통일 (정인=받쳐주는 기운, 식신=표현하는 기운 등). 본문 가산·감산 표·코드 주석에는 그대로 유지 OK.

**Q. 8-d 매트릭스 카드 헤더는 어떻게 쓰나?**
A. 결합 결과를 직접 표현. 예) "김수민 양이 흔들릴 때 어머님이 안정시키는 자리". 추상 표현 X. 룰 23·24 참조.

**Q. 명리 원전 인용 박스(자평진전·적천수 인용)를 결과지 본문에 노출해도 되나?**
A. **No**. 룰 20 (명리 원전 박스 삭제). 자도인 톤 안에서 원전 정신을 자연스럽게 흡수. 단 코드 주석·내부 문서에는 유지 OK.

**Q. 동물 유형 종합 해석 페이지(p.10, v1.7부터)는 왜 7장 다음, 8장 직전인가?**
A. STS와 동일한 논리. 6요인 detail이 다 노출된 직후 = "왜 그 동물인가" 점수 근거가 갖춰진 시점. 그 직후 자녀 결을 종합·결산하고 부모 챕터(8장)로 전환. 룰 28 참조.

**Q. p.10 양육 코칭과 2~7장 (c) 양육 Tip이 중복 아닌가?**
A. 아님. 6요인 챕터 (c) = **단일 요인 기준** Tip (예: "활기가 낮은 결 자녀에게"). p.10 양육 코칭 = **동물 유형 = 매칭 키 3요인 조합 기준** 코칭 (예: "양의 결 = 어울림+흔들림+조심 조합 자녀에게"). 분석 단위가 달라 중복 X.

**Q. 동물 매칭 룰이 max 1요인 기준인데 p.10에서 왜 상위 3요인을 보여주나?**
A. 매칭은 max 1요인 (5_visuals.md `matchAnimal` 함수). p.10에서 보여주는 상위 3은 "왜 그 동물인지 + 그 결을 더 깊게 만드는 보조 결까지" 직관적으로 설명하기 위해. 매칭 본기는 라벨 "가장 두드러짐", 보조 2개는 "함께 깊음".

**Q. 표지(p.1)에 동물 이모지·일러스트 노출해도 되나?**
A. **No** (v1.7 룰). 표지에 동물 정체성을 노출하면 종합 해석 페이지(p.10)의 임팩트가 분산. 표지는 title + subtitle + info + 자도인 마크만 노출.

**Q. p.4 동물 캐릭터 인사 컷 페이지는?**
A. **v1.7부터 폐기**. 동물 노출 = p.10 한 곳으로 단일화. 1장 본질결도 일간·일주 2개 소제목만 남음 (동물 캐릭터 소제목 X).

**Q. 본인 입력 — 부모 사주 정보는 어디서 받나?**
A. 입력 폼에 어머님·아버님 생년월일시 추가. 한쪽 부모만 입력 가능 (1_structure.md 8장 분기 참조).
