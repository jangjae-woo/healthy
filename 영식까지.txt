## ✅ 영식 매핑 (대화 누적 기록)

```
"바른생활 테리우스·모범생"
- 정성스럽게 다가옴 (예: 손풍기 선물·이름 새기기)
- 세심·정성·헌신적
- 내향·진솔
- 큰 키·곱상한 미남 (외형 통념 → 내적 X)
```

### V3 적용 매핑

| 항목 | 내용 |
|---|---|
| **이름** | 영식 |
| **내적 이미지** | 착실·정성·세심·바른생활·모범생 |
| **사주 신호 (정밀)** | 정관(正官) + 정인(正印) + 식신(食神) 균형 + 음일간 |
| **우선순위 캐스케이드** | **2순위** (영철 다음) |
| **여자 평행 캐릭터** | 영숙 (참한·맞춰주는·다정·부드러운) |
| **현대 옷 톤** | 깔끔한 그레이 셔츠 + 슬랙스 |

### 우선순위 캐스케이드 (남자 6명)

```
1순위: 식상(상관) + 도화 + 양일간 → 영철
2순위: 정관 + 정인 + 식신 균형 + 음일간 → 영식 🆕
3순위: 정관 + 식상(상관) + 비견 결합 → 영호
4순위: 편인 강 + 정관 + 깊이 → 광수
5순위: 정관·정인 안정 + 중후 → 영수
6순위 (fallback): 균형 + 정재·식신 안정 → 상철
```

### 영식 차별 (다른 남자 캐릭터와)

| 비교 | 영식의 차별 |
|---|---|
| 영식 vs 영호 | 영식 = **내향·정성** (정관+정인) / 영호 = **외향·사교** (정관+상관+비견) |
| 영식 vs 광수 | 영식 = **정성·세심·식신 결합** / 광수 = **편인 우세·진중·깊이** |
| 영식 vs 영수 | 영식 = **젊음·정성·식신 활발** / 영수 = **중후·안정·식상 약** |
| 영식 vs 상철 | 영식 = **정관·정인 강함 (모범)** / 상철 = **균형·재성 안정 (편안)** |

→ 4명 차별 명확

## V3 적용 위치 (현재 매트릭스)

### 3장 ① "내 짝꿍은 누구일까?" — 남자 6명 매칭 후보
```
영철 / 영식 / 영호 / 광수 / 영수 / 상철
   ↑
  포함됨 ✅
```

### 짝꿍 매트릭스 6×6 = 36
```
여자 6명 × 남자 6명 (영식 열 포함) = 36 매칭

영식 짝꿍 6칸:
- 옥순 × 영식 = 직진녀에게 정성 다하는 결
- 현숙 × 영식 = 시크녀+정성, 진심에 마음 여는 결
- 정숙 × 영식 = 강단+정성, 가장 안정된 결혼 적합 결
- 순자 × 영식 = 활발+세심, 활기와 정성 시너지
- 영숙 × 영식 = 참한+정성, 둘 다 바른생활 (가장 평화)
- 영자 × 영식 = 일상+정성, 따스하고 부담 없는 결
```
